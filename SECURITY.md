# Security policy

## Supported versions

AetherRoute is currently in pre-release development. Security fixes are made
against the latest `main` branch and the latest published prerelease.

## Reporting a vulnerability

Do not open a public issue with an exploit, subscription URL, activation key,
profile, diagnostic archive, certificate, or customer information. Use the
repository's private security-advisory channel and include:

- affected version or commit;
- impact and reproduction steps;
- whether TUN, Transparent Proxy, profile import, licensing, or updates are
  involved;
- a minimal redacted proof of concept.

The maintainer will acknowledge a valid report, assess severity, prepare a
private fix, and publish coordinated release notes after affected users have a
safe upgrade path. Never send Apple credentials or private signing keys.
