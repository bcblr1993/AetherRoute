# 官网设计规范

## 视觉

- 背景：暖白 `#faf9f6`；正文：石墨灰 `#242b31`；强调色：蓝色 `#315cce`。
- 强调色用于主按钮、标题重点和当前导航，不使用彩色渐变文字。
- 使用系统字体，中文优先 PingFang SC；不请求第三方字体。
- 页面宽度上限 1120px，说明文档正文上限 840px。手机左右留白 20px。
- 首页突出产品与下载，功能介绍使用短句；协议、校验和与详细说明按需展开。
- 说明页保留完整安装步骤、版本事实与法律条款，使用统一段落、分隔线和提示样式。

## 公共组件

所有正式 HTML 与 `templates/` 中的版本模板，共用 `public/assets/site.css` 和 `site.js`。
页头包含产品标识、体验、版本、帮助、语言切换、获取按钮；页尾包含版本、帮助、隐私、许可与 GitHub。
手机收起桌面导航，所有目的页仍可由页尾及获取按钮到达。

- `.primary`：主要下载操作；`.button`：正文次级操作。
- `.page-hero`：说明页标题区；`.prose`：阅读正文；`.notice`：重要操作说明。
- `.card`：版本或支持入口；`.checksum`：可通过鼠标、Enter 或空格复制的校验信息。
- 中英文使用 `data-lang="zh|en"`；实际软件截图按语言切换。
- 保留清晰键盘焦点，尊重系统减少动态效果偏好。
- 禁用内联样式和内联脚本，遵守正式站 CSP；更改公共资源时同步更新全部页面、模板和静态检查中的版本参数。

## 发布验证

```sh
bash scripts/test_distribution_web.sh
node --check Services/WebDistribution/public/assets/site.js
```

本地浏览必须检查首页、版本目录、各历史版本、支持、隐私、许可、404；覆盖中英文、手机宽度、截图切换、展开说明及校验和复制。
发布仅上传 `public/`，`design-preview/` 是历史设计草案，不包含在正式发布中。
部署前确认 Cloudflare Pages 项目 `aetherroute` 的生产分支，保留前一次生产部署 ID；部署后检查正式域名页面及样式脚本版本。
