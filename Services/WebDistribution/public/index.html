  • 配置随行，连接独立。同步订阅与节点配置，每台设备独立控制连接，并保留自己的活动配置。Shared profiles. Independent connections. Sync subscription and node profiles while each device controls its own connection and keeps its active profile.

M 系列芯片 · 深度定制Purpose-built for Apple M-series

原生到底，优化到细节。Native at heart. Tuned in every detail.

专为 Apple M 系列芯片深度定制，以极致优化为目标。arm64 原生架构、SwiftUI 界面与 Rust 网络核心协同工作，从按需刷新到批量数据包处理，持续打磨响应速度、资源占用与能效表现。Purpose-built for Apple M-series chips, with optimization at every layer. Native arm64, SwiftUI and a Rust networking core work together, with on-demand updates and batched packet processing to refine responsiveness, resource use and efficiency.

了解细节Explore the details+
  • ARMv8 硬件加解密指令加速：原生调用 M 芯片内置 Cryptography Extensions（硬件 AES/SHA/NEON），线速数据包加解密在硬件流水线瞬间完成，不占 CPU 核心。ARMv8 Hardware Cryptography: Directly invokes Apple Silicon's on-chip Cryptography Extensions (hardware AES/SHA/NEON), offloading crypto to dedicated silicon without CPU penalty.
  • 统一内存（Unified Memory）零冗余架构：Swift 6 宿主与网络内核通过静态链接高效整合，消除跨进程 IPC 套接字/管道序列化与内存多重拷贝，总物理内存仅约 210MB（较传统减少 60%+）。Unified Memory Zero-Redundancy: Swift 6 host and Rust protocol engines are statically linked, eliminating IPC socket serialization and redundant buffer copying to maintain a lean ~210MB footprint.
  • E-Core 能效核与内核深度休眠：菜单栏面板收起时，100% 线程立即切入 mach_msg2_trap 内核深度休眠，定时器与多余唤醒归零，后台静默 CPU 仅 0.0% ~ 0.1%，冷感长续航。E-Core & Kernel Sleep Scheduling: 100% of threads enter mach_msg2_trap deep kernel sleep when collapsed, eliminating background timers for 0.0% ~ 0.1% idle CPU and all-day endurance.
  • NEPacketTunnelFlow 批量刷包优化：结合单例报文头与批量数据包写入（Coalesced Flush），减少 95% 以上系统内核上下文切换，大吞吐依然平稳丝滑。Batched Packet Flushing: Coalesces tunnel packet writes with shared protocol headers via NEPacketTunnelFlow, slashing kernel context switches by over 95%.

对比 Clash Verge、Surge 等主流客户端，AetherRoute 性能表现如何？ How does AetherRoute compare with Clash Verge and Surge in performance? +

得益于纯血 Swift 6 + SwiftUI 原生架构与静态链接的 Rust 高性能协议引擎，AetherRoute 相比 Electron 类客户端（如 Clash Verge、Nyanpasu）减少了超过 60% 的内存消耗（总物理 Footprint 仅约 210MB 对比 500MB~800MB+），并彻底消除了 Chromium 后台定时器唤醒，后台静默 CPU 低至 0.0% ~ 0.1%（100% 线程进入 mach_msg2_trap 内核深睡）。在持续吞吐能效与系统扩展沙盒安全性上，完全比肩业内标杆 Surge Mac，且无需安装任何带有 Root 权限的第三方 Helper 守护进程。Thanks to pure Swift 6 and statically linked Rust protocol engines, AetherRoute consumes over 60% less memory than Electron apps like Clash Verge (around 210MB vs 500MB~800MB+) and eliminates Chromium background wakeups, achieving 0.0% ~ 0.1% background idle CPU via mach_msg2_trap. Its throughput efficiency and sandbox safety rival Surge Mac, without requiring privileged root helpers.

AetherRoute 专为 Apple 芯片（M 系列）做了哪些底层深度优化？ What low-level deep optimizations are tailored for Apple silicon? +

AetherRoute 采用纯 arm64 架构从源码编译，完全剥离任何 x86 兼容层，零 Rosetta 2 性能损耗与内存惩罚。底层深度利用 Apple Silicon 硬件特性：① 直接调用 ARMv8 Cryptography Extensions（硬件 AES 与 SHA 指令），在芯片硬件流水线中瞬间完成复杂节点加解密，释放 CPU 计算核心；② 依托 Apple 统一内存架构（Unified Memory），网络核心静态链接至扩展，根除跨进程 IPC 套接字/管道序列化与内存多重拷贝；③ 深度适配 macOS 异构能效核调度，折叠菜单栏时 100% 线程切入 mach_msg2_trap 内核级深睡，零无用定时器唤醒，实现全天候 0.0% ~ 0.1% 静默 CPU 与冷感超长电池续航；④ NEPacketTunnelFlow 批量单例刷包机制，大幅聚合虚拟网卡数据包下发，降低 95% 以上内核上下文切换。AetherRoute is built 100% natively as pure arm64 with zero Rosetta 2 translation overhead or memory penalty. It takes deep advantage of Apple silicon hardware: (1) Harnesses ARMv8 Cryptography Extensions (hardware AES/SHA instructions) directly in silicon for line-rate encryption without CPU bottlenecks; (2) Leverages Apple Unified Memory architecture with static core linkage to eliminate IPC serialization and duplicate memory copying; (3) Integrates with Efficiency-core scheduling, placing 100% of threads into mach_msg2_trap deep kernel sleep when collapsed for 0.0% ~ 0.1% idle CPU and all-day fanless battery life; (4) Uses NEPacketTunnelFlow batched packet coalescing to cut kernel context switches by over 95%.

灵活选择连接方式：透明代理与 TUN 有何区别？ Connect your way: Transparent Proxy vs Direct TUN +

提供透明代理（App Proxy）与 Direct TUN 两种网络引擎，均支持规则、全局和直连模式。透明代理运行在用户态，开销更低，DNS 由系统直接托管；Direct TUN 创建虚拟网卡捕获整机全部 TCP/UDP 流量并配备 Fake-IP，适合需要全面接管终端命令行及各类后台服务的进阶场景。AetherRoute embeds Transparent Proxy (App Proxy) and Direct TUN engines, both supporting Rule, Global, and Direct modes. Transparent Proxy is lightweight and keeps macOS DNS authoritative; Direct TUN captures all TCP/UDP traffic and command-line tools with built-in Fake-IP.
