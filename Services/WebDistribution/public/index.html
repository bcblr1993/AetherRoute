兼容真实订阅Practical subscription import

原生、清晰、可访问Native, clear, accessible

遵循 macOS 导航、键盘焦点、减少动态效果和系统外观约定；状态、错误和恢复操作始终出现在明确位置。Follows macOS navigation, keyboard focus, Reduce Motion, and appearance conventions, with status, errors, and recovery actions kept in predictable places.

◉

资源边界与故障关闭Bounded resources, fail closed

导入、延迟测试和连接任务具有大小、并发与超时限制；协议核心未就绪时不会把界面伪装成已连接。Imports, latency checks, and connection work are bounded by size, concurrency, and timeouts. The UI never claims a connection before the protocol core is ready.
