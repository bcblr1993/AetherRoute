常见问题解答Frequently Asked Questions

关于系统权限、隐私保护与使用机制的透明说明。Transparent answers about permissions, security, and operation.

使用 AetherRoute 需要降低系统安全性或关闭 SIP 吗？Does AetherRoute require disabling SIP or lowering security?

完全不需要。AetherRoute 基于现代 Apple Network Extension 用户态框架构建，绝不加载遗留的内核扩展（KEXT），在保持 macOS 完整系统安全性与 SIP 完整启用的状态下即可顺畅运行。Absolutely not. AetherRoute is built on modern Apple Network Extension user-space APIs. It never uses kernel extensions (KEXT) and runs seamlessly with System Integrity Protection (SIP) fully active.

为什么 AetherRoute 仅支持 Apple 芯片，而不支持 Intel 架构 Mac？Why is AetherRoute exclusively for Apple silicon Macs?

为了追求极致的原生性能与最低功耗，AetherRoute 1.0.0 的网络数据平面与加解密引擎专门面向 ARM64 硬件指令集进行了优化编译，彻底抛弃了跨架构兼容的历史包袱，实现毫秒级冷启动与数十兆极低内存占用。To achieve maximum native throughput and minimal power consumption, AetherRoute 1.0.0 is compiled specifically for ARM64 hardware instructions, shedding legacy x86 overhead for instant cold starts and sub-35MB memory usage.

断开连接后，我的 Mac 会出现网络残留或打不开网页的情况吗？Will disconnecting leave residual proxy settings or break internet access?

绝不会。传统客户端往往通过直接修改 macOS“系统设置 → 网络代理”来接管流量，进程意外退出极易造成断网残留。AetherRoute 默认绑定本地环回接口并通过系统网络扩展接管，断开即立即恢复原生网络，零残留。Never. Traditional clients often rewrite macOS system network proxies, which frequently breaks connectivity upon crashes. AetherRoute utilizes pure Network Extensions, cleanly restoring your pristine network interface immediately upon disconnection.

AetherRoute 是否收费？应用是否提供内置代理节点？Is AetherRoute free? Does it provide built-in proxy servers?

AetherRoute 1.0.0 采用 MIT 开源协议完全免费分发，无任何付费内购、会员账号体系或强制广告。应用本身是纯粹的通用客户端工具，不提供、不销售也不运营任何第三方网络节点或订阅服务。AetherRoute 1.0.0 is distributed freely under the MIT license without any in-app purchases, subscriptions, or paywalls. It is a strictly standalone client tool and neither sells nor hosts any proxy servers or subscriptions.
