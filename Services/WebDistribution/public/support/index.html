请勿公开订阅地址、激活码、节点密码、私钥或完整配置。Never post subscription URLs, activation keys, node passwords, private keys, or complete profiles.

提交问题前Before reporting

  1. 确认正在使用的版本、构建号和 macOS 版本。Record the AetherRoute version, build, and macOS version.
  2. 在“设置 → 诊断”导出隐私安全报告。Export the privacy-safe report from Settings → Diagnostics.
  3. 说明使用透明代理还是 TUN、问题是否可复现，以及其他代理软件是否同时运行。State whether you use Transparent Proxy or TUN, whether it reproduces, and whether another proxy app is running.
  4. 若单个节点失败，确认同一节点在独立客户端中的实际握手结果。For a node-specific failure, confirm the same node's real handshake in an independent client.

安装提示Installation notes

DMG 已通过 Developer ID 签名和 Apple 公证。首次启用透明代理或 TUN 时，macOS 会要求批准网络扩展。AetherRoute 不会绕过、自动点击或模拟此系统授权。The DMG is Developer ID signed and Apple notarized. macOS asks for approval the first time you enable Transparent Proxy or TUN. AetherRoute never bypasses, auto-clicks, or simulates this system authorization.
