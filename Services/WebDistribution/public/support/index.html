三步开始使用Get started in three steps

  1. 下载免费 Beta 或稳定版，打开 DMG，将 AetherRoute 拖入“应用程序”，再从“应用程序”打开。Download the free beta, open the DMG, drag AetherRoute into Applications, and launch it from there.
  2. 在“配置”中添加自己的订阅、节点或本地配置。路由资源已随应用提供，无需单独下载数据库。Add your own subscription, nodes, or local configuration in Profiles. Routing resources are bundled with the app; no separate database download is needed.
  3. 回到“概览”点击连接，按下方步骤批准 macOS 网络扩展，然后返回应用继续连接。Click Connect in Overview, approve the macOS Network Extension using the steps below, then return to the app to continue.

免费版不需要账号或付费激活。应用本身不提供订阅或代理节点。The free edition needs no account or paid activation. The app does not provide subscriptions or proxy nodes.

首次启用网络扩展Enable the Network Extension

透明代理和 TUN 可以路由网络流量，因此 macOS 15 或更高版本要求您亲自批准。AetherRoute 会把您带到正确的系统设置页面，但不会绕过、自动点击或模拟这项安全授权。Transparent Proxy and TUN can route network traffic, so macOS 15 or later requires your approval. AetherRoute takes you to the correct System Settings page but never bypasses, auto-clicks, or simulates this security authorization.

  1. 将 AetherRoute 拖到“应用程序”，打开后导入或选择一个有效配置，再点击连接。Move AetherRoute to Applications, open it, import or select a valid profile, then click Connect.
  2. 出现“批准网络扩展”卡片后，点击“打开系统设置”。When the “Approve Network Extension” card appears, click “Open System Settings.”
  3. 在“通用 → 登录项与扩展”中继续滚动到页面底部的“扩展”区域；不要操作上方的“登录时打开”列表。In General → Login Items & Extensions, scroll to the Extensions section at the bottom. Do not use the Open at Login list.
  4. 找到“网络扩展”，点右侧信息按钮 ⓘ，打开 AetherRoute，然后点“完成”。Next to Network Extensions, click the info button, turn on AetherRoute, then click Done.
  5. 返回 AetherRoute，点击“已批准，重新检查”；应用会继续刚才的连接。Return to AetherRoute and click “Approved — Check Again.” The app resumes the pending connection.
不需要降低系统安全性。Reduced Security is not required. AetherRoute 使用 Apple 的用户空间 Network Extension，不需要关闭 SIP（does not require disabling SIP），也不需要在恢复模式启用内核扩展。如果这台 Mac 由组织管理且开关不可用，请联系管理员批准网络扩展。 AetherRoute uses Apple's user-space Network Extension. It does not require disabling SIP or enabling kernel extensions in Recovery. If this Mac is managed and the switch is unavailable, ask your administrator to approve the Network Extension.

显示已连接，但网页打不开Connected, but websites do not load

“已连接”不能保证每个节点和网站都能访问。先确认实际网页是否可用，再按以下顺序排查：A connected status does not guarantee that every node or website is reachable. Check a real webpage, then try these steps:

  1. 确认当前配置和选择的节点正确；需要代理的网站应使用代理节点，避免误选 DIRECT（直连）。Check the active profile and selected node. Use a proxy node for sites that require one, and check that DIRECT was not selected by mistake.
  2. 如果还有其他代理或 VPN 软件正在连接，先断开它们，再重新连接 AetherRoute 一次。If another proxy or VPN is connected, disconnect it and reconnect AetherRoute once.
  3. 尝试另一个已知可用的节点，并访问两个不同的网站。记录是所有网站都失败，还是只有某个网站无法访问。Try another known-working node and two different websites. Note whether all sites fail or only one is affected.
  4. 仍然失败时，记录使用的是 TUN 还是透明代理，以及页面或应用显示的错误，再导出下方的诊断报告。If it still fails, note whether you use TUN or Transparent Proxy and the error shown by the page or app, then export the diagnostics described below.

如需恢复原有网络，先点击“断开连接”。不要为了排查而关闭系统完整性保护或删除系统网络文件。To restore your previous network, click Disconnect first. Do not disable System Integrity Protection or delete system network files while troubleshooting.

仍然看不到 AetherRoute？Still cannot find AetherRoute?

  1. 确认 App 位于“应用程序”文件夹，而不是仍从 DMG 或下载目录运行。Confirm the app is in Applications rather than running from the DMG or Downloads.
  2. 完全退出 AetherRoute，重新打开，再点击一次连接以重新提交安装请求。Quit AetherRoute completely, reopen it, and click Connect once to submit the installation request again.
  3. 若系统要求重启，请先保存工作并按提示重启；返回后点击“已批准，重新检查”。If macOS asks for a restart, save your work and restart as instructed; then return and click “Approved — Check Again.”
  4. 仍失败时，在“设置 → 诊断”导出隐私安全报告，并附上错误文字；不要发送订阅、节点密码或私钥。If it still fails, export the privacy-safe report from Settings → Diagnostics and include the exact error text. Never send subscriptions, node passwords, or private keys.

提交问题前Before reporting

  1. 确认正在使用的版本、构建号和 macOS 版本。Record the AetherRoute version, build, and macOS version.
  2. 在“设置 → 诊断”导出隐私安全报告。Export the privacy-safe report from Settings → Diagnostics.
  3. 说明使用透明代理还是 TUN、问题是否可复现，以及其他代理软件是否同时运行。State whether you use Transparent Proxy or TUN, whether it reproduces, and whether another proxy app is running.
  4. 若单个节点失败，说明它是否能在你原来使用的客户端中正常连接。For a node-specific failure, note whether the same node connects successfully in your previous client.
