AetherRoute 1.0.17

Build 2026091802 · 2026-09-18 · Apple silicon · macOS 15.0+

开机自启动连接恢复门禁彻底解耦修复Startup Auto-Reconnect Gate Decoupling

  • 彻底修复初始化准备阶段 isPreparing 锁未复位导致开机启动时 100% 误判跳过连接的缺陷。Resolved critical gate lock issue where isPreparing caused startup auto-reconnection to be skipped on boot.
  • 独立定义 canRestorePreviousConnection 门禁，开机自启动后全自动静默秒级恢复隧道连接。Decoupled security gate ensuring fully automatic and silent tunnel restoration upon boot or cold start.

菜单栏低功耗按需刷新与多项性能优化Menu Bar Power Optimization & Performance

  • 动态追踪菜单栏 Popover 弹出与遮挡状态，仅在展示时调度高频遥测轮询，收起时自动休眠，杜绝后台 CPU 浪费。Dynamically observe menu bar popover visibility, suspending telemetry polling when hidden to eliminate background CPU load.
  • TCP 半关闭看门狗机制：为透明代理半关闭流提供 15 秒看门狗超时清理，防止会话悬空与句柄泄漏。15-second watchdog timer for half-closed transparent TCP flows, safely reclaiming orphaned resources.
  • TUN 出站包批量写入：引入线程安全出站缓冲区合并发包，大幅减少内核边界切换与系统调用开销。Thread-safe batched writePackets queueing, boosting packet tunnel throughput.

真机硬件与生产全量自动化回归通过Hardware & Automated Regression Verification

  • 在真实硬件 Apple Silicon Mac mini 上实测静默开机秒级自动重连、主动断开保持断开，全生命周期通过率 100%。Verified silent auto-reconnect and state retention on real Apple Silicon Mac mini with 100% pass rate.
  • 全量本地构建与自动化测试套件（104+ 测试用例）全绿通过，零回归。All product test suites (104+ test cases) passed cleanly with zero regressions.
