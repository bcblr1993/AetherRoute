策略组切换体验与当前组身份呈现重构Native Segmented group bar and active group banner

  • 将代理页顶部策略组切换器改造为 Apple HIG 原生 Segmented 胶囊切换栏，配合平滑弹簧切换动画，彻底解决策略组过多时切换不够直观的痛点。Transform the top proxy strategy group picker into an Apple HIG segmented capsule switcher with smooth spring animations, greatly improving group switching clarity.
  • 在节点列表上方新增当前策略组专属状态卡片，明确呈现当前选中的策略组名、语义图标、调度策略标签（Select / URL-Test / Fallback）及手动切换状态。Add a dedicated active group identity card above the node grid, highlighting the group's name, SF Symbol, routing mode badge, and manual selection state.

测速层级解耦与底库节点诊断专区Decoupled speedtest scopes and diagnostic registry

  • 彻底区分顶层“全部测速”与组内“测试延迟”，在顶层明确标注全局全组测速范围，在组内卡片提供单组专属测速动作，消除操作歧义。Clearly decouple top-level 'Test All Groups' from intra-group 'Test Group Latency', adding explicit scope explanations to remove user confusion.
  • 将“底库节点清单与 Providers”明确更名为“节点解析与协议诊断（底库清单）”，并在展开区补充诊断说明，帮助排查底层节点解析状态与协议参数。Rebrand underlying providers into 'Node Resolution & Diagnostic Registry' with clear contextual guidance for inspecting parser results and protocol details.
  • 完整补充代理页面新增元素的双语国际化词条（Localizable.xcstrings）。Complete bilingual localization for all new proxy view components.

Sparkle 软件更新弹窗重构Sparkle update dialog layout redesign

  • 重塑更新窗口为现代 Apple HIG 双层原生卡片视觉结构，完美自适应浅色与深色外观。Overhaul update alert dialog into a modern Apple HIG dual-layer card structure, adapting seamlessly between light and dark modes.
  • 更新说明分类结构化呈现（新增特性、体验优化、问题修复），顶部直观展示版本号与构建编号药丸徽章。Structure changelog into clear categorized sections (New Features, Improvements, Bug Fixes) with prominent version badges.
  • 构建工具自动化注入排版样式，根除更新弹窗无样式纯文本与排版跳动缺陷。Automate release notes styling pipeline to prevent unstyled text and layout shifts.

  • 在 Tart 虚拟机（macOS 15.0 / arm64）中完成 6 种运行模式矩阵（TUN / 透明代理 × 规则 / 全局 / 直连）全量回归，全部通过（0 failures）。Pass full acceptance matrix across all 6 engine and routing modes in Tart VM with 0 failures.
