AetherRoute 1.0.0

Build 2026091201 · 2026-09-12 · Apple silicon · macOS 15.0+

可信分发承诺：Trusted distribution: 此版本采用 Apple Developer ID 签名并已通过 Apple 公证装订。安装包仅提供经过编译安全强化的原生 arm64 架构二进制，不含第三方捆绑软件或追踪分析代码。 This release is Developer ID signed, notarized by Apple, and stapled. Contains strictly hardened native arm64 Mach-O binaries with zero third-party bundles or tracking analytics.

版本核心特性Highlights

  • 原生 Swift 6 与 SwiftUI 现代化交互，遵循 macOS Sequoia 人机交互指南，完美适配原生深色模式。Native Swift 6 and SwiftUI architecture strictly conforming to macOS HIG with seamless dark appearance integration.
  • 透明代理（Transparent Proxy / Network Extension）与系统级 TUN 双网络引擎，支持规则分流、全局代理与直连模式无缝切换。Transparent Proxy and system TUN dual engines with Rule, Global, and Direct routing modes.
  • 全面支持 12 类现代网络协议（VLESS + REALITY, VMess, Hysteria2, TUIC, Trojan, Shadowsocks, WireGuard, ShadowQUIC 等）。Support for 12 modern protocol families (VLESS, VMess, Hysteria2, TUIC, Trojan, Shadowsocks, WireGuard, etc.).
  • 配置与订阅库采用 Apple 数据保护钥匙串（Keychain）硬件级 AES-GCM 加密，零明文敏感数据外泄风险。Hardware-backed Keychain AES-GCM profile encryption, minimal permissions, zero unnecessary system modifications.
  • 集成原生 Sparkle 2 自动升级引擎，具备 Ed25519 签名与哈希双重强校验。Native Sparkle 2 updater with Ed25519 signature and SHA-256 dual verification.

系统要求Requirements

  • Apple silicon (M1, M2, M3, M4 或后续系列 Mac)
  • macOS 15.0 (Sequoia) 或更高版本
  • 首次开启连接时，系统设置会弹出提示，请按指引允许 AetherRoute 网络扩展组件。无需关闭系统完整性保护（SIP）。macOS prompts for approval of the AetherRoute Network Extension component on first connection. SIP remains fully enabled.
