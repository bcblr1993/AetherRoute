版本亮点Highlights

  • 原生 Swift 6 与 SwiftUI 现代化架构，严格适配 macOS 人机交互指南与原生深色外观。Native Swift 6 and SwiftUI architecture strictly conforming to macOS HIG and dark appearance.
  • 透明代理（Transparent Proxy）与系统级 TUN 双引擎，支持规则分流、全局与直连模式。Transparent Proxy and system TUN dual engines with Rule, Global, and Direct routing modes.
  • 支持 12 类现代网络协议（VLESS, VMess, Hysteria2, TUIC, Trojan, Shadowsocks, WireGuard 等），集成多节点订阅与故障隔离解析。Support for 12 modern protocol families (VLESS, VMess, Hysteria2, TUIC, Trojan, Shadowsocks, WireGuard, etc.) with multi-node subscription and resilient parsing.
  • 数据保护钥匙串 Keychain AES-GCM 硬件级配置加密，零多余权限，不修改系统全局非必要设置。Hardware-backed Keychain AES-GCM profile encryption, minimal permissions, zero unnecessary system modifications.
  • 原生 Sparkle 2 自动更新引擎，具备 Ed25519 签名与 SHA-256 双重验签机制。Native Sparkle 2 updater with Ed25519 signature and SHA-256 dual verification.

系统要求Requirements

  • Apple silicon (M1, M2, M3, M4 或更高芯片)
  • macOS 15.0 (Sequoia) 或更高版本
  • 首次开启连接时，macOS 系统设置会弹出提示以批准 AetherRoute 网络扩展组件。macOS prompts for approval of the AetherRoute Network Extension component on first connection.
