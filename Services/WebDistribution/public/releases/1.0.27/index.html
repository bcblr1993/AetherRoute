AetherRoute 1.0.27

核心修复：Tailscale 虚拟覆盖网络与内核路由冲突彻底根治Permanent Fix for Tailscale Overlay Network & Kernel Route Conflict

  • 移除内核排除路由冲突：深度定位发现用户配置 100.64.0.0/10 自定义分流规则或绕过规则时，macOS Darwin NetworkExtension 的 excludedRoutes 会强制向物理出口网卡（en0）下发静态网关路由，导致内核克隆主机路由劫持 Tailscale utun 流量并中断 SSH 会话。在 PacketTunnelNetworkSettingsPlan 与 PacketTunnelProvider 中增加虚拟覆盖网络识别拦截，杜绝 100.64.0.0/10 及 IPv6 虚拟网段进入内核 excludedRoutes。Prevented 100.64.0.0/10 and IPv6 overlay subnets from entering Darwin NetworkExtension excludedRoutes, preventing the kernel from cloning static host routes to physical interfaces that hijack Tailscale utun traffic.
  • 引擎底层覆盖网络穿透直连：虚拟覆盖网络流量完全交由分流引擎内核规则与无物理网卡强绑定的 Socket 原生出站，确保与 Tailscale 并行时零干扰、毫秒级低延迟通信。Handed overlay traffic entirely to rule-based engine routing and unbounded sockets, ensuring zero-interference, sub-millisecond coexistence with Tailscale.
  • 配置策略安全净化：TunnelManager 启动与运行时自动净化历史遗留覆盖网段配置，保障全生命周期环境一致性。Added automated profile sanitization in TunnelManager to prune legacy overlay subnet entries from bypass policies.

系统扩展在轨平滑升级优化Seamless System Extension In-Place Upgrade

  • 构建版本严格递增：递增构建版本号至 2026092402，确保 Darwin sysextd 在实机环境下精准触发网络扩展热替换，杜绝二进制 hash 校验异常。Bumped build number to 2026092402 to guarantee sysextd cleanly recognizes and upgrades existing system extensions.

虚拟机与物理真机全矩阵验证通过Hardware & VM Matrix Verification

  • Tart 虚拟机 6 维网络矩阵实测：TUN/透明代理 x 规则/全局/直连全部 6 项模式矩阵 100% 通过（aether-diag-1434），测试完成后虚拟机测试文件和记录完成全量自动清理并关机。Verified across all 6 engine and routing matrix permutations in Tart VM (aether-diag-1434) with 100% pass rate and clean post-run teardown.
  • 真实 Apple Silicon Mac mini 硬件实机验证：通过 SSH 远程测试门禁，全量 50+ 项协议与网络性能测试 100% 通过（TCP 吞吐达 7500+ Mbps，UDP 10,000 数据包 0 丢包）；实机部署公证版后，双向 Ping 稳定 0.0% 丢包（22~29ms），Tailscale 与 SSH 连接无缝稳定。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate (TCP 7500+ Mbps, UDP 0 drops); live notarized deployment ping test achieved 0.0% packet loss with completely stable Tailscale and SSH sessions.
