AetherRoute 1.0.13

Build 2026091703 · 2026-09-17 · Apple silicon · macOS 15.0+

热插拔物理网卡检测与自愈恢复Hot-plugged physical uplink detection and self-healing

  • 彻底解决手机热点/Wi-Fi断开、休眠后再插网线导致隧道永久卡在“等待网络恢复”无法自愈的死锁缺陷。Resolve recovery deadlock where disconnecting hotspot/Wi-Fi and plugging in an Ethernet cable left the tunnel permanently stuck in waiting for recovery.
  • 引入 Darwin 底层硬件枚举（if_nameindex()）与 macOS ServiceOrder 系统服务顺序，摆脱沙盒网络扩展处于 reasserting 时 NWPathMonitor 的静默盲区。Introduce Darwin hardware enumeration (if_nameindex()) and macOS ServiceOrder prioritization, bypassing the silent blindspot of sandboxed NWPathMonitor during reassertion.
  • 严格过滤 feth/bridge/utun/vmenet/lo 等虚拟网卡前缀，杜绝 Docker/OrbStack 虚拟接口误选导致的底层内核重置失败。Strictly filter out virtual and container prefixes (feth, bridge, utun, vmenet, lo) to prevent misidentification of Docker/OrbStack interfaces from failing core reset.

宿主级网络恢复硬超时看门狗Host recovery watchdog and auto-healing

  • 为 .recovering 状态增加 45 秒宿主级看门狗（hostRecoveryWatchdogTimeout）。Arm a 45-second host-level recovery watchdog whenever the tunnel enters the recovering state.
  • 若底层网络驱动或扩展发生死锁且超时未恢复，主应用自动无感重启自愈，杜绝人工反复手动断开重连。Automatically perform a graceful reconnect if the system extension remains wedged in recovery, eliminating the need for manual restarts.

配置管理页面原生分组列表重构Profiles page native grouped list redesign

  • 配置页面彻底升级为 Apple 原生分组卡片流，消除信息重复展示与视觉碎片化。Overhaul the configuration profiles view into an Apple-native grouped list, eliminating metadata duplication and visual clutter.
  • 优化活跃与非活跃配置的切换与管理交互，视觉体系更加纯粹现代。Streamline active and inactive profile management with clean, elegant visual hierarchy.

概览连接卡片绝对零高度跳变Zero-layout-shift Hero card and fluid luminous bar

  • 彻底移除连接中的三阶段进度步骤条（“系统授权 -> 扩展启动 -> 协议握手”），锁定 Hero 卡片绝对高度，实现物理级零高度抖动。Completely remove the 3-stage progress step bar to permanently lock Hero card height with absolute zero layout shift regardless of connection duration.
  • 保留流光能量条（ConnectionLuminousBar）与呼吸脉冲光圈（AetherRouteStatusLens），交互沉浸连贯。Preserve the fluid luminous energy sweep bar and ambient breathing status lens for seamless visual feedback.

代理节点原始顺序固化与测速防抖Proxy node order stabilization and speedtest fixes

  • 固化主应用代理节点呈现顺序，严格按照配置文件原始声明排列，彻底消除测速刷新时卡片位置跳动乱序。Anchor proxy node card ordering to follow original configuration declarations, preventing card jumping during latency sweeps.
  • 修复单节点与级联策略组测速刷新超时问题，提升并发测速稳定性。Fix node latency test timeouts and cascade latency updates properly to parent strategy groups.

虚拟机实机全量场景与矩阵测试通过Virtual machine full regression verification

  • 在 Tart 虚拟机（macOS 15.0 / arm64）中完成 6 种运行模式矩阵（TUN / 透明代理 × 规则 / 全局 / 直连）全量回归，全部通过（0 failures）。Pass full acceptance matrix across all 6 engine and routing modes in Tart VM with 0 failures.
  • 物理链路断开 8 秒自愈（test_vm_network_recovery.sh）实机测试通过，秒级完成 coreReset 并恢复 HTTP 204 通畅，双进程零重启。Verify 8-second physical link disconnection self-healing in guest with instant coreReset and zero process restarts.
  • 锁屏与解锁长连接保持（test_vm_sleep_wake_recovery.sh）实机测试通过，双引擎长连接全程零重连（reconnects: 0）。Verify screen lock connection continuity with zero reconnects and seamless keep-alive across both engines.
  • OpenAI、ChatGPT、Codex、Anthropic Claude、Google AI 全部桌面应用与端点 100% 连通通过。Verify 100% pass across all AI desktop applications and API endpoints in both TUN and Transparent Proxy modes.
