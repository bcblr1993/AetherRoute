AetherRoute 1.0.26

Build 2026092401 · 2026-09-24 · Apple silicon · macOS 15.0+

核心引擎虚拟覆盖网络路由绑定穿透修复Core Engine Physical Interface Binding Bypass for Overlay Networks

  • 深度排查并定位 Tailscale 节点在开启代理后不可达的底层根本原因：当分流引擎发起 DIRECT 出站连接时，底层 socket 默认被绑定（IP_BOUND_IF）至主物理出口网卡（如 en0），导致发往 Tailscale utun 虚拟网卡的数据包被内核阻断。Resolved root-cause issue where DIRECT sockets bound to physical network interface (en0) blocked Darwin kernel from routing traffic to Tailscale utun virtual interfaces.
  • 在底层核心引擎中实现覆盖网络地址判定：针对发往 100.64.0.0/10 及 fd7a:115c:a1e0::/48 的连接跳过物理网卡强绑定，使内核正常路由至 Tailscale 虚拟接口，P2P 直连与 SSH 访问完全恢复秒级通畅。Implemented overlay network detection in Core Engine to bypass physical interface binding for Tailscale CGNAT subnet (100.64.0.0/10) and IPv6 overlay (fd7a:115c:a1e0::/48), restoring seamless peer-to-peer and SSH traffic.
  • 内置 Tailscale 协调服务器与 DERP 中继放行规则与 Fake-IP 避让，保障 NAT 打洞与 DERP 回退毫秒级就绪。Injected automated bypass and Fake-IP avoidance for Tailscale and DERP relay infrastructure.

自定义规则安全防护与核心证据链锁定Custom Rule Safety & Core Evidence Synchronization

  • 自定义规则前缀校验防护：阻断 /0 无效掩码输入，杜绝意外生成 0.0.0.0/0 全局捕获规则造成正常网络误拦截。Prevented /0 mask input in custom CIDR rules to avoid accidental 0.0.0.0/0 catch-all rule creation.
  • 核心引擎提交与哈希对齐：锁定核心引擎提交 c23370da96b70e6282f04254b4a93761e2a54fee，同步更新 ProtocolCoreEvidence.json 与 ThirdPartyLicenses.json。Synchronized production core hashes and git commit in ProtocolCoreEvidence.json and ThirdPartyLicenses.json.

虚拟机与物理真机全矩阵验证通过Hardware & VM Matrix Verification

  • Tart 虚拟机 6 维网络矩阵实测：TUN/透明代理 x 规则/全局/直连全部 6 项模式矩阵 100% 通过（aether-diag-1434），测试完成后虚拟机测试文件和记录完成全量自动清理并关机。Verified across all 6 engine and routing matrix permutations in Tart VM (aether-diag-1434) with 100% pass rate and clean post-run teardown.
  • 真实 Apple Silicon Mac mini 硬件实机验证：通过 SSH 远程测试门禁，全量 50+ 项协议与网络性能测试 100% 通过（TCP 吞吐达 7579 Mbps，UDP 10,000 数据包 0 丢包），Tailscale 开启 AetherRoute 实测延迟低至 27ms 稳定畅通。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate (TCP 7579 Mbps, UDP 0 drops), verified fast and stable Tailscale P2P connectivity with AetherRoute running.
