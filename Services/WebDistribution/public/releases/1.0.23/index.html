AetherRoute 1.0.23

物理网络变更通知防抖与动态存储会话复用Network Path Notification Debounce & Dynamic Store Reuse

  • 150ms 聚合防抖：在隧道扩展启动（installNetworkSettings）及网卡物理链路切换时，对网络接口变动事件实施 150ms 防抖归并，彻底终结了高达 220+ 次/秒的 CoreFoundation 事件风暴与内核 IPC 争用。Integrated 150ms DispatchWorkItem debounce on physical path changes, eliminating >220 events/sec CoreFoundation notification storms and system throttling warnings.
  • SCDynamicStore 实例长连接复用：消除了每次网卡事件重复创建与销毁会话的开销，保持低开销的系统配置变更监听。Persistent SCDynamicStore session reuse across interface transitions without reallocation churn.

底层核心 MMDB 内存映射与线程预算收敛Core Engine MMDB Memory Mapping & Bounded Threads

  • MMDB 零拷贝内存映射：底层 GeoIP 库全面迁移至 memmap2 只读内存映射，大幅降低物理堆内存占用，严格满足 iOS 15MB Jetsam 上限并减小 macOS 系统扩展常驻驻留。Migrated GeoIP resolution to zero-copy memory-mapped I/O via memmap2, fulfilling iOS 15MB Jetsam budget constraints and trimming memory footprint.
  • 异步运行时线程收敛：约束 Tokio 运行时工作线程数量，削减无谓的多线程上下文切换与常驻开销。Bounded Tokio runtime worker thread pools to reduce background context switching.

虚拟机与物理真机全矩阵验证通过Hardware & VM Matrix Verification

  • Tart 虚拟机 6 维网络矩阵实测：TUN/透明代理 x 规则/全局/直连全部 6 项模式矩阵 100% 通过（aether-diag-1434），测试后虚拟机测试文件和记录完成全量自动清理。Verified across all 6 engine and routing matrix permutations in Tart VM (aether-diag-1434) with 100% pass rate and clean post-run teardown.
  • 真实 Apple Silicon Mac mini 硬件实机验证：通过 SSH 远程测试门禁，全量 50+ 项协议与网络性能测试 100% 通过（TCP 吞吐达 7490–8264 Mbps，UDP 10,000 数据包 0 丢包）。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate (TCP 7490–8264 Mbps, UDP 0 drops).
