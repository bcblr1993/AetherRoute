AetherRoute 1.0.7

Build 2026091601 · 2026-09-16 · Apple silicon · macOS 15.0+

下载 1.0.7 正式版Download 1.0.7 ReleaseGitHub Release ↗获取 1.0.6 历史版本Get 1.0.6 previous release

断网恢复与生命周期死锁修复Network recovery and lifecycle deadlock fix

  • 修复物理网卡瞬断及恢复耗尽时，Network Extension 进程未能关停核心导致 EngineLifecycleGate 永久死锁的缺陷。Fix a deadlock where PacketTunnelProvider failed to stop the core engine after recovery exhaustion, leaving the lifecycle gate permanently stuck.
  • 启动新会话时主动探测并驱逐残留的僵死引擎实例，自动向底层发送 shutdown 信号并等待优雅降级，防止扩展永久报忙。Actively detect and evict residual running engine instances on new start requests, sending a shutdown signal to prevent permanent lifecycle busy rejections.
  • 增加异常退出自愈与进程重启调度，当扩展进程处于异常状态时自动拉起新进程自愈，无需重启 Mac 机器。Add self-healing process relaunch fallback and crash retirement to restore idle state automatically without requiring a Mac reboot.

虚拟机实机验证Virtual machine verification

  • 在 Apple 芯片 macOS 虚拟机中完成物理链路中断 8 秒自愈恢复测试，进程与数据通道无缝自愈，无重启或崩溃。Verify physical uplink disconnection recovery (8s down) in an Apple silicon VM with zero process restarts and immediate probe recovery.
  • 完成多网卡/IP 别名动态切换与出口地址变更测试，链路保持健康且数据通信无中断。Verify dynamic network adapter handoff with secondary IP alias addition/removal with uninterrupted data path connectivity.

发布说明Release information

  • 此正式包使用正常生产核心，经过 Developer ID 签名及 Apple 公证，不包含 QA 自动连接。This stable package uses the normal production core, is Developer ID signed and Apple notarized, and contains no QA auto-connect.
  • 经维护者授权，在虚拟机详细测试全部通过后发布 v1.0.7 正式版。Authorized by the maintainer for stable release following 100% pass across all virtual machine test suites.
