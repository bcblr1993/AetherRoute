AetherRoute 1.0.24

Build 2026092301 · 2026-09-23 · Apple silicon · macOS 15.0+

用户自定义分流规则与实时语法校验Custom Routing Rules & Real-time Validation

  • 全面支持用户自主添加与管理自定义路由规则，支持 DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD、IP-CIDR、IP-CIDR6 及 GEOIP 六大类型，目标灵活指定 DIRECT、REJECT、PROXY 或节点选择组。Comprehensive custom routing rules supporting DOMAIN, DOMAIN-SUFFIX, DOMAIN-KEYWORD, IP-CIDR, IP-CIDR6, and GEOIP with custom targets (DIRECT, REJECT, PROXY, or proxy groups).
  • 表单向导与 Clash 单行字符串双向解析切换，内置 CustomRuleValidator 实时语法纠错，支持 no-resolve 与注释管理。Dual-mode editing supporting visual form and Clash text line syntax, with real-time field-level validation and syntax error hints.
  • 分流最高优先级与 Fake-IP 穿透保护：自定义规则置于分流链最顶端，直连域名规则自动注入 fake-ip-filter 防止 DNS 劫持。Top priority in routing chain, and direct domain custom rules are automatically injected into fake-ip-filter to bypass DNS hijacking.

自定义规则实测、路由模拟与热重载Live Rule Simulation, Verification & Hot Reload

  • 规则实测与路由模拟：在规则编辑窗中集成一键实测，主界面分流测试引擎实时展示绿色 CUSTOM 徽章与命中详情。One-click rule test in editor and route simulation engine highlighting custom rule matches with distinctive green CUSTOM badges.
  • 零中断热重载（Live Reload）：规则修改与开关切换通过轻量 IPC 管道动态刷新，无需重启网络扩展或断开当前连接。Seamless hot reload via lightweight IPC without restarting network extensions or dropping active connections.

Tailscale CGNAT 直连与私有网络超时根本解决Tailscale CGNAT Bypass & Headscale Timeout Resolution

  • 在内核 TUN 默认直连排除网段中正式加入 100.64.0.0/10（掩码 255.192.0.0），防止内核 TUN 捕获 Tailscale 内网流量。Explicitly added Tailscale CGNAT 100.64.0.0/10 to TUN default excluded routes, preventing kernel packet interception.
  • 预置 Tailscale 官方域及私有 Headscale/DERP 直连放行与 Fake-IP 过滤，彻底消除 Tailscale 与 SSH 远程超时。Built-in direct bypass and Fake-IP avoidance for Tailscale domains, permanently eliminating Tailscale and SSH timeouts.

应用退出生命周期同步优化Application Termination Synchronization Optimization

  • 引入退出前同步清理 prepareForApplicationTermination()，立即取消进行中的健康测量与 URLSession 任务，应用退出耗时从 60s 骤降至 < 0.5s。Introduced synchronous pre-termination cleanup, cancelling in-flight health and probe tasks immediately, cutting exit latency from 60s to < 0.5s.

虚拟机与物理真机全矩阵验证通过Hardware & VM Matrix Verification

  • Tart 虚拟机 6 维网络矩阵实测：TUN/透明代理 x 规则/全局/直连全部 6 项模式矩阵 100% 通过（aether-diag-1434），测试完成后虚拟机测试文件和记录完成全量自动清理并关机。Verified across all 6 engine and routing matrix permutations in Tart VM (aether-diag-1434) with 100% pass rate and clean post-run teardown.
  • 真实 Apple Silicon Mac mini 硬件实机验证：通过 SSH 远程测试门禁，全量 50+ 项协议与网络性能测试 100% 通过（TCP 吞吐达 8032–9670 Mbps，UDP 10,000 数据包 0 丢包）。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate (TCP 8032–9670 Mbps, UDP 0 drops).
