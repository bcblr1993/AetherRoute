原生 macOS 开机自启动深度集成Native macOS Launch at Login Integration

  • 基于 macOS 原生 ServiceManagement (SMAppService.mainApp) 框架构建，遵循沙盒与系统登录项安全规范。Built with native ServiceManagement (SMAppService.mainApp) framework, strictly adhering to macOS sandbox and login items security standards.
  • 在设置面板中提供开机自启动直观切换开关，支持动态感知系统授权状态并提供未批准引导。Provide an intuitive toggle in settings, dynamically reflecting system authorization status with guidance when approval is required.

退出保护与智能连接状态记忆恢复Termination Protection & Smart State Recovery

  • 退出或关机时安全切断 Network Extension 避免系统网络瘫痪，同时锁定连接意图隔离标志，防止清理逻辑误判。Safely disengage Network Extension on quit or reboot to protect OS networking while preserving user connection intent.
  • 应用冷启动或开机自启动就绪后，若退出前为连接状态且满足网络权限则自动秒级恢复连接；若此前为关闭状态则保持关闭。Automatically reconnect on launch if connected before quit; gracefully remain disconnected if previously turned off.
  • 严格区分用户主动操作与系统生命周期断开，记忆状态始终精准体现用户真实意志。Strictly distinguish manual user toggles from lifecycle cleanup, ensuring state memory accurately reflects user intent.

Tart 虚拟机与物理真机双机全生命周期验证Dual-Machine Full Lifecycle Verification

  • 在 Tart 虚拟机（macOS 15.0 / arm64）中完成连接退出保护、冷启动自动重连、主动断开退出及冷启动保持断开 4 大全链路自动化测试，100% 通过。Automated tests across all 4 lifecycle scenarios passed 100% in Tart VM.
  • 通过 SSH 在真实 Apple Silicon 硬件设备（Mac mini）上执行实机闭环联调，对齐正式签名与扩展权限，全量测试验证 100% 通过。Physical hardware validation on Apple Silicon Mac mini completed with 100% pass rate.
  • 包含单元测试（ConnectionIntentStoreTests）与回归测试在内的 104+ 测试用例全部通过。All unit and regression test suites (104+ test cases) passed with zero failures.
