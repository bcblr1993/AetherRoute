TUN 与透明代理底层平滑热切与 UI 连贯切换Seamless engine handover and visual continuity

  • 实现底层平滑交接（performSeamlessNetworkEngineHandover），新旧引擎交替期间先激活目标引擎、就绪校验后再优雅停止原引擎，保护活跃网络会话。Implement seamless network engine handover by pre-activating the destination engine and verifying readiness before gracefully stopping the prior engine.
  • 在引擎切换全过程中拦截瞬态断开通知，界面与状态栏始终保持“已连接”状态，连通计时器与状态指示灯连贯不重置。Intercept transient disconnection states during handover to keep UI and menu bar in a continuous connected state without resetting timers.
  • 引入切换防重入锁定（isSwitchingEngine）与异常降级回滚保障机制（attemptRollbackToEngine）。Add re-entrancy switching guard (isSwitchingEngine) and automatic rollback fallback (attemptRollbackToEngine).

长时间休眠唤醒网络自愈与核心重置Long-sleep wake recovery and core connection reset

  • 深度修复系统长时间休眠（10小时+）唤醒后，外部网络畅通但网页打不开、应用更新过慢的故障。Resolve browser stalls and sluggish updates after extended sleep (10+ hours) by actively resetting core connection state on wake.
  • 在 macOS 唤醒自愈链中主动重置底层核心连接状态与套接字池，消除静默半开连接与陈旧缓存。Schedule active core reset and socket pool refresh in the macOS wake recovery path to clear stale sockets and broken state.

规则管理页面视觉重构与路由模拟测试器Rules page redesign and route simulation tester

  • 全面升级规则管理页面为现代卡片流与层级视觉体系，呈现直观的类型胶囊标签、目标匹配值与出站策略动作。Overhaul Rules page with modern card styling, type capsule tags, and clean visual hierarchy.
  • 新增交互式“路由模拟测试器”（Route Simulation Tester），输入目标域名或 IP 地址即可实时推演命中规则详情与最终出站节点。Add interactive Route Simulation Tester to preview matched rules and target outbound groups in real time.
  • 引入快捷多维筛选器（全部 / Proxy / Direct / Reject）与关键词实时过滤，补全 Reject 动作规范本地化。Add action-based filter chips (All, Proxy, Direct, Reject) and real-time search with complete Reject action localization.

概览连接动效重构与菜单栏节点优化Overview transition animation and menu bar optimization

  • 消除连接/断开状态切换时的页面高度瞬态抖动与布局跳跃，重构为流光呼吸 Beacon 指示灯与渐进式诊断面板。Eliminate height jitter during connection state transitions with smooth beacon pulse and progressive diagnostics disclosure.
  • 固化菜单栏节点呈现顺序，严格按照配置文件原始声明排列，不再随选中或测速跳动；优化一级/二级菜单联动呈现。Fix menu bar node ordering to respect original configuration declarations, and streamline two-level menu synchronization.
  • 明确终端代理快捷复制按键文案为“复制代理命令”与“复制清除命令”，避免歧义。Clarify terminal proxy action buttons as Copy Proxy Command and Copy Clear Command to eliminate ambiguity.

虚拟机实机全量回归测试通过Virtual machine full verification

  • 在 Tart 虚拟机（macOS 15.0 / arm64）中完成 6 种运行模式矩阵（TUN / 透明代理 × 规则 / 全局 / 直连）全量回归，全部通过（0 failures）。Pass full acceptance matrix across all 6 engine and routing modes in Tart VM with 0 failures.
  • 物理网络断开 8 秒自愈（test_vm_network_recovery.sh）与网络出口动态切换（test_vm_network_switch.sh）实测通过，进程零重启。Verify 8-second physical link disconnection self-healing and dynamic uplink handoff with zero process restarts.
  • 锁屏与解锁长连接连续性（test_vm_sleep_wake_recovery.sh）实测通过，长连接全程维持零重连（reconnects: 0）。Verify screen lock connection continuity with zero reconnects and seamless keep-alive across both engines.
  • OpenAI、ChatGPT、Anthropic Claude、Google AI 全部端点与真实客户端在代理环境下 100% 连通通过。Verify 100% pass across all AI desktop applications and API endpoints in both TUN and Transparent Proxy modes.
