核心功能与体验演进Core Features & Architecture Evolution

  • 国内与 Apple 加速界面开关：在配置与通用设置中支持随时启用/关闭零配置内存优化引擎，设置即时平滑生效。User-facing toggle for domestic routing optimization in Settings and Profiles, reloading seamlessly on change.
  • 双引擎网络自愈机制统一：透明代理对齐 Packet Tunnel 的系统级 NWPathMonitor 与 SCDynamicStore 监听，Wi-Fi 与手机热点切换时零重启无感自愈。Symmetrical dual-engine physical interface recovery via NWPathMonitor and SCDynamicStore, enabling zero-restart healing across Wi-Fi and hotspot handovers.
  • 规则优化器健壮容错：增强对空配置、空白行、行内注释及畸形规则符号的容错清洗能力。Enhanced fault tolerance for blank lines, comments, and malformed empty items in profile optimization.

核心架构治理与超大对象解耦Architecture Refactoring & Decoupling

  • TunnelManager 领域驱动分拆：保持公共外观 API 不变，将 6,400+ 行单体拆分为 7 个高内聚扩展模块（连接生命周期、扩展注册、配置管理、路由资源、节点选择、流量遥测、并发测速）。Decoupled monolithic TunnelManager into 7 high-cohesion domain extensions while preserving 100% backward API compatibility.
  • UI 视图组件化重构：拆分 ProfilesPageView、RulesPageView 与 DNSPageView，全面推行 DesignSystem 语义 Token 并消除内存强引用循环。Modularized UI into dedicated Profiles, Rules, and DNS page views with DesignSystem tokens and retain cycle prevention.

物理真机硬件与虚拟机矩阵全绿验证Physical Hardware & VM Matrix Verification

  • 真实 Apple Silicon Mac mini 硬件实机验证：系统扩展稳定加载，协议与底层网络流门禁 100% 通过。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate.
  • Tart 虚拟机全模式矩阵（TUN / 透明代理 x 规则 / 全局 / 直连）6 项矩阵验收 100% 通过，0 崩溃 0 失败。Passed all 6 Tart VM matrix configurations across TUN and Transparent Proxy modes with 0 failures and 0 crashes.

Apple 芯片专属底层深度调优与极致能效Apple Silicon M-Series Deep Optimization

  • ARMv8 硬件加解密扩展指令加速：直接调用 M 芯片内部专用 AES 与 SHA 指令流水线，吞吐过程 CPU 负载降低至 0.7% ~ 1.7%。ARMv8 Cryptography Extensions: hardware-accelerated AES and SHA instructions execute directly on-chip, reducing CPU load to 0.7% ~ 1.7%.
  • 异构内核休眠调度与统一内存：折叠菜单栏时 100% 线程进入 mach_msg2_trap 内核深睡，后台静默 CPU 0.0% ~ 0.1%，物理内存 footprint 控制在 ~210MB。Heterogeneous sleep scheduling & unified memory: 100% of threads enter mach_msg2_trap deep sleep when idle, yielding 0.0% ~ 0.1% CPU and ~210MB total memory footprint.
