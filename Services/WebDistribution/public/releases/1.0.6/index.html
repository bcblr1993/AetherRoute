AetherRoute 1.0.6

Build 2026091508 · 2026-09-15 · Apple silicon · macOS 15.0+

菜单栏与实时流量Menu panel and live traffic

  • 全新稍透明的原生玻璃面板与小飞机菜单栏图标，移除重复电源按钮，保留常用功能。A wider native glass panel and paper-plane menu bar icon, with one main connection control.
  • 修复节点名称显示；无搜索的二级节点面板按实测延迟排序，显示完整节点列表。Fix node labels and offer a search-free secondary node panel sorted by measured latency.
  • 前台概览约每秒刷新；无其他实时面板需求时，后台降为每 10 秒刷新。波形按真实时间展示最近 30 秒，并单独显示刷新间隔。Refresh the foreground overview about every second and use 10-second background polling when no live panel needs it. Plot the actual last 30 seconds and label the refresh interval separately.

网络稳定性与退出Network stability and shutdown

  • 网卡未变化时保留健康传输连接，避免 Hysteria2、TUIC、ShadowQUIC、WireGuard 无谓重连和额外握手等待。Preserve healthy pooled transports when the uplink is unchanged, avoiding unnecessary protocol reconnections and handshake delays.
  • 直连 UDP 会话异步解析一次出口网卡，供两个套接字复用，减少重复枚举及探测带来的线程阻塞。Resolve the direct UDP uplink once asynchronously and reuse it across both sockets, reducing repeated scans and worker blocking.
  • 直连模式跳过远程代理健康探测；退出时及时取消轮询、就绪验证和通信等待，并完善 AppKit 退出处理。Skip remote proxy health checks in direct mode, cancel background work and provider-message waits on shutdown, and improve AppKit termination handling.

发布说明Release information

  • 此正式包使用正常生产核心，经过 Developer ID 签名及 Apple 公证，不包含 QA 自动连接。This stable package uses the normal production core, is Developer ID signed and Apple notarized, and contains no QA auto-connect.
  • 维护者已报告完成一轮测试，并授权直接发布、不再追加测试；本次 24 小时稳定性验收跳过。该授权不表示本轮所有独立验收均已通过。The maintainer reported a completed test round and authorized release without additional testing. The 24-hour stability gate is waived for this version; this does not claim that every independent acceptance gate passed.
