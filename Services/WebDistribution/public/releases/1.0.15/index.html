统一主窗口单例生命周期与唤醒体验Unified Singleton Window Lifecycle

  • 彻底解决点击 Dock 与点击菜单栏分别弹出独立面板的体验缺陷，重构主窗口为全局唯一单例生命周期管理。Resolve dual-window duplication between Dock and menu bar by establishing a unified singleton window lifecycle manager.
  • 无论从 Dock 图标、菜单栏菜单、快捷键还是系统通知唤起，始终平滑激活并置顶当前已打开的主窗口面板，杜绝重复创建或窗口叠置。Smoothly activate and front the existing window from Dock, menu bar, shortcuts, or notifications without window stacking or duplicates.

新增隐藏 Dock 仅菜单栏常驻模式Menu Bar Only Mode with Dock Hidden

  • 在设置中新增“隐藏 Dock 图标（仅在菜单栏常驻）”选项，支持将应用转换为 macOS Accessory 模式，满足桌面极简与常驻后台需求。Add "Hide Dock Icon (Menu Bar Only)" preference, converting the app into macOS Accessory mode for a clean, minimalist desktop.
  • 在常驻菜单栏模式下，主窗口关闭后应用仍在后台平稳运行，点击状态栏菜单项可秒级重新唤出完整大面板，体验行云流水。In menu bar only mode, closing the main window keeps the app running seamlessly, and status bar actions instantly restore the main interface.

DNS 页面现代紧凑双列与卡片合并重构Modern Compact Dual-Column DNS Interface

  • 重构宽松冗长的单列纵向布局为标准紧凑双列网格，大幅提升大屏与标准分辨率下的信息密度与视觉精致感。Overhaul spacious single-column vertical layout into a compact dual-column view, greatly improving information density and visual elegance.
  • 将原本分离的“DNS 状态”与“DNS 测试/诊断”卡片深度融合为“DNS 运行时状态与解析诊断”一体化卡片，移除重复多余的操作按钮。Consolidate disparate DNS Status and Test cards into a unified Runtime Status & Resolution Diagnostics card, eliminating redundant buttons.
  • 重新编排基础设置、高级特性与上游服务器列表层级，使得模式选择、劫持防护与加密传输配置一目了然。Restructure basic settings, advanced features, and upstream servers into clear, intuitive tiers.

虚拟机实机全量场景与矩阵测试通过Virtual Machine Full Matrix & Scenario Verification

  • 在 Tart 虚拟机（macOS 15.0 / arm64）中完成 6 种运行模式矩阵（TUN / 透明代理 × 规则 / 全局 / 直连）全量回归，全部通过（0 failures）。Pass full acceptance matrix across all 6 engine and routing modes in Tart VM with 0 failures.
  • 物理链路断开 8 秒自愈（test_vm_network_recovery.sh）实机测试通过，秒级完成 coreReset 并恢复 HTTP 204 通畅，双进程零重启。Verify 8-second physical link disconnection self-healing in guest with instant coreReset and zero process restarts.
  • 锁屏与解锁长连接保持（test_vm_sleep_wake_recovery.sh）实机测试通过，双引擎长连接全程零重连（reconnects: 0）。Verify screen lock connection continuity with zero reconnects and seamless keep-alive across both engines.
  • OpenAI、ChatGPT、Codex、Anthropic Claude、Google AI 全部桌面应用与端点 100% 连通通过。Verify 100% pass across all AI desktop applications and API endpoints in both TUN and Transparent Proxy modes.
