AetherRoute 1.0.22

Build 2026092008 · 2026-09-20 · Apple silicon · macOS 15.0+

活动连接下的配置热重载（Live Profile Reload）无损生效Live Profile Reload Without Connection Drops

  • 直接内存 IPC 载荷传输：彻底移除基于磁盘共享快照文件（pending-reload-snapshot.bin）的旧设计，改用 ProxySelectionProviderRequest.reloadProfile(Data) 直接在内存中传输轻量二进制 PropertyList（5~35 KB），完美契合 iOS/macOS Jetsam 标准（< 128 KB）。Direct in-memory IPC payload transmission over reloadProfile(Data) via binary PropertyList, complying strictly with Jetsam IPC boundaries (< 128 KB).
  • 解决 macOS 跨 UID 沙盒隔离问题：根除了 root 权限系统扩展无法读取用户目录配置的问题，热重载过程无需断开连接、不重建 utun 网卡、不重启进程，实现 TCP 长连接 0 中断。Resolved cross-UID sandbox container isolation on macOS, eliminating tunnel teardown, process restarts, and dropped TCP connections during live profile reload.

跨平台 iCloud 订阅与配置目录同步Cross-Platform iCloud Profile Catalog Sync

  • 端到端加密云端同步：引入 ProfileCloudSyncManager，支持 macOS 与 iOS 设备间通过 iCloud 私有数据库与钥匙串进行配置目录端到端加密同步。End-to-end encrypted profile catalog synchronization between macOS and iOS devices through iCloud Private Database and synchronizable Keychain.
  • 冲突自动解决与状态反馈：内置冲突检测与版本合并机制，支持手动/自动触发同步，并在设置面板提供实时同步状态及详细日志展示。Built-in conflict resolution and automatic version merging, manual sync triggers, and real-time status reporting.

虚拟机与物理真机全矩阵验证通过Hardware & VM Matrix Verification

  • Tart 虚拟机热重载与 6 维矩阵实测：在持续压测流量下热重载 10/10 次 HTTP 200 成功；TUN/透明代理 x 规则/全局/直连全部 6 项模式矩阵 100% 通过；网卡断开 8 秒自愈测试 0 异常。Verified live reload in Tart VM with 10/10 HTTP 200 success, passed all 6 matrix permutations, and verified 8-second network drop recovery.
  • 真实 Apple Silicon Mac mini 硬件实机验证：通过 SSH 远程测试门禁，全量协议与性能指标 100% 通过（TCP 吞吐速率 > 8500 Mbps，UDP 10,000 数据包 0 丢包）。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate (TCP > 8500 Mbps, UDP 0 drops).
