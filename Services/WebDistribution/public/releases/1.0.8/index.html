AetherRoute 1.0.8

Build 2026091602 · 2026-09-16 · Apple silicon · macOS 15.0+

连接中配置管理放宽Unrestricted profile management while connected

  • 放宽连接状态下的配置操作限制：在 TUN/代理运行期间，保护当前正在运行的活跃配置（禁止移除与重命名），同时允许对所有非活跃配置进行重命名、编辑配置或直接移除，无需频繁断开重连。Relax profile restrictions during active connection: the currently active profile remains protected from removal/rename, while all inactive profiles can be renamed, modified, or deleted without disconnecting the tunnel.

代理测速稳定性与性能优化Proxy latency testing stability and performance optimization

  • 彻底修复 Swift 6 Actor 隔离冲突引起的代理测速闪退问题，在 Task 回调与状态分发中严格保证主线程 Actor 隔离安全。Completely eliminate proxy latency testing crashes caused by Swift 6 Actor isolation conflicts, ensuring thread-safe state dispatch.
  • 引入最大 16 并发度的滑动窗口控制，防止批量测速瞬时发起海量并发连接导致文件描述符耗尽或网络扩展流过载。Introduce a 16-worker sliding window concurrency pool to prevent socket exhaustion and packet tunnel stream overload during bulk latency testing.
  • 优化测速探测端点为轻量 HTTP 204 无内容探针，消除多余 TLS 握手耗时，延迟测量结果全面对齐主流代理工具（50ms 级别），并修复 DIRECT 直连节点测速超时（20ms 秒测）。Switch latency probe target to a lightweight HTTP 204 endpoint to eliminate TLS handshake overhead, aligning latency readings to 50ms, and fix DIRECT node timeout with 20ms instant response.
  • 节点列表支持独立的单节点测速，明确区分测速中、已响应、已超时和未测速四种状态，测速过程不干扰其他节点显示。Support independent single-node latency testing with distinct Testing, Responded, TimedOut, and Untested states without UI flickers across peer nodes.

网络波形图平滑重构与 3 秒刷新Smooth traffic waveform and 3-second refresh

  • 主界面网络波形图由高频抖动刷新重构为 3 秒平滑采样与同频渲染，消除视觉顿挫感。Refactor the traffic overview waveform from rapid jittery polling to smooth 3-second sampling and synchronized TimelineView rendering.
  • 引入单调三次 Hermite 样条插值算法，彻底杜绝折线打结与曲线极值过冲，并增加左侧平滑贴底延展。Implement monotone cubic Hermite spline interpolation to eliminate loop knotting and overshoot, with a flat baseline lead-in.

虚拟机实机验证Virtual machine verification

  • 在 Apple 芯片 macOS 虚拟机中完成 v1.0.8 正式包的安装、系统扩展激活、物理网络链路断开 8 秒自愈与网络适配器出口动态切换实测，进程零重启、通道零阻塞。Verify v1.0.8 installation, system extension activation, 8-second physical link severance self-healing, and dynamic network adapter handoff in an Apple silicon VM with zero process restarts and uninterrupted connectivity.
  • 实测连接中非活跃配置重命名与移除、DIRECT 与代理节点单测/全测，所有功能 100% 正常。Verify inactive profile rename/delete while connected, as well as single-node and bulk latency testing in the live environment.
