AetherRoute 1.0.28

Build 2026092501 · 2026-09-25 · Apple silicon · macOS 15.0+

核心修复：Darwin TUN 缓冲区背压与无损退避重试Darwin TUN Socket Buffer Backpressure & Lossless Retry

  • TUN 描述符写入背压弹性重试：在底层 Darwin TUN 描述符写入返回 ENOSPC (28) / ENOBUFS (55) 时，将未消费的数据包放回优先重试队列，并以 2ms 异步退避延时触发消费，消除瞬时高并发吞吐下的静默丢包与连接中断。Implemented lossless retry and 2ms asynchronous backoff when Darwin TUN socket write returns ENOSPC (28) or ENOBUFS (55), preventing packet drop under heavy burst traffic.
  • 探针会话周期动态刷新：健康检查与连通性探针重置时自动新建 URLSession，杜绝长连接复用旧物理出口引发的误判性回滚降级。Recreated fresh URLSession instances upon network switch probe resets, eliminating false-positive fallback rollbacks caused by stale HTTP keep-alive connections.
  • 网络扩展日志防爆优化：将 PacketTunnel 与 TransparentProxy 的频繁网络路径变更状态查询日志从默认日志降级为 .debug，降低长时间运行下的 I/O 与日志系统开销。Demoted high-frequency network path status query logs in network extensions to .debug to eliminate log spam and unnecessary I/O overhead.

虚拟机与物理真机全矩阵验证通过Hardware & VM Matrix Verification

  • Tart 虚拟机 6 维网络矩阵实测：TUN/透明代理 x 规则/全局/直连全部 6 项模式矩阵 100% 通过（aether-diag-1434），测试完成后虚拟机测试文件和记录完成全量自动清理并关机。Verified across all 6 engine and routing matrix permutations in Tart VM (aether-diag-1434) with 100% pass rate and clean post-run teardown.
  • 真实 Apple Silicon Mac mini 硬件实机验证：通过 SSH 远程测试门禁，全量自动化回归测试 100% 通过（TCP 吞吐率达到 10.4 Gbps，UDP 10,000 数据包完整性测试 0 丢包）。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate (TCP throughput reached 10.4 Gbps, UDP 10,000 datagrams 0% drop).
