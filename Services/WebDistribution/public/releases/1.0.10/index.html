AetherRoute 1.0.10

Build 2026091604 · 2026-09-16 · Apple silicon · macOS 15.0+

网络自愈与健康探测增强Network self-healing and health probe enhancements

  • 优化网络恢复机制：当主探测端点不可达时，自动回退到备用探测端点并结合实时接收流量作为恢复依据，杜绝误判。Enhance recovery mechanism with fallback probe endpoints and received traffic evidence when primary probe is unreachable.
  • 保护透明代理与长连接：在同一次网络恢复轮次中避免重复重置透明代理流，保障长连接与高并发流的持续稳定。Avoid repetitive transparent proxy flow resets within the same recovery run to ensure steady long-lived connections.
  • 状态细分与交互优化：在 UI 和菜单栏中将“网络恢复中”与“首次连接”明确区分，网络恢复过程中完整保留连接时长，且断开连接操作随时可用。Distinguish network recovery from initial connection in UI and menu bar, preserving session duration and keeping Disconnect available.

长连接锁屏连续性实机验证Persistent connection screen lock continuity verification

  • 使用单条持久 TCP keep-alive 连接严格验证锁屏与解锁期间连接零中断、零重连与零丢包。Verify zero interruption and zero reconnection during screen lock/unlock using persistent TCP keep-alive connections.
  • 彻底剥离模拟 QA 电源事件与真实锁屏事件的耦合，确保生产环境下锁屏与解锁期间进程零重启、网络零抖动。Decouple simulated QA power events from screen lock to guarantee zero process restarts and zero network jitter in production.

虚拟机实机全量回归Virtual machine full verification

  • 在 Apple 芯片 macOS 虚拟机中完成 v1.0.10 正式包实机部署与系统扩展激活。Verify v1.0.10 installation and system extension activation in an Apple silicon VM.
  • 物理网络断开 8 秒自愈（test_vm_network_recovery.sh）与网络出口动态切换（test_vm_network_switch.sh）实测通过，进程零重启。Verify 8-second physical link disconnection self-healing and dynamic uplink handoff with zero process restarts.
  • OpenAI、ChatGPT、Anthropic Claude、Google AI API 全部 AI 服务端点与公网出口 IP 代理验证 100% 通过。Verify 100% pass across all AI endpoints (OpenAI, ChatGPT, Claude, Google AI) and egress public IP routing.
