锁屏与屏幕休眠持续连接Continuous connection during screen lock and display sleep

  • 修复锁屏与熄屏时隧道自动断开并重新连接的缺陷：解除屏幕锁屏/解锁（com.apple.screenIsLocked / com.apple.screenIsUnlocked）及显示器休眠/点亮对隧道重置的过度绑定。Remove over-broad observers for screen lock/unlock and display sleep that falsely triggered tunnel resets and disconnections.
  • 锁屏与屏幕休眠期间，物理网络与系统状态正常运行，AetherRoute 保持持续连接且零抖动，避免锁屏期间打断文件下载与长连接会话。Keep tunnel and TCP connections continuously active while screen is locked, preserving active downloads and SSH sessions with zero network interruptions.
  • 真实整机物理休眠与唤醒依然保持完整的网络自愈与重连支持，并增加自动化回归测试套件。Retain robust self-healing on real system sleep/wake, backed by the new Tests/RuntimeEnvironment automated test suite.

虚拟机实机验证Virtual machine verification

  • 在 Apple 芯片 macOS 虚拟机中完成 v1.0.9 正式包的安装、系统扩展激活、锁屏/解锁网络持续连通实测，无多余休眠/重连日志流转。Verify v1.0.9 installation, system extension activation, and screen lock continuity in an Apple silicon VM with uninterrupted data path connectivity.
  • 物理网络链路断开 8 秒自愈与网络适配器出口动态切换实测通过，进程零重启、通道零阻塞。Verify 8-second physical link disconnection self-healing and dynamic network adapter handoff with zero process restarts and zero packet blocks.

  • 此正式包使用正常生产核心，经过 Developer ID 签名及 Apple 公证，不包含 QA 自动连接。This stable package uses the normal production core, is Developer ID signed and Apple notarized, and contains no QA auto-connect.
  • 经维护者授权，在虚拟机详细测试全部通过后发布 v1.0.9 正式版。Authorized by the maintainer for stable release following 100% pass across all virtual machine test suites.
