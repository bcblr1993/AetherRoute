菜单栏与节点检索体验升级Menu Bar & Node Search Enhancements

  • 菜单栏 Popover 节点即时搜索：在菜单栏弹窗中集成关键字快速搜索与实时筛选（searchText / isFiltering），支持按节点名与协议快速定位，无需层层翻找。Instant keyword search and live node filtering in the menu bar popover, enabling fast proxy node lookup by keyword or protocol without navigating submenus.
  • 订阅配置自动更新调度周期：新增 1 小时、6 小时、12 小时、24 小时及手动更新周期配置，定时器在后台平滑触发自动拉取与热重载。Configurable subscription refresh schedules (1h, 6h, 12h, 24h, or manual) with persistent storage and scheduled background timer synchronization.
  • 分流规则模拟器一键域名预设：规则测试面板内置 Google、Apple、GitHub、Bilibili 等高频预设标签，一键点选模拟分流决策。Quick preset chips (google.com, apple.com, github.com, bilibili.com) in Rule Simulator for rapid routing decision verification.

页面交互与视觉自适应优化Page Interaction & Responsive Grid

  • 连接页面 Outlet 出口名称自适应拓展：扩大 Outlet 最小与建议列宽（100~320px），结合中间截断与原生 Tooltip 浮窗提示，彻底解决节点名称省略号截断。Expanded Outlet column width with middle truncation and full tooltips in Connections view, eliminating proxy node title clipping.
  • 代理卡片多端自适应网格：微调网格卡片列宽边界（250~380px），适配 13 寸 MacBook 至 32 寸 4K 宽屏显示器。Fine-tuned adaptive proxy card column widths for optimal reading comfort across all display sizes.
  • 配置整行点击极速切换：移除多余的“使用”按钮，点击未激活配置整行即可直接切换激活，交互更加简洁高效。Whole-row click activation for inactive configuration profiles without redundant buttons.
  • 全部断开二次确认防误触：在“全部断开”操作增加原生确认对话框，有效防止误触断开 VPN。Added confirmation dialog to Disconnect All action to prevent unintended tunnel teardowns.

生命周期与网络扩展退出自愈Lifecycle & Extension Clean Exit

  • AppKit 退出响应者链校验修复：遵循 AppKit 响应者规范并显式实现协议代理，安装专用 AppleEvent 退出拦截器，彻底解决自动化与 AppleScript 退出异常。Resolved AppKit responder chain validation failures during Quit AppleEvent handling with dedicated AppleEvent dispatcher.
  • 退出过程防重入保护：退出进行中自动丢弃重复退出信号，防止外部重入打断网络扩展与路由恢复流程。Re-entrancy guards prevent redundant quit events from interrupting graceful network extension teardown.
