Tailscale CGNAT 底层路由冲突彻底根治Tailscale CGNAT Overlay Routing Collision Resolution

  • 深度溯源并解决 macOS Darwin 内核对 NetworkExtension 排除路由（excludedRoutes）的特殊行为：系统会在全局路由表强行添加指向物理网卡默认网关的静态路由（如 100.64/10 -> 10.8.7.254 on en11），导致 Tailscale 虚拟网卡（utun4）的覆盖路由被劫持而产生丢包与超时。Resolved macOS Darwin kernel routing conflict where NEIPv4Settings.excludedRoutes forcibly installs a global static gateway route to physical LAN router, superseding Tailscale interface routes on utun4.
  • 解耦虚拟覆盖网络与内核物理排除网段：正式从 excludedRoutes 移除 100.64.0.0/10 及自定义 CIDR，仅保留 RFC 1918 物理内网网段。Decoupled overlay networks from kernel excludedRoutes, retaining only true physical RFC 1918 LAN routes.
  • 分流引擎内核内置直连保护：Tailscale 流量的直连放行与 Fake-IP 避让交由分流内核（DomesticRoutingOptimizer）处理，内核不再产生冲突静态路由，Tailscale peer 间连接与 SSH 秒级互通无阻。Engine-layer direct rules and Fake-IP avoidance for Tailscale domains without kernel static route interference, restoring instant SSH connectivity.

核心引擎睡眠唤醒时钟健壮性优化Core Engine Sleep/Wake Clock Resilience

  • 单调时钟防 Panic 治理：升级 Clash 核心至提交 7bb5f30，在系统跨周期睡眠唤醒场景下，将所有可能产生负向时钟偏差的 Instant::duration_since 全面替换为 saturating_duration_since，底层杜绝时钟漂移崩溃。Upgraded clash core submodule (7bb5f30), migrating duration_since calls to saturating_duration_since during system sleep/wake transitions to eliminate monotonic clock-skew panics.
  • 协议证据链与许可证哈希对齐：同步更新并锁定 ProtocolCoreEvidence.json 与 ThirdPartyLicenses.json 的核心 SHA-256 哈希值与源码提交点，严格保障供应链完整性与协议证据链闭环。Synchronized production core hashes and git commit in ProtocolCoreEvidence.json and ThirdPartyLicenses.json.

虚拟机与物理真机全矩阵验证通过Hardware & VM Matrix Verification

  • Tart 虚拟机 6 维网络矩阵实测：TUN/透明代理 x 规则/全局/直连全部 6 项模式矩阵 100% 通过（aether-diag-1434），测试完成后虚拟机测试文件和记录完成全量自动清理并关机。Verified across all 6 engine and routing matrix permutations in Tart VM (aether-diag-1434) with 100% pass rate and clean post-run teardown.
  • 真实 Apple Silicon Mac mini 硬件实机验证：通过 SSH 远程测试门禁，全量 50+ 项协议与网络性能测试 100% 通过（TCP 吞吐达 7579 Mbps，UDP 10,000 数据包 0 丢包），Tailscale 连通与 SSH 握手极速无延迟。Verified on physical Apple Silicon Mac mini via remote automated test gate with 100% pass rate (TCP 7579 Mbps, UDP 0 drops), zero Tailscale latency.
