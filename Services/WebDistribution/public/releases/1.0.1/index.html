1.0.1 核心修复与更新日志 (Changelogs)1.0.1 Fixes & Changelog

  • macOS 宿主机网络扩展公证装订全面强化Notarization & Ticket Stapling: 全面强化 Developer ID 签名与 Apple 官方公证票据（Stapled Ticket），彻底修复开启 SIP 的真实 Mac 宿主机上报 “code signature invalid” (OSSystemExtensionErrorDomain 8) 并卸载扩展的问题。Enforced full Apple Notarization and ticket stapling, preventing "code signature invalid" (error code 8) under enabled System Integrity Protection (SIP).
  • 休眠唤醒与网络环境切换自动恢复Sleep-Wake & Interface Recovery: 修复系统在经历长时间睡眠唤醒或 Wi-Fi/有线网卡热插拔切换时，数据平面丢失的问题，实现接口变更后的自愈重建。Auto-recovers TUN data plane routing after long sleep/wake cycles and network interface switching.
  • TUN 模式路由规则与全局代理平滑切换Routing Mode Transitions: 优化 TUN 模式下规则分流与全局模式切换时的节点选择器与 DNS 解析流向，修复全局模式下特定节点连通性延迟问题。Optimized proxy selector and DNS resolution when switching between Rule and Global routing modes.
  • 透明代理流控与会话生命周期稳定性Flow Control & Session Stability: 强化透明代理会话注册表的并发控制与空闲流主动回收，杜绝长时间运行下的内存漂移。Enhanced session registry concurrency and idle flow cleanup to prevent memory drift.
  • 日志隐私脱敏与规范化Sanitized Observability: 统一日志 Subsystem 与分类，自动脱敏订阅链接与敏感凭证，严守隐私安全底线。Unified logging categories with automatic redaction of subscription URLs and credentials.

系统要求Requirements

  • Apple silicon (M1, M2, M3, M4 或后续系列 Mac)
  • macOS 15.0 (Sequoia) 或更高版本
