1.0.1 核心更新日志 (Changelogs)1.0.1 Fixes & Changelog

  • 智能 1 秒实时动态遥测与平滑波形 (方案 B)Smart Realtime Telemetry & Waveform: 概览面板在前台活跃时采用 1 秒高频采样与 30 秒平滑动态双波形跳动；切换至其他页面、窗口最小化或隐藏至托盘时自动降频至 10 秒，极致节省 CPU 与电池能耗。Features 1-second high-resolution telemetry and smooth 30-second live waveforms when foregrounded, automatically throttling to 10 seconds when minimized or hidden to maximize energy efficiency.
  • 全模块视觉体系规范化与物理动效Design System & Motion Standards: 全面统一 AetherVisual 动效节奏，包括 gentleSpring 原生物理弹簧过渡、quickFade 120ms 悬浮高亮微交互、统一卡片与控制项圆角分级，提供丝滑原生 macOS 体验。Standardized visual system and motion tokens including gentleSpring physics, 120ms quickFade hover highlights, and aligned corner radii across all views.
  • 100% 动态多语言本地化闭环Full Dynamic Localization Pass: 彻底重构界面文本体系，全量接入 AppLocalization，覆盖 887 个条目中英双语 100% 匹配，语言切换无需重启即时全量生效。Full dynamic localization across all 887 keys in English and Simplified Chinese, ensuring immediate zero-restart language switching.
  • 侧边栏导航与状态同步优化Sidebar Navigation & State Sync: 重构侧边栏导航项与 NavigationSplitView 交互绑定，彻底修复页面切换时详情区域空白及选中高亮错位的问题。Resolved navigation state desync and detail blanking in NavigationSplitView with unified sidebar tagged navigation.
  • 配置管理操作菜单原生化重构Native Context Menu Overhaul: 将配置卡片操作菜单全面升级为原生高对比度 macOS 菜单，清晰呈现重命名与二次确认移除等关键操作。Replaced popovers with high-contrast native macOS menus for configuration management, renaming, and removal.
  • 休眠唤醒与网卡切换数据平面自愈Sleep-Wake & Interface Recovery: 引入 NetworkRecoveryCoordinator，在长时间睡眠唤醒或 Wi-Fi/有线网卡切换时自动指数退避自愈恢复，杜绝断流空悬。Introduced NetworkRecoveryCoordinator for automatic route convergence and recovery after sleep/wake cycles and network changes.
  • macOS 宿主机网络扩展公证装订全面强化Notarization & Ticket Stapling: 严格执行 Developer ID 签名与 Apple 官方公证票据离线装订（Stapled Ticket），彻底确保开启 SIP 的系统环境中稳定激活运行。Strict Developer ID signing and offline ticket stapling ensuring reliable activation on SIP-enabled systems.
