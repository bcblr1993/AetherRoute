1.0.2 核心更新日志 (Changelogs)1.0.2 Fixes & Changelog

  • 断开连接即时恢复系统网络与 DNSImmediate Disconnect & Network Restoration: 彻底解决在节点失联或网络波动时断开连接出现较长时间无网的问题。系统网络扩展在响应断开时立即向 macOS 卸载路由与虚拟接口，并将后台协议栈退出加入异步线程回收，杜绝因协议引擎等待导致系统网络脱网。Disconnecting now restores system routing and DNS immediately. The Network Extension stop completes without waiting up to ten seconds for protocol unwinding, preventing machine connectivity dropouts when nodes stop responding.
  • 进程级单例引擎生命周期守卫 (Process-Wide Engine Gate)Process-Wide Engine Concurrency Gate: 为 Network Extension 引入全局进程级引擎互斥门禁。在快速重新连接或切换节点时，强制保证同一进程内仅有单例协议引擎实例处于活跃状态，杜绝双引擎并发引起的内存突增、传输冲突与连接取消问题。Added a process-wide gate for the protocol engine lifecycle. Restarts wait for clean engine handoffs or recycle extension processes, ensuring duplicate engines never run concurrently to cause memory bloat or transport collision.
  • 非阻塞节点探活与遥测调度Non-blocking Probes & Telemetry: 针对无响应节点的延迟探活逻辑全面重构，超时探活不再阻塞隧道正常停止、节点切换与遥测队列上报。Latency probes against unresponsive nodes no longer delay tunnel shutdown, proxy selection, or queued telemetry reporting.
  • 真实生效 DNS 解析器感知与透明代理诊断Active Resolver Telemetry & Transparent Proxy Stats: 诊断面板精准显示系统当前实际生效的 DNS 解析器来源，并支持透明代理流式传输诊断与统计导出。Accurately reports active system DNS resolvers in diagnostics and incorporates flow-level telemetry export for transparent proxy operations.
  • 强化公证与安全票据装订Hardened Runtime & Notarization: 采用 Apple Developer ID 签名，集成 Hardened Runtime 与离线装订票据，在 macOS 15 Sequoia 严格安全机制下实现免告警安全启动。Signed with Apple Developer ID, notarized, and ticket-stapled for seamless zero-warning launch under macOS 15 Gatekeeper.
