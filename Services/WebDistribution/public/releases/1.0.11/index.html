AetherRoute 1.0.11

Build 2026091605 · 2026-09-16 · Apple silicon · macOS 15.0+

分层测速语义与自底向上级联聚合Layered latency measurement and cascade aggregation

  • 测速重构为两层显式语义：流式 TCP 握手可达性探测与选中节点真实协议栈 activeLatency 校验，状态栏清晰标识，杜绝虚假通畅展示。Refactor latency measurement into explicit layers: streaming TCP handshake reachability and verified protocol-level active latency.
  • 修复单节点测速完成时未联动触发嵌套策略组自底向上聚合更新的缺陷，保证父级策略组即时呈现子组最佳延迟。Cascade latency aggregation to parent strategy groups upon completing single-node tests to ensure immediate reflection in parent groups.
  • 引入 ProxyLatencyIndex 暂存层，测速记录为 O(1)，发布采用 ~100ms 批量聚合，彻底杜绝多节点测速导致的主线程高频重绘与卡顿。Introduce ProxyLatencyIndex staging with O(1) record cost and ~100ms batched flush, eliminating main-thread UI stutters.

菜单栏终端代理快捷命令联动Menu bar dynamic terminal proxy command

  • 废弃快捷复制中硬编码的 7890 端口，联动读取当前用户实际配置的本地代理端口，同时补充防 DNS 泄露的 socks5h:// 与 NO_PROXY 环境变量。Dynamically link menu-bar shell commands to configured local proxy ports instead of hardcoded 7890, adding socks5h:// and NO_PROXY.
  • 清空命令统一采用标准清理指令，确保环境变量安全还原。Standardize clear commands to safely restore shell environment variables.

虚拟机实机全量回归与场景测试Virtual machine full verification

  • 在 Apple 芯片 macOS 虚拟机中完成 6 种运行模式矩阵（TUN / 透明代理 × 规则 / 全局 / 直连）全量回归，全部通过。Pass full acceptance matrix across all 6 engine and routing modes in an Apple silicon VM.
  • 长连接锁屏连续性实测通过，物理网络断开自愈与网卡动态切换实测通过，进程零重启。Verify screen lock connection continuity, physical link self-healing, and dynamic uplink handoff with zero process restarts.
  • OpenAI、ChatGPT、Anthropic Claude、Google AI 全部端点与真实客户端在代理环境下 100% 连通通过。Verify 100% connectivity and routing for OpenAI, ChatGPT, Claude, and Google AI services.
