AetherRoute 1.0.11

Build 2026091701 · 2026-09-17 · Apple silicon · macOS 15.0+

消除透明代理与 TUN 模式切换死锁Eliminate engine switching deadlocks

  • 重构模式切换逻辑，停止在切换中改写对方配置的偏好设置，彻底消除系统 nehelper 进程锁死与僵死假死问题。Eliminate nehelper deadlocks during mode switching by avoiding destructive preference modifications on opposing managers.
  • 修复 macOS NetworkExtension 强校验拒绝 IPv6 回环路由（::1/128）导致的隧道启动挂起。Fix macOS NetworkExtension rejecting IPv6 loopback route in excluded routes.
  • 引入系统扩展会话级激活缓存与防重入看门狗，切换秒级平滑响应。Add system extension activation caching and non-reentrant state guards for instant mode toggles.

全量节点并发测速与主线程流式防抖High-concurrency latency sweep and UI debouncing

  • 并发探测池提升至 32，TCP 握手超时优化至 1500ms，任务调度至专属并发队列，彻底避免全局 GCD 线程争抢。Boost probe concurrency to 32, optimize timeout to 1500ms, and route tasks to dedicated concurrent dispatch queue.
  • 新增 latencyFlushTask 批量防抖，保证数百上千节点高速测速下 UI 60fps 丝滑渲染，并锁定原始配置节点顺序防止跳动。Introduce latencyFlushTask debouncing for smooth 60fps rendering and lock fixed source node ordering.
  • 分层测速语义：全量流式可达性探测结合当前节点真实协议栈校验，单节点测速自底向上即时联动父级策略组。Layered reachability probes and active protocol verification with bottom-up cascade aggregation.

菜单栏终端代理快捷命令联动Menu bar dynamic terminal proxy command

  • 废弃快捷复制中硬编码的 7890 端口，联动读取当前用户实际配置的本地代理端口，同时补充防 DNS 泄露的 socks5h:// 与 NO_PROXY 环境变量。Dynamically link menu-bar shell commands to configured local proxy ports instead of hardcoded 7890, adding socks5h:// and NO_PROXY.
  • 清空命令统一采用标准清理指令，确保环境变量安全还原。Standardize clear commands to safely restore shell environment variables.

实机与虚拟机全量回归测试通过Physical and VM full verification

  • 在物理机器（Apple M系列）与 Tart 虚拟机中完成 6 种运行模式矩阵（TUN / 透明代理 × 规则 / 全局 / 直连）全量回归，全部通过。Pass full acceptance matrix across all 6 engine and routing modes in physical hardware and Apple silicon VM.
  • 长连接锁屏连续性实测通过，物理网络断开自愈与网卡动态切换实测通过，进程零重启。Verify screen lock connection continuity, physical link self-healing, and dynamic uplink handoff with zero process restarts.
  • OpenAI、ChatGPT、Anthropic Claude、Google AI 全部端点与真实客户端在代理环境下 100% 连通通过。Verify 100% connectivity and routing for OpenAI, ChatGPT, Claude, and Google AI services.
