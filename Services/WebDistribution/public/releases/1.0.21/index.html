后台常驻内存主动回收Background Memory Footprint Trimming

  • 主窗口关闭与最小化内存回收：引入 Darwin malloc_zone_pressure_relief，在窗口隐藏或最小化时主动通知系统收缩虚拟内存分页，物理驻留内存自 ~123MB 回收至 60–90MB。Proactive background memory pressure relief on window closure and miniaturization, reducing physical resident footprint from ~123MB down to 60–90MB.
  • 数据包批处理缓冲预分配：网络发包队列初始化预留容量（reserveCapacity(64)），消除高吞吐网络流量下的数组频繁扩容与内存抖动。Packet tunnel queue capacity pre-allocation to eliminate array reallocation overhead and heap thrashing under burst packet throughput.
