# AetherRoute 快速使用

AetherRoute 首版免费使用，不需要账号或激活码。请自备你信任的订阅、配置文件或节点；应用不提供代理服务。当前支持搭载 Apple 芯片的 Mac，系统要求 macOS 15 或更新版本。

正式安装包须完成项目的发布验收。仓库中的开发预览和标记为 QA 的测试包不代表正式发布。

## 第一次连接

1. 安装正式签名的 DMG，将 AetherRoute 拖到“应用程序”，再从那里打开。
2. 阅读隐私说明。macOS 提示时，在系统设置中允许 AetherRoute 的网络扩展。
3. 打开“配置”，选择“添加订阅”粘贴 HTTPS 订阅地址，或用“导入配置”选择本地文件。没有订阅时也可以手动添加节点。
4. 确认已选中需要使用的配置和节点，点击“连接”。

安装包已包含经过完整性校验的路由规则。即使首次安装时无法访问规则下载站点，连接也能使用内置规则；不需要另外寻找、下载或导入 `Country.mmdb`、`GeoSite.dat`，也不需要下载代理核心。首次准备规则和配置在后台进行。

正常使用保留“规则”模式即可。需要所有适用流量都走所选代理时使用“全局”；“直连”用于暂时不经过代理。在“概览”的“网络引擎”中可以切换透明代理和 TUN，首次使用另一种引擎时 macOS 可能再次要求允许对应扩展。

## 配置与规则更新

订阅更新会联系订阅服务商。订阅内容通过校验后才会替换原配置；更新失败时保留原配置。

路由规则在需要时自动准备，较旧的内置规则可在连接成功后后台更新。更新失败会保留已经校验的可用规则，后台更新不会覆盖你后来手动导入的文件。手动导入、下载和文件状态位于路由规则卡片的“高级选项”中，通常无需使用。

## 遇到连接问题

先确认订阅有效、配置已选中，并在“代理”中切换或测试节点。若 macOS 正在等待扩展授权，完成授权后回到应用重试。

“连接中”可以直接取消。需要排查时，可在“诊断”中导出诊断报告；不要在反馈中附上订阅链接、配置密码或 Apple 账号信息。

## 更新应用

首版使用手动 DMG 更新。先断开连接并退出 AetherRoute，再用新版正式签名应用替换“应用程序”中的旧版。正常替换应用会保留已保存的配置；不要删除应用数据目录。
