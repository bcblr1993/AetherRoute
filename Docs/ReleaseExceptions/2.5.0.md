## 核心特性与优化

1. **多维流量排行榜与连接筛选联动（`Sources/AetherRouteKit/ConnectionTrafficAggregator.swift` & `Sources/AetherRouteApp/ConnectionsPageView.swift`）**
   - 新增 `ConnectionTrafficDimension`（`.application` 按应用、`.host` 按域名/目标、`.outbound` 按策略/节点）、`ConnectionTrafficEntry`、`ConnectionTrafficSummary` 与纯值类型无锁聚合器 `ConnectionTrafficAggregator.summarize(_:dimension:limit:)`。
   - 按各维度实时聚合活跃与历史连接的总流量（`totalBytes`）、上行（`uploadBytes`）、下行（`downloadBytes`）、连接数（`connectionCount`）、活跃连接数（`activeCount`）与占比（`shareOfTotal`），并在「连接」页提供紧凑可视化排行卡片。
   - 支持一键点击任意排行榜条目直接联动「连接」页搜索过滤（再次点击同一条目即清除过滤），遵循 `AetherVisualTokens` 设计规范与完整中英双语本地化。

2. **核心引擎出站代理可重试握手的对冲超时优化（`Core/Engine/clash-lib/src/app/dispatcher/dispatcher_impl.rs`）**
   - 新增 `PROXY_RETRYABLE_ATTEMPT_TIMEOUT = Duration::from_secs(3)` 与 `outbound_connect_attempt_timeout(attempt, attempt_limit)`：当出站代理连接配置了多次重试（`PROXY_CONNECT_ATTEMPTS = 3`）时，前两次可重试握手（`attempt < attempt_limit`）使用 3 秒对冲超时，避免高并发突发（如 60 并发 TLS 握手）下首包偶发丢包时等待整整 10 秒底层 Socket 超时后才触发第 2 次重试导致客户端提前超时；最后一次兜底尝试（`attempt == attempt_limit`）仍保留完整底层超时预算。
