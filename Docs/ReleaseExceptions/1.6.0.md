# v1.6.0 发布验收说明

2026-10-11，功能版本，正式构建 2026101102。新增节点故障转移：每个选择型分组可设为手动、自动最快或故障转移。引擎与系统扩展未改动（核心 `183c120`），实施计划见 `Docs/Plan-1.6.0.zh-CN.md`。

## 变更内容

- **模式**：`ProxySelectionMode`（manual / fastest / failover）。旧版"自动选择最快节点"为开时读作 fastest；切换模式时同时写回旧布尔键，降级后仍自动切换。
- **故障转移**：
  - 首选节点优先，无响应时由最快的可用节点接替。
  - 备用期间每 60 秒扫描一次分组，首选连续 2 次有响应才切回。切回前做 204 验证，失败则回到备用。
- **切换防抖与清理**：
  - 当前节点探测失败后，1 秒后复测同一节点，再失败才切换。
  - 因故障切换时，关闭经过坏节点的连接（`proxyChainMember(坏节点)`）；切回首选时遵守"切换节点时关闭连接"设置。
  - 巡检由 15 秒改为 10 秒。
- **巡检范围**：
  - 连接后所有自动分组都纳入巡检（最多 4 个）。
  - 外部 204 请求只对兜底规则所在分组有意义，其他分组以自身节点探测判断，避免主线路故障时误切其他分组。
- **存储**：首选节点用与选择文件相同的 AES-GCM 信封、独立文件与独立认证用途（`proxy-preferences.v1.json`）。扩展读取的 `proxy-selections.v1.json` 格式与认证数据不变。
- **界面**：
  - 代理页新增模式分段控件、首选/备用中标签、备用提示条、切换记录弹层（仅内存）。
  - 菜单栏与命令面板按模式处理节点点选。
  - 设置新增"节点自动切换提醒"，默认关闭，通知不含任何名称。
- **测试**：
  - 新增 `ProxyFailoverTests` 单元测试、3 项 UI 测试改动或新增。
  - 新增 QA 专用钩子 `AETHERROUTE_QA_SELECTION_MODE`，只编进 QA 构建，正式通道守卫拒绝 QA 构建。
  - 新增真实故障转移端到端脚本 `scripts/test_failover_e2e.sh`。

## 例外说明

1. **故障转移端到端在 VM 而非 Mac mini 上运行**：
   - 正式公证构建不含 QA 钩子，无法无人值守地切换模式、注入测试节点。
   - Mac mini 运行的是维护者的真实配置，不宜改动。
   - 因此真实切换在 VM 克隆上用 QA 构建验证。QA 构建与正式构建源码一致，钩子只负责在连接前设置模式。
   - Mac mini 上执行了标准的真机检查（见上）。
2. **端到端脚本修正**：首轮运行发现三处测试自身问题，均已修正：
   - 探测地址 `www.apple.com` 命中内置的 Apple 直连规则，不经过节点。
   - 基础 VM 保留了上次矩阵结束时的直连模式。
   - 冻结期间被接住的连接在恢复后才写日志，会被误判为"已切回"。
   功能代码未因此修改，修正后两种引擎全部通过。首轮报告保留在 `outputs/failover-e2e-160-try1/`、`-try2/`。
3. **矩阵大请求上传偏慢**：两项 2 MiB 上传约 105 秒（门限内通过），其余 3.7–6.2 秒。服务器均完整收到数据，判定为外部网络（httpbin）波动；1.5.1 也出现过同类慢样本。
4. **应用图标构建顺序**：
   - 首个公证候选与发布 DMG 比 1.5.2 小约 2.2 MB。核查发现包内 `AppIcon.icns` 只有 75 KB（16–256 px），而不是仓库中的 1.39 MB 完整版。
   - 原因：资源目录编译器默认也写同名精简图标，与仓库图标争抢同一路径，结果取决于构建顺序。
   - 修复（`f577417`）：
     - 设置 `ASSETCATALOG_COMPILER_STANDALONE_ICON_BEHAVIOR = none`；Assets.car 中的图标不变。
     - `package_release_dmg.sh` 要求包内图标与仓库文件逐字节一致。
   - 修复后重跑了 `test.sh`，重新构建并公证了候选包，在 Mac mini 上重做了真机检查，然后重新打包。
   - 此改动只影响图标资源，不涉及代码，故 VM 矩阵、UI 测试、端到端测试与性能门禁沿用修复前候选包的结果。旧包保留在 `*-thin-icon` 目录，未发布。
5. **跳过的 UI 用例**：`testSignedNetworkExtensionConnectDisconnectLifecycle`、`testBilingualNavigationResponsiveness`、`testCaptureUIReviewMatrix` 需要显式环境变量才会运行，与历次发布一致。
