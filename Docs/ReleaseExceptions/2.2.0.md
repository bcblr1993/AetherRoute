## 核心特性与架构演进

1. **一等公民链式代理（`dialer-proxy` 与 `relay`）**
   - **配置数据模型与编译器**：在 `CustomOutboundNode`（`Sources/AetherRouteKit/ProfileOverride.swift`）与 `AetherNode`（`Sources/AetherRouteKit/AetherNode.swift`）新增 `dialerProxy: String?`；在 `CustomProxyGroup` 与 `ProfileConfigurationSummary.ProxyGroup`（`Sources/AetherRouteKit/ProfileConfigurationSummary.swift`）新增 `ProxyGroupKind.relay`（`type: relay` 有序跳点链）。在 `ProfileOverrideCompiler`（`Sources/AetherRouteKit/ProfileOverrideCompiler.swift`）实现环路与悬空引用校验（`validateDialerProxyChain`）及 `dialer-proxy` / `relay` 的无损 YAML 编译与反解析。
   - **原生编辑器与代理页可视化**：在 `NativeProfileEditorView`（`Sources/AetherRouteApp/NativeProfileEditorView.swift`）、`ProxyGroupOverrideSheets`（`Sources/AetherRouteApp/ProxyGroupOverrideSheets.swift`）与 `ProxiesPageView`（`Sources/AetherRouteApp/ProxiesPageView.swift`）提供节点级前置代理（`Pre-Proxy (dialer-proxy)`）选择器、`Via <upstream>` 胶囊徽章、有序 `Relay Chain` 策略组增删排序，以及代理页只读多跳路径展示（`A → B → C`），配套完整中英双语本地化（`Sources/AetherRouteApp/Localizable.xcstrings`）。
   - **Rust 双引擎多跳拨号与跳点记录**：在 `OutboundManager::resolve_dialer_proxy_chains`（`Core/Engine/clash-lib/src/app/outbound/manager.rs`）实现带深度与环路保护（`MAX_DIALER_PROXY_DEPTH = 8`）的递归 `dialer-proxy` 装配；更新 `ProxyConnector`（`proxy_connector.rs`）与 `relay::Handler`（`relay/mod.rs`）串联全部中间跳点并完整写入 `Session.hop_chain`。

2. **节点与路由模式切换时的旧节点连接即时驱逐与多跳链路追踪**
   - **全跳点链路追踪与匹配关闭**：在 `Session`、`TrackerInfo`（`tracked.rs`）与 `StatisticsManager`（`statistics_manager.rs`）引入 `hop_chain: Vec<String>`，将遥测连接链格式化为 `Group → Hop1 → Hop2`，并使 `close_connections_by_proxy` 与 `close_connections_excluding_proxy` 匹配 `TrackerInfo.chain` 中的任意跳点（涵盖直连出站、策略组成员、`dialer-proxy` 上游及 `relay` 跳点）。
   - **Hysteria / Hysteria2 持久 QUIC 会话池同步驱逐**：在 `OutboundHandler`、`OutboundManager`、各策略组及 `hysteria2::Handler` / `hysteria::Handler` 实现 `evict_active_sessions`，切换节点时同步清空旧节点缓存的 `Arc<Client>` QUIC 会话池，彻底阻断新开流复用旧节点 QUIC 连接。
   - **Swift 控制面精确收敛**：`ProxySelectionStore.apply` 返回 `previousMember`，在 `TunnelManager+ProxySelection.swift`、`TunnelManager+Failover.swift` 与 `TunnelManager.swift` 中切换节点时同时关闭仍流经 `previousMember` 的连接及当前组内非新选节点的连接；切换至 `Direct` 直连模式时立即驱逐所有非 `DIRECT` 代理连接。
