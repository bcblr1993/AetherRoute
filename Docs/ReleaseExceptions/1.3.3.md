# v1.3.3 发布验收说明

2026-10-08，体验与架构优化版本：全面收敛统一 macOS 原生视觉设计系统（AetherRouteVisualSystem）与 HIG 交互规范；建立标准化的行高阶梯、卡片内边距、行内操作按钮、弹窗底栏、状态消息反馈与开关体系；升级静态设计 Token 守卫与 Reduce Motion 动态效果门禁。

### 验证结论

1. **本地回归**：`test_ui_design_token_guards.sh`、`verify_ui_design_tokens.sh`、`test_motion_guards.sh`、`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全部通过，零编译警告；App 完整构建通过。
2. **物理真机门禁与运行时验证（Mac mini，局域网 100.64.0.3，代替虚拟机）**：公证正式候选包 2026100802 执行 TUN 与透明代理全量测试，空闲复用（6/6）与 2 MiB 上传（6/6）全部通过。
3. **远程门禁**：`test_remote_arm64.sh fast` 在 `100.64.0.3` 上执行通过。

### 例外说明

1. **虚拟机矩阵改在物理真机执行**：因本地 Tart VM 环境不可用，按照发布策略，全量测试矩阵与门禁改在局域网物理设备 Apple Silicon Mac mini (`chenxu@100.64.0.3`) 上执行。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记，发布通道为 `stable`；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），发布打包脚本核查仅含 `AetherRoute.app` 与 `Applications`，卷标为 `AetherRoute 1.3.3`。
