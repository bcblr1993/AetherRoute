# v1.8.0 发布验收说明

2026-10-15，局域网共享代理（Allow LAN）与跨端网络中继大版本，正式构建 2026101505。本版本正式推出局域网共享代理功能，允许处于同一局域网内的其他设备（手机、平板、Windows/Linux PC、虚拟机及开发板）无缝通过本机的 AetherRoute 隧道访问节点代理网络。

## 变更内容

- **局域网共享代理（Allow LAN）核心实现**
  - **核心沙盒与网关架构 (`LANProxyServer`)**：在主应用进程中承载轻量级高并发本地代理服务，规避 Network Extension 严格的 15MB Jetsam 内存上限；由于主应用发起的外部出站连接会被活动状态的 TUN 或透明代理捕获，所有局域网设备流量天然且平滑地享受当前的规则分流与代理加速。
  - **多协议并发监听**：默认监听 Mixed/HTTP（端口 7890，支持 HTTP CONNECT 隧道透传与绝对路径 HTTP GET）及 SOCKS5（端口 7891，支持无认证握手与 TCP/UDP 流量中继）。
  - **精准物理 IPv4 解析器 (`LANAddressResolver`)**：智能遍历系统活跃网络接口，精准提取局域网物理 IPv4 地址（排除 `lo0` 回环、`utun` 隧道、`awdl`、点对点链路等虚拟接口），自动向用户呈现即用型的共享代理地址。
  - **主应用沙盒服务器监听授权**：在 `AetherRoute.entitlements` 与 `AetherRoute.DeveloperID.entitlements` 声明 `com.apple.security.network.server = true`，安全合规地在沙盒内监听外部入站端口；同步升级静态代码签名与权限审计门禁。
  - **系统级网络使用权限声明**：在 `Config/App-Info.plist` 中补充 `NSLocalNetworkUsageDescription`，明确声明局域网服务用途，保障 macOS 系统隐私合规。

- **UI 规范与用户体验交互全面优化**
  - **原地反馈复制按钮 (`LanCopyGuideButton`)**：重构复制指引交互，点击后在按钮内部原地展示 1.6 秒平滑绿色 Checkmark 动画，彻底规避打扰用户的全局浮层与跳跃弹窗。
  - **平滑弹簧动效展开**：设置页面局域网配置详情及菜单栏快捷展开面板严格采用 `AetherVisual.disclosure` 弹性曲线动画，消除展开与收起时的生硬与卡顿。
  - **菜单栏快捷面板无缝集成**：在菜单栏卡片中提供独立直观的「允许局域网」开关卡片，实时同步状态与物理 IP，支持一键点击复制代理配置。
  - **保姆级多端连接指引文档 (`HelpTopics.allowLAN`)**：内置图文详尽的多端教程，覆盖 iOS (Wi-Fi 代理)、Android (WLAN 代理)、macOS (网络代理设置)、Windows 11/10、Linux (环境变量) 及终端 cURL/Git 配置指令。

- **核心自动化测试门禁升级**
  - 新增专用回归门禁 `Tests/AllowLAN/run.sh`，强制集成到 `./scripts/test.sh` 核心发版流水线中；
  - 自动化验证默认安全边界（默认关闭、端口 7890/7891 边界保护）、物理接口地址提取、真实 Socket 代理握手（HTTP CONNECT 隧道透传、HTTP GET、SOCKS5 握手与双向中继）以及向后兼容性与教程完整性。
