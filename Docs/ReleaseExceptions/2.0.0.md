# v2.0.0 发布验收说明

2026-10-31。AetherRoute 2.0.0 重大里程碑版本正式发布。构建 2026103101（stable 通道，Normal Core，引擎 `e1a82c4`）。

## 变更内容

- **现代协议矩阵与协议扩展（M0–M2）**：新增并全面支持 Hysteria v1（含 xplus / auth-str）、ShadowsocksR (SSR) TCP/UDP、VLESS xhttp / httpupgrade、VLESS encryption（`mlkem768x25519plus`）、TUIC v4（token 认证）、Snell v1–v5、sing-mux（`h2mux` / `smux` / `yamux`）、Mieru TCP/UDP、AmneziaWG（Jc/Jmin/Jmax/H1-H4/S1-S2 混淆）、ECH（Encrypted ClientHello，`ech-opts`）。
- **Chrome 152 uTLS 指纹与 ALPS**：客户端 TLS 握手完整模拟 Chrome 152 浏览器指纹，支持 ALPS（Application-Layer Protocol Settings）与混合后量子密钥交换（X25519MLKEM768）。
- **规则引擎、DNS 与嗅探器全覆盖（M3）**：支持全部 37 种 Mihomo 路由规则（含 `SUB-RULE`、`IN-TYPE`、`IN-USER`、`IN-NAME`、`DSCP`、`UID`、`PROCESS-NAME-REGEX`、`PROCESS-PATH-REGEX` 等）；DNS 支持 DoQ（`quic://`）、DoH3（`h3://`、`prefer-h3`）、`direct-nameserver`、`fake-ip-filter-mode`；支持顶级 `sniffer` 流量嗅探器配置。
- **配置导入、分享链接与 UI（M4）**：全面支持 16 种协议及传输选项的双向分享链接导入导出、SIP008 JSON 批量导入、Surge `[Proxy]` 格式解析；手动节点编辑器全量字段升级，提供协议与传输层直观 Badge 显示；提供引擎能力清单预检与订阅协议兼容性报告。
- **真实网络实验室与差分对照（M5）**：`protocol_lab.py` 扩充至 43 个真实节点，覆盖所有新增协议变体，与 Mihomo 逐节点对照结论一致；支持 Xboard / V2Board / SSPanel 订阅语料库容错与回归门禁。

## 例外

### 1. 协议兼容性边界与专有实现说明

- **Hysteria v1 `faketcp`**：macOS 平台系统扩展不允许普通进程创建原生原始套接字（Raw Socket），因此 `faketcp` 模式在配置规范化中安全回退至标准 UDP 传输，并在兼容性报告中明确提示。
- **Snell 服务端**：Snell 协议服务端为专有闭源协议，在实验室与互通门禁中使用 Mihomo 内置兼容服务端监听器进行全协议版本握手与数据透传验证。
- **REALITY MLKEM 协商优化**：REALITY 借用第三方站点握手时，在部分前置 CDN 场景下省略 post-quantum MLKEM 密钥交换以防止触发 HelloRetryRequest (HRR) 导致不必要的往返延迟。
