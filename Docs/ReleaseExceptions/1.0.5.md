## 已有验证

- 正常核心的生产特性测试在宿主机与 VM 中通过；独立 VM 协议矩阵通过。
- QA1503 中 IPv6 hosts 的 AAAA 查询、另一地址族 NODATA 和 IPv6 HTTPS 受控路径通过。
- QA1503 中断网 210 秒及快速链路抖动后的稳定窗口分别 20/20，通过最终连续 10/10 受控请求；恢复初期失败样本保留。
- 完整 VM UI 套件 40 项中 38 项通过；独立签名 NE 用例跳过；响应性用例另行测量。

## 未通过或未完成

- VM 30 分钟 UI 响应性：360 次操作，p95 为 581.574 ms，高于 120 ms。
- 宿主机完整离线空闲采样：窗口打开 RSS 最高 182,681,600 字节，高于 128 MiB；菜单栏状态未超该轮门槛。后续短诊断不能替代正式验收。
- 指定真机的新扩展激活及 Ethernet/Wi-Fi 双向切换未完成。
- 最终冻结源码的 24 小时稳定性、已安装 NE 性能校准及完整安装后验收未完成。
- 宿主机补充 UI 响应性与 Hangs 测量没有完整通过结果；按本次授权停止继续测量。
