# v1.2.1 发布验收说明

2026-10-05，功能版本：订阅显示已用流量与到期时间，快用完或快到期时在 App 内提醒，可选系统通知；支持服务商建议的更新间隔与订阅文件名。路由、网络引擎与两个系统扩展与 1.2.0 相同（引擎未变更）。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全部通过，零编译警告；App 单元测试 387 + 84 + 20 全部通过（新增 7 个）。
2. **协议互通门禁（release）**：5 项全部 PASS（`outputs/interop-1.2.1`）。
3. **物理真机矩阵（Mac mini，局域网 192.168.50.226，代替虚拟机）**：公证正式候选包以 `test_runtime_acceptance.sh` 验收 tun / transparent × rule / global / direct 共 6 个组合，全部通过；空闲复用 6/6、2 MiB 上传 6/6、透明代理 SNI 恢复 3/3。报告见 `outputs/macmini-matrix-1.2.1-2026100502/`。
4. **远程门禁**：`test_remote_arm64.sh fast` 通过（`outputs/test-evidence/remote-arm64-20261005T125710Z-fast`）。

### 例外说明

1. **虚拟机矩阵改在物理真机执行**：按维护者决定，本版本不使用 Tart 虚拟机，6 维矩阵在 Mac mini 上执行（方法同 1.2.0）。
2. **首轮透明代理组合各 1 项失败**：本轮先跑透明代理，当时 TUN 扩展尚未激活到新构建，"tunnel activated" 记为失败；跑完 TUN 组合后重跑三组透明代理全部通过，首轮报告保留为 `acceptance-transparent-*.first-run.txt`。
3. **直连模式的大请求上传耗时约 120 秒**：两种引擎的 direct 组合中，2 MiB 在 1.5 秒内发完、服务器 4–7 秒内返回 HTTP 200，但 httpbin 回传的约 2.8 MB 响应下载极慢，直到 curl 的 120 秒上限。在完全退出 AetherRoute、不经过任何代理时复测，结果相同（150 秒内仅收到 2.5–2.8 MB），判定为当时本地宽带直连 httpbin.org 的网络状况，与本版本无关；经代理的组合为 4.5–10.4 秒。
