# 1.10.1 release exceptions

## A differential run overlapped the TUN physical evidence

While the pipeline collected the TUN receipts on the Mac mini (05:18:33–05:21:42), a Mihomo differential run for the next change (httpupgrade, not part of 1.10.1) used the same Mac mini through `AETHER_DIFFERENTIAL_HOST`. That collection switches the Mac mini's network service, so this rule was broken: nothing else may use the Mac mini during physical evidence.

Impact: the differential run only added proxy traffic through its own engines on loopback ports; it does not touch the system proxy, the tunnel or the network services. All TUN receipts passed (idle reuse, 2 MiB upload in 0.98 s, interface switch recovery 1/2/2/2/1/1 s within the 15 s deadline), and the transparent receipts, collected after the run, passed with similar numbers. The receipts were not re-collected.

The overlapping differential run reported Mihomo failing the WireGuard node, which it passed in the run before; that run's results are discarded and the node is re-checked with the next change.

Rule kept: do not use the Mac mini for any test while `collect_physical_runtime_pair.sh` runs.
