# v1.4.2 发布验收说明

2026-10-10，修复版本，正式构建 2026101001。修复最小窗口下的两处布局溢出，以及自 1.3.3 起失败的 5 项 UI 测试。

## 修复内容

- **连接表**：1.3.0 新增「应用」列后，在 780pt 窗口下六列的理想宽度合计超出表格 79pt，需要横向滚动。按「理想宽度之和放进最窄窗口」的原设计重新分配列宽（理想合计 424pt），时长列保留设计规范要求的 56/60/100 预算。
- **概览「路由模式」「网络引擎」**：长文案下，标题与固定宽度的分段控件重叠，并把页面撑出窗口。原有两档横排（带说明、不带说明）保持不变，新增第三档：控件放不下时移到标题下方。
- **UI 测试**：
  - 预览数据自 1.3.0 起有 3 条连接，行数与时长数量的断言改为 3。「时间戳无效」预览模式下，api.github.com 也改用无效开始时间。
  - 规则页「添加应用」是 SwiftUI 原生菜单，与 Profiles 菜单同属已有的审计误报白名单。规则页审计改用能完整显示页面的窗口，避免审计过程中滚动导致按钮不可点。
  - TUN 本地代理说明后来追加了一句 TUN 提示，断言改为按开头匹配。
  - 审计附件附带问题元素的描述，便于直接定位。
