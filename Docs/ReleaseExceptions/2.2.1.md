# 2.2.1 验收与边界

发布构建：`2026110601`。Rust 核心提交 `bdb88eb7804287ab4cb53c5ca5e2fb1238cb1115`（`bdb88eb`），重点交付 **「新建链式代理」默认分组自动匹配、独立「链式代理」分组兜底展示与自定义策略组归属** 以及 **iCloud 配置同步状态展示与可操作本地化错误指引**。

## 核心修复与改进

1. **「新建链式代理」默认分组归属、独立分组展示与自定义策略组支持**
   - **主分组默认选中（突破 64 节点探测上限）**：在 `Sources/AetherRouteKit/ProfileOverrideSuggestions.swift` 新增 `ProfileOverrideSuggestions.defaultParentGroup(in:excluding:)`，直接基于 `summary.allRules` 解析 `MATCH` 规则目标策略组，不再受 `ProxyConnectionReadinessPolicy.groupsToVerify` 的 `memberCount <= 64` 并发测速上限过滤。在 `ProxiesPageView.swift` 与 `ProxyGroupOverrideSheets.swift` 中，对于成员数超过 64 的订阅主策略组（如 `"赛博云"`），打开「新建链式代理」时自动默认选中该主策略组；切换「加入到」目标分组时自动联动更新 `dialerProxy` 以避免同名自环。
   - **独立「链式代理」分组兜底展示**：更新 `ProfileOverrideCompiler`（`Sources/AetherRouteKit/ProfileOverrideCompiler.swift`）、`ProfileOverride`（`Sources/AetherRouteKit/ProfileOverride.swift`）与 `TunnelManager+ProfileOverrides.swift`，当链式代理的 `parentGroup == nil`（UI 选项重命名为 `"独立「链式代理」分组"` / `"Standalone \"Chained Proxies\" group"`）时，自动在编译后的 YAML 与 JSON 配置中生成顶层 `select` 分组（`"链式代理"` 或冲突回退候选），使历史已保存或新建的独立链式代理在「节点」页立即可见、可选中、可测速、可编辑与可删除。
   - **支持加入自定义策略组与跨级环路校验**：允许 `ChainedProxy.parentGroup` 引用用户新建的自定义策略组（`CustomProxyGroup`），并在 `ProfileOverride.validated()` 中扩展跨级环路检测（防止链式代理加入某个自定义分组，而该自定义分组的父分组又处于该链式代理的 `dialerProxy` 链路上）。

2. **iCloud 配置同步状态清晰化与本地化错误指引**
   - 在 `ProfileCloudSyncManager`（`Sources/AetherRouteKit/ProfileCloudSyncManager.swift`）新增 `ProfileCloudSyncError.accountUnavailable` 并映射常见 `CKError`（未登录 iCloud、网络不可达、空间不足、权限/容器未就绪、限流等）为中英双语可操作提示；同步优化 `ProfileCloudSyncSheet` 与 `ContentView` 的账号状态预检与最近同步状态展示。
