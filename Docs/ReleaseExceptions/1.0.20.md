# v1.0.20 发布验收说明

2026-09-19，按照维护者要求完成 P0 到 P3 全部产品功能与体验优化落地，并经过物理真机及 Tart 虚拟机全量回归测试：

### 核心功能演进与体验落地：

1. **P0 阶段：核心体验与稳定性加固**：
   - **连接页面 Outlet 出口名称完整显示**（`ConnectionsPageView.swift`）：扩大 Outlet 列宽预算（`min: 100, ideal: 160, max: 320`），结合中间截断（`.truncationMode(.middle)`）与原生 Tooltip 悬浮提示（`.help(outlet.localizedTitle)`），彻底消除节点名称省略号截断；
   - **全部断开防误触二次确认**（`ConnectionsPageView.swift`）：为“全部断开”增加原生确认对话框（`confirmationDialog`），避免用户在连接状态下因误触导致 VPN 异常中断；
   - **配置整行点击极速切换**（`ProfilesPageView.swift`）：移除冗余的“使用”按钮，直接支持点击未激活配置行激活，大幅精简交互路径。

2. **P1 阶段：导航与管理效率升级**：
   - **菜单栏 Popover 节点即时搜索**（`AetherRouteApp.swift`）：在菜单栏弹窗中内嵌即时搜索文本框与动态过滤逻辑（`searchText`, `isFiltering`），支持直接通过名称或协议关键字秒级定位目标节点，无需层层展开子菜单；
   - **代理卡片多端自适应网格**（`ProxiesPageView.swift`）：调优自适应网格边界（`min: 250, max: 380`），在 13 寸 MacBook 到 32 寸 4K 外接显示器上均能呈现最佳卡片排版密度；
   - **规则模拟器快速测试预设**（`RulesPageView.swift`）：在 Rule Simulator 中内置常用域名测试标签（`google.com`, `apple.com`, `github.com`, `bilibili.com`），支持一键填充进行分流模拟。

3. **P2 & P3 阶段：国际化全量覆盖与订阅自动更新**：
   - **多语言本地化 catalog 全量覆盖**（`Localizable.xcstrings`）：新增全部相关 UI 词条的完整中英文双语翻译，`verify_localizations.sh` 校验 964 词条 100% 完整覆盖；
   - **订阅配置自动更新调度周期**（`TunnelManager+Profiles.swift` & `ProfilesPageView.swift`）：新增 1h、6h、12h、24h 及手动多档位定时自动拉取间隔，后台定时器平滑调度，配置随时保持最新。

4. **生命周期治理与 AppKit 优雅退出修复**：
   - **AppKit 退出响应者链校验修复**（`AetherRouteApp.swift`）：`AetherRouteApplicationDelegate` 显式遵循 `NSMenuItemValidation` 与 `NSUserInterfaceValidations` 协议，安装专用 AppleEvent 处理器（`kCoreEventClass` / `kAEQuitApplication`），消除 AppleScript 与自动化脚本退出异常；
   - **防重入退出保护**：退出过程中自动屏蔽外部重复退出信号（`terminationReplyPending`, `signalTerminationPending`），确保网络扩展与系统路由平滑撤销后再退出进程。
