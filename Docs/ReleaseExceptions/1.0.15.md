### 核心功能演进与缺陷修复：

1. **单例主面板生命周期保证（`AppWindowManager`）**：
   - 彻底修复点击 Dock 图标与菜单栏同时弹出两个独立主面板的问题；
   - 拦截主窗口关闭信号（`windowShouldClose` 转为 `orderOut` 隐藏），统一调度置顶、反最小化（`deminiaturize`）与按键焦点聚焦；
   - 确保全系统全局始终保持唯一一个主面板。

2. **新增“隐藏 Dock 图标（仅在菜单栏常驻 / 最小化到菜单栏）”模式（`AppDockVisibilityController`）**：
   - 支持动态切换 macOS 原生 `NSApplication.ActivationPolicy`（`.accessory` ⇄ `.regular`）实现实时隐藏或显示 Dock 图标，并持久化于 `UserDefaults`；
   - 在「设置 -> 通用」中新增「Dock 与菜单栏」配置分区及「隐藏 Dock 图标」开关；
   - 隐藏 Dock 图标模式下，支持通过系统菜单栏「打开 AetherRoute」或在启动台、访达、聚焦搜索中点击应用图标唤醒主面板。

3. **“DNS & Fake-IP” 页面 UI 结构全面精简重构（`DNSView`）**：
   - **合并“解析行为”与“TUN 运行时覆盖”**：消除 80% 垂直重复内容，统一在一体化卡片中呈现图标、配置默认说明与运行时切换控件，整合 Hosts 映射；
   - **“上游隐私”与“Fake-IP 防护”双列并排**：左右对称布局，页面纵向高度缩减 30%，默认窗口首屏直览全局核心配置；
   - **优化 `StatePill` 样式**：移除伪按钮质感的系统背景与描边，更新为轻量微透纯色原生 Tag 徽章风格。

4. **代理页面测速按钮去重精简（`ProxiesPageView`）**：
   - 移除了右上角全局「全部测速」按钮，仅保留卡片工具栏内的「测试延迟」按钮，明确单组测速作用域。

### 正式发布规范执行核验：

1. 采用标准生产核心（Normal Core Variant），剥离 QA 自动化测试标记；
2. 主程序（`com.aetherroute.desktop`）及网络扩展（`com.aetherroute.desktop.tunnel`、`com.aetherroute.desktop.transparent-proxy`）均采用 Developer ID 签名与 Hardened Runtime；
3. 通过 Apple Notarization 官方公证（Accepted）并完成票据装订（Stapled）；
4. Sparkle 自动更新清单采用官方专用 Ed25519 密钥签名并经反向验签断言通过；
5. 生成完整 SHA256SUMS 校验清单并发布官网与 GitHub。
