# v1.1.0 发布验收说明

2026-10-01，全应用改为 macOS 26 液态玻璃设计：侧边栏为系统原生液态玻璃侧边栏，卡片、按钮与分段控件为玻璃，内容层保持不透明；代理、DNS、配置、规则、概览与菜单栏面板重做，大数据量页面渲染提速。网络引擎、协议实现与两个网络扩展的代码与 1.0.38 相同。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全部通过。
2. **Tart 虚拟机矩阵（`macos27`，构建 2026100102）**：6 个组合全部通过，含大请求上传、空闲 Keep-Alive 复用与透明代理 SNI 恢复检查；测试后已清理虚拟机临时文件。
3. **物理真机（Apple Silicon Mac mini）**：使用公证候选包实测——TUN 模式 2 MiB 上传 4.1 秒、6 MiB 6.1 秒，空闲 Keep-Alive 复用通过；透明代理模式 2 MiB 3.9 秒、6 MiB 6.1 秒，空闲 Keep-Alive 复用与 SNI 恢复通过；远程回归门禁 `test_remote_arm64.sh fast` 通过。

### 例外说明

- **构建号 2026100101 作废，改用 2026100102**：源码修复后按同一版本号与构建号重建 QA 包，虚拟机中已激活的同版本系统扩展未被替换，矩阵判定"运行中的扩展与安装的候选包不一致"。提升构建号后系统正常替换扩展，6 个组合全部通过。2026100102 与通过远程门禁的源码一致，仅构建号不同。
- **Xcode 26.5 编译错误**：首轮远程门禁在 Mac mini（Xcode 26.5）上编译失败，原因是分段控件的数字宽度辅助函数在主线程方法的闭包中捕获了泛型 `Value` 类型。已移出泛型类型（行为不变），修复后远程门禁通过。
- **首轮虚拟机矩阵 `transparent/rule` 探测超时**：作废构建的首轮矩阵中，该组合仅"出口地址"与 IPv6 探测超时，同组合其余检查（大上传、空闲复用、SNI 恢复）均通过；单独重跑全部通过。正式构建 2026100102 的矩阵中该组合首轮即通过。
- **TUN 全局模式大上传 27 秒**：2026100102 矩阵中 `tun/global` 的 2 MiB 上传耗时 27 秒（其余组合 3.6–4.0 秒），检查判定通过。全局模式下所有流量经代理节点上行，耗时受节点上行带宽影响；Mac mini 实机 TUN 模式 2 MiB 4.1 秒。
- **Mac mini 全套 UI 测试未复跑**：辅助功能审计修复（内容层改为不透明以保证次要文字对比度、页面与设置面板的标识不再被外层容器覆盖、连接开关转圈时仍为按钮）及过时用例更新之后，Mac mini 上的全套 UI 测试运行被维护者中止，按维护者要求直接进入发布门禁。修复已通过本地严格编译、本地化校验、遥测观察与动效守卫，以及本机截图核对（深色与浅色）。下一版本发布前需完整复跑。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记，发布通道为 `stable`；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），已挂载 DMG 逐项核查。
