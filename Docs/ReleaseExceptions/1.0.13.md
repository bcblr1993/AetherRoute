### 核心功能演进与缺陷修复：

1. **热插拔物理网卡检测与网络恢复自愈（`PhysicalUplinkDetector` & `PacketTunnelProvider`）**：
   - 彻底修复手机热点断开、休眠后再插网线导致隧道永久卡在“等待网络恢复”（`.recovering`）的严重死锁缺陷；
   - 引入 Darwin 内核底层硬件枚举 `if_nameindex()` 与 macOS `ServiceOrder` 系统服务顺序加权排序，绕过沙盒网络扩展处于 `reasserting` 时 `NWPathMonitor` 的静默盲区；
   - 引入排他性虚拟/容器网卡前缀过滤（`feth`、`bridge`、`utun`、`vmenet`、`anpi`、`ap`、`awdl`、`lo` 等），彻底防止 Docker/OrbStack 虚拟网卡碰撞误选导致的内核重置失败；
   - 实现确定性路径指纹算法 `pathSignature`，物理链路变更时秒级响应自愈。

2. **宿主级恢复看门狗机制（`TunnelManager`）**：
   - 为 `.recovering` 状态配备 45 秒硬超时看门狗（`hostRecoveryWatchdogTimeout`）；
   - 若系统底层驱动或网络扩展因未知内核异常超时卡死，宿主 App 自动执行平滑重启，保障系统绝对不死锁。

3. **配置管理页面原生分组列表重构（`ProfilesSettingsView`）**：
   - 将配置页面彻底重构为精致的原生分组卡片流，消除信息重复展示与视觉碎片化；
   - 优化活跃/非活跃配置切换交互，提供清爽优雅的现代 macOS 桌面体验。

4. **概览页面 Hero 连接卡片绝对零高度跳变（`ContentView`）**：
   - 彻底移除冗余的三阶段进度步骤条（“系统授权 -> 扩展启动 -> 协议握手”），锁定 Hero 卡片高度，实现绝对零高度跳动；
   - 优化流光能量条（`ConnectionLuminousBar`）与微光呼吸脉冲（`AetherRouteStatusLens`），视觉体验纯粹连贯。

5. **节点默认排序固化与测速防抖（`ProxiesSettingsView`）**：
   - 固化主应用代理节点呈现顺序，严格按照配置文件原始声明排列，彻底消除测速刷新时卡片位置乱跳问题；
   - 优化单节点与策略组测速刷新超时逻辑。
