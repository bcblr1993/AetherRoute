# v1.1.7 发布验收说明

2026-10-04，缺陷修复版本：修复 Shadowsocks UDP 重复发包与 SSH 节点空闲 5 秒断开两个引擎缺陷（引擎 `e3762b0`），并加强协议互通测试（大数据双向、空闲复用、多包 UDP、证书校验负向检查，新增 3 个用例与 8 个 UDP 组合）。其他协议、路由与两个系统扩展的行为与 1.1.6 相同。

### 验证结论

1. **协议互通（debug 与 release 各两轮）**：主矩阵 24 个用例 × 2 轮、证书拒绝 26 次、VLESS REALITY、WireGuard、ShadowQUIC、OpenSSH（含空闲 50 秒）全部通过；引擎回环吞吐量与修复前一致。新增 Shadowsocks 单元测试在旧引擎上失败、修复后通过。
2. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全部通过，零编译警告。
3. **Tart 虚拟机矩阵（`macos27`，构建 2026100403）**：6 个组合一次全部通过；空闲 Keep-Alive 复用 6/6、2 MiB 上传 6/6、透明代理 SNI 恢复 3/3。
4. **物理真机（Apple Silicon Mac mini）**：远程回归门禁 `test_remote_arm64.sh fast` 通过（证据见 `outputs/test-evidence/remote-arm64-20261004T121950Z-fast`）；公证正式候选包在 TUN 与透明代理两种模式下的空闲复用、大请求上传均通过，透明代理 SNI 恢复通过。

### 例外说明

- **真机上传耗时波动**：首轮 TUN 上传 4.7–5.8 秒，较 1.1.6 的 3.5 秒偏慢。在同一台 Mac mini、同一时段交替安装 1.1.6 与 1.1.7 对比，预热后两者一致（1.1.7：3.7–4.4 秒；1.1.6：3.3–3.7 秒），中间一轮两版本均出现 5–20 秒的晚高峰波动；引擎回环吞吐量亦无变化，判定为网络波动，非版本退化。
- **引擎单元测试 `tests::start_and_stop`**：需在 3 秒内从 GitHub 下载 mmdb，网络较慢时超时失败，与本次改动无关；其余 380 个单元测试通过。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记，发布通道为 `stable`；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），发布打包脚本核查仅含 `AetherRoute.app` 与 `Applications`，卷标为 `AetherRoute 1.1.7`。
