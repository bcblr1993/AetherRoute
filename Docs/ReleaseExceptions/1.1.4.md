# v1.1.4 发布验收说明

2026-10-03，修复代理页策略组无法切换，菜单栏面板流量图与概览一致，并把 Mac App Store 渠道纳入常规回归。网络引擎源码（`d9f3952`）、路由与两个网络扩展的数据路径与 1.1.3 相同。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh`（含新接入的 Store 渠道测试）全部通过，零编译警告。
2. **策略组修复**：新用例 `testEveryProxyGroupCanBeOpened` 在修复前于 Mac mini 上稳定失败（探针确认按钮动作从未触发），修复后连续 4 次通过，覆盖宽、窄两种窗口与任意切换顺序；截图核对代理页外观不变。
3. **Mac mini 全套 UI 测试（构建 2026100303）**：43 个用例中 42 个一次通过；配置页右键菜单用例单独复跑 2 次均通过；运行期间本机网络状态未变。
4. **物理真机（Apple Silicon Mac mini）**：公证候选包、两个系统扩展均升级为 2026100303——TUN 模式 2 MiB 上传 3.5 秒，空闲 Keep-Alive 复用通过；透明代理模式 2 MiB 3.7 秒，空闲 Keep-Alive 复用与 SNI 恢复通过；远程回归门禁 `test_remote_arm64.sh fast` 通过。
5. **Tart 虚拟机矩阵（`macos27`，构建 2026100303）**：6 个组合全部通过（`tun/rule` 经单组合复跑）；空闲 Keep-Alive 复用 6/6、2 MiB 上传 6/6、透明代理 SNI 恢复 3/3。

### 例外说明

- **构建号 2026100302 作废**：该构建已通过虚拟机矩阵、真机门禁与真机双模式检查，但 Mac mini UI 测试随后发现策略组无法切换，修复后改用 2026100303 重新走完全部门禁；2026100302 未发布。
- **策略组问题的定位过程**：右侧卡片的液态玻璃（`glassEffect`）在页面级共享 `GlassEffectContainer` 中移动或被替换后，旧的命中区域仍然存在，吞掉了左侧（窄窗口时为上方）策略组按钮的点击。尝试过但未采用：把玻璃画在不参与命中的背景层（截图显示玻璃被合成到内容之上，文字模糊）；再包一层 `GlassEffectContainer`（仅在有持续重绘时生效）；布局变化时重建卡片（窄窗口仍失败）。最终方案为代理页不使用共享容器，并在首帧确定宽窄布局。其他页面仍使用共享容器，其全部 UI 用例通过；同类问题如在其他页面出现，可用同一参数处理。
- **矩阵磁盘预算下调**：`macos27` 被另一项目（AetherFilm 验收）的数据占用到 98%，剩余空间低于矩阵默认的 2 GB 基线。安装实际只需约 100–200 MB，因此全量矩阵以 `AETHERROUTE_VM_MIN_FREE_KB=1048576`、`tun/rule` 复跑以 `524288` 运行；未删除其他项目的数据。
- **`tun/rule` IPv6 探测一次超时**：首轮该组合仅“IPv6 探测完成时间”一项失败（11.3 秒，curl 退出码 35），与 1.1.3 验收中出现过的同类间歇超时一致；单组合复跑 1.3 秒通过，其余检查均通过。
- **透明代理 global 组合上传 17.6 秒**：通过阈值但偏慢；同轮其他组合 3.5–7.0 秒，真机为 3.7 秒。期间宿主机网络与虚拟机负载均有波动。
- **配置页右键菜单用例偶发**：全套运行中一次未找到“重命名…”菜单项，单独复跑 2 次通过；本版本未改动配置页。
- **虚拟机出口固件**：沿用 1.1.3 的宿主机 VMess 固件（`Tests/VMProtocolIntegration/explicit-automatic-failover.yaml` 的仅 IPv4 版本，服务端为宿主机 Clash Verge 自带的 mihomo）。
- **App Store 渠道**：本版本包含 1.1.2 Store 渠道的源码与工具（Store 构建图测试已接入 `test.sh`，Developer ID 守卫拒绝 Store 编译标记），已在 1.1.3 代码上完成 Store 构建图无签名编译；未提交新的 Store 版本，1.1.2 Store 审核仍在进行中。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记，发布通道为 `stable`；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），发布打包脚本核查仅含 `AetherRoute.app` 与 `Applications`，卷标为 `AetherRoute 1.1.4`。
