# v1.1.2 发布验收说明

2026-10-02，修复连接时从菜单栏面板退出卡死，以及主菜单"复制终端代理导出命令"写死端口的问题。网络引擎、协议实现与两个网络扩展的代码与 1.1.1 相同。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh`（含扩展后的应用终止守卫）全部通过。
2. **退出修复**：最小 AppKit 复现程序（`applicationShouldTerminate` 返回 `.terminateLater`、由主线程 Task 回复）在旧写法（主队列块中调用 `terminate`）下卡死、在新写法（run loop perform）下正常退出；终止守卫对旧代码报错。
3. **Mac mini UI 测试**：本地代理复制规则与免费版设置相关用例 2/2 通过。
4. **物理真机（Apple Silicon Mac mini）**：公证候选包、两个系统扩展均已升级为 2026100202——TUN 模式 2 MiB 上传 3.9 秒、6 MiB 7.7 秒，空闲 Keep-Alive 复用通过；透明代理模式 2 MiB 4.7 秒、6 MiB 10.9 秒，空闲 Keep-Alive 复用与 SNI 恢复通过；每次在连接状态下退出应用均正常结束；远程回归门禁 `test_remote_arm64.sh fast` 通过。
5. **Tart 虚拟机矩阵（`macos27`，构建 2026100202）**：5 个组合全部通过；6 个组合的空闲 Keep-Alive 复用、大请求上传（3.7–4.6 秒）与透明代理 SNI 恢复全部通过。

### 例外说明

- **`tun/global` 国内站点探测超时**：矩阵中仅此一项失败（HTTP 000 超时），与 1.1.1 首轮矩阵中同组合同检查项的间歇超时一致；该组合其余检查（大上传、空闲复用、出口地址、Anthropic 可达性）均通过。虚拟机经本机 NAT 与本机自身的 TUN 出网，连通性探测不稳定；本版本未改动网络引擎与扩展，真机双模式全部通过，未阻断发布。
- **未在真机上自动点击菜单栏面板"退出"**：通过 SSH 的 UI 脚本无法访问菜单栏面板窗口，改以最小复现程序验证死锁成因与修复，并在真机上确认连接状态下的正常退出路径。
- **未复跑 Mac mini 全套 UI 测试**：本版本界面改动仅为菜单栏面板菜单中的一行说明文字（面板无 UI 用例覆盖），只运行了与本地代理复制规则相关的用例；1.1.1 全套 42/42 通过。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记，发布通道为 `stable`；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），发布打包脚本核查仅含 `AetherRoute.app` 与 `Applications`。
