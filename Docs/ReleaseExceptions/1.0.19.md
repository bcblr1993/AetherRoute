# v1.0.19 发布验收说明

2026-09-19，完成三个阶段的核心治理、架构重构、自愈统一与发布基线建设：

### 核心功能演进与缺陷修复：

1. **阶段一（P0）：紧急排障与发布基线**：
   - **自动化测试文件竞态与超时防护**：修复 `SignedNEProbe/CancellationTests.swift` 中由于未刷新文件流导致的 JSON 解码竞态，确保测试套件稳健通过；
   - **国内极速分流与 Apple 加速界面开关**：在 Profiles 与 General 设置界面以及 `TunnelManager` 中集成 `DomesticRoutingOptimizer` 运行时开关（`isDomesticRoutingOptimizationEnabled`），支持用户自由控制零配置内存分流策略并即时生效；
   - **Dock 图标与应用生命周期稳定性**：修复隐藏 Dock 图标重启及重开窗口后失效的问题，建立稳健的 `NSApp.setActivationPolicy` 与窗口生命周期同步。

2. **阶段二（P1）：核心架构治理与超大对象解耦**：
   - **`TunnelManager` 领域模型分拆**：保持公共外观 API（Facade）100% 向后兼容的前提下，将原 6,408 行的大单体精简至 1,727 行，分拆出 7 个高内聚的扩展模块：
     - `TunnelManager+ConnectionLifecycle.swift`：连接建立、断开与异常终止生命周期；
     - `TunnelManager+ProviderManagement.swift`：Network Extension 与系统扩展通信及 IPC 交互；
     - `TunnelManager+Profiles.swift`：配置文件导入、激活与热重载；
     - `TunnelManager+RoutingResources.swift`：GeoSite、GeoIP 及国内规则资源管理；
     - `TunnelManager+ProxySelection.swift`：代理节点选择与策略组切换；
     - `TunnelManager+Telemetry.swift`：实时吞吐量与连接统计指标；
     - `TunnelManager+Latency.swift`：节点并发延迟测速与健康检查。
   - **UI 视图模块化与解耦**：
     - `ContentView.swift`（3,064 行 -> 1,708 行）：抽离出 `ProfilesPageView.swift`（1,360 行）；
     - `FeatureViews.swift`（1,850 行 -> 199 行）：拆分出 `RulesPageView.swift`（794 行）与 `DNSPageView.swift`（860 行）。
   - **UI Token 规范化与内存安全性**：消除硬编码颜色与字体，全面采用 `DesignSystem` Token；引入弱引用及退避守卫防止内存泄漏与循环引用。

3. **阶段三（P2）：双引擎网络切换自愈机制统一与容错增强**：
   - **双引擎网络自愈对齐**：在 `TransparentProxyProvider.swift` 中引入系统级 `NWPathMonitor` 和 `SCDynamicStore` 物理网卡出口监听器，对齐 `PacketTunnelProvider` 的路径变更检测逻辑；
   - **统一平滑重置**：检测到物理链路与网卡出口切换（如 Wi-Fi 与手机热点切换）时触发有序平滑重置（`stage=networkRecovery coreReset success`），实现双引擎在网络剧烈切换时零重启无感自愈；
   - **`DomesticRoutingOptimizer` 容错健壮性**：增强对空输入、空白行、行内注释及畸形空规则符号（`- -`, `- ''`, `- ""`）的清洗与归一化过滤。
