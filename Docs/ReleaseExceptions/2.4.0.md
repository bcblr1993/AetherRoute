# 2.4.0 验收与边界

发布构建：`2026110702`。Rust 核心提交 `bdb88eb081eb8594351438d1f78a40f84dc858ab`（`bdb88eb`），重点交付对标 Surge 5 / Clash Verge Rev (Mihomo) / Stash 的四大深度可观测性与配置运维核心特性：**Rule Providers 远程规则集可视化管理、即时刷新与订阅引用检视**、**单连接 6 步分流决策路径追踪（`ConnectionRouteDecisionTrace`）与连接内快捷加规则/定位**、**DNS 交互式解析与 Fake-IP 反向检视测试器（`DNSLookupInspector`）** 以及 **代理页多关键词分词检索与协议/传输层/前置代理筛选**。

## 核心新特性

1. **Rule Providers 远程规则集可视化管理、即时刷新与订阅引用检视（`RuleProviderEngine` & `ProviderConfigurationSummary`）**
   - 在 `Sources/AetherRouteKit/ProfileConfigurationSummary.swift` 扩展 `ProviderConfigurationSummary`，支持同时从 YAML（`rule-providers` / `proxy-providers`）与 JSON（`rule_set`）配置中解析 `behavior`（`domain` / `ipcidr` / `classical`）、`format`（`yaml` / `text` / `mrs`）、`intervalSeconds`、`referencedRuleCount`（被 `RULE-SET` 规则引用的次数）与 `referencedTargets`（引用的策略组/出站目标），并在 `Sources/AetherRouteApp/FeatureViews.swift` 的 `ProviderRow` 中以结构化胶囊徽章展示。
   - 在 `Sources/AetherRouteKit/RuleProviderEngine.swift` 新增 `searchRules(forProviderID:query:limit:)` 与 `inspectSummary(for:)`，通过 `Sources/AetherRouteApp/TunnelManager+RuleProviders.swift` 接入 `RulesView`（`Sources/AetherRouteApp/RulesPageView.swift`），支持添加/编辑/启停 HTTPS 自定义远程规则集、一键单独或批量刷新更新、指定命中的目标策略组/出站，以及弹窗检索预览缓存的规则条目。

2. **单连接 6 步分流决策路径追踪与连接内快捷加规则/定位（`ConnectionRouteDecisionTrace`）**
   - 在 `Sources/AetherRouteKit/ConnectionAndDNSInspector.swift` 新增 `ConnectionRouteDecisionTrace`，对任意实时或历史连接（`ConnectionTelemetry`）自动推演 6 步分流决策链路：`routingMode`（分流模式）→ `hostsResolution`（本地 Hosts 映射）→ `applicationRule`（应用专属分流）→ `customDestinationRule`（自定义目标规则）→ `profileRule`（订阅/规则集匹配）→ `outboundChain`（出站执行链路）。
   - 在 `Sources/AetherRouteApp/ConnectionsPageView.swift` 的连接详情面板（`ConnectionInspector`）新增「分流决策路径（`Route Decision Trace`）」可视化卡片、一键将当前连接的域名/IP/来源应用添加为高优先级自定义规则（已连接状态下自动清理受影响的旧连接流），以及「在规则页定位（`Locate in Rules`）」快捷跳转（自动切至「规则」页、填入路由测试器并滚动高亮命中的规则行）。

3. **DNS 交互式解析与 Fake-IP 反向检视测试器（`DNSLookupInspector`）**
   - 在 `Sources/AetherRouteKit/ConnectionAndDNSInspector.swift` 新增 `DNSLookupInspector`，支持对任意域名或 URL 同时评估：自定义本地 Hosts 映射命中（支持精确匹配、`*.` 单级通配与 `+.` 后缀通配）、当前生效 DNS 解析模式（`Fake-IP` / `Redir-host` / `Normal`）、关联分流规则与目标出站，以及基于 POSIX `getaddrinfo` 的系统实时解析结果（自动识别 IPv4 `198.18.0.0/15` 与 IPv6 `fc00::/18` Fake-IP 地址池并测量毫秒级解析耗时）。
   - 在 `Sources/AetherRouteApp/DNSPageView.swift` 新增「DNS 解析测试（`DNS lookup`）」交互卡片，支持一键测试与复制解析出的 IPv4/IPv6 地址。

4. **代理页多关键词分词检索与协议/传输层/前置代理筛选**
   - 在 `Sources/AetherRouteKit/NodeRegion.swift`（`NodeRegion.filterMembers` / `NodeRegion.matchesSearch`）与 `Sources/AetherRouteApp/ProxyPageNodeOrder.swift`（`ProxyPageNodeOrder.filtered(members:query:protocols:transports:dialers:)`）支持空格多词 AND 组合搜索（可同时匹配国家/地区中英文名称与旗帜、节点名、协议类型、传输层 `ws`/`grpc`/`h2`/`httpupgrade`/`xhttp` 与 `dialer-proxy` 前置代理名称），并在 `Sources/AetherRouteApp/ProxiesPageView.swift` 的 `ActiveProxyGroupView` 中完整接入。
