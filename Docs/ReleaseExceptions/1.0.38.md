# v1.0.38 发布验收说明

2026-10-01，为网络引擎与 DNS 设置加入 App 内帮助说明，完善菜单栏状态提示，概览支持测速当前节点。网络引擎、协议实现与两个网络扩展的代码与 1.0.37 相同。

### 新增

1. **帮助说明**：设置旁的"?"按钮就地弹出通俗说明，底部链接到 AetherRoute 官网。
   - "透明代理还是 TUN？"：概览、菜单栏、设置 › 网络三处可打开，说明两种引擎的区别（本地代理、DNS 覆盖、绕过规则、与 Tailscale 共存）与选择建议；
   - DNS 页：TUN 运行时覆盖、解析模式、IPv6 响应、查询遵循规则、Hosts 映射逐项说明。
2. **概览测速当前节点**：点击出口的延迟胶囊即重新测速当前节点，未测速时显示"测速"按钮（此前该胶囊无点击动作，显示为禁用的灰色）。
3. **菜单栏状态提示**：无配置时提示"尚未导入配置"并提供"添加配置"；连接失败时显示具体原因与"查看详情"，不再只显示"不可用"。
4. **关于页**：加入官网标语与简介，以及官网、本版本更新说明、历史版本、隐私政策、支持与反馈链接。

### 改进

1. **分段控件选中状态**：保留原生半透明样式，选中项前加强调色状态点。原生控件只在 App 处于前台时以强调色绘制选中项，菜单栏面板不会激活 App，此前选中项只是略亮的灰色。
2. **引擎描述通俗化**：首次引导与设置中的引擎说明改为易懂表述。
3. **关于页**不再显示作者署名。

### 修复

1. 菜单栏"复制代理命令"在本机没有代理监听时（透明代理，或 TUN 未开启本地代理）仍可点击；现与设置一致。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全部通过；单元测试 472 个全部通过。
2. **Tart 虚拟机矩阵（`macos27`，构建 2026093006）**：6 个组合全部通过，含大请求上传、空闲 Keep-Alive 复用与透明代理 SNI 恢复检查；测试后已清理虚拟机临时文件。
3. **物理真机（Apple Silicon Mac mini）**：使用公证候选包实测——TUN 模式 2 MiB 上传 6.6 秒、6 MiB 8.7 秒，空闲 Keep-Alive 复用通过；透明代理模式 2 MiB 4.0 秒、6 MiB 6.6 秒，空闲 Keep-Alive 复用与 SNI 恢复通过；远程回归门禁 `test_remote_arm64.sh fast` 通过，门禁前后系统代理、DNS、默认路由与网卡状态一致。

### 例外说明

- **虚拟机矩阵 `transparent/direct` 重跑**：首轮该组合仅"强制门户探测"一项超时（HTTP 000），同组合其余检查（Anthropic 可达、国内直连、SNI 恢复、大请求上传、空闲复用）均通过；单独重跑该组合全部通过，探测 0.25 秒返回 HTTP 204。判定为探测时的网络瞬时超时，引擎代码与 1.0.37 相同。
