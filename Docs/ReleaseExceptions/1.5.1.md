# v1.5.1 发布验收说明

2026-10-11，修复版本，正式构建 2026101003。解决切页卡顿与内存膨胀、长会话按应用流量统计缺口，页面内容对齐 macOS 26 Liquid Glass 设计规范，并新增 UI 性能与内存发布门禁。

## 变更内容

- **内存**：每秒刷新的实时数值（菜单栏面板速率、连接页会话栏、概览大号速率、图表峰值）不再做 `.numericText` 滚动动画。根因经 `leaks --referenceTree` 确认：约 90 MB 被 CoreGraphics 字形缓存（`CGFontCacheGetLocalCache.local_font_cache`）持有，每帧滚动中的数字都被缓存，永不归还。
- **切页卡顿**：字面量 `LocalizedStringKey` 在中文界面下每次排版都重新解析 200 KB 字符串表（实测 1.5 ms/次，约为 `AppLocalization` 的 500 倍），改走 `AppLocalization`；连接表单元格固定行高；去掉页面入场动画；概览模式行以自定义 `Layout` 替代三候选 `ViewThatFits`（原生分段控件只建一次）；分段控件宽度全局缓存；概览图表只有波形逐帧重绘。
- **按应用流量统计**（核心 `183c120`，线格式 ART4 / Flow ABI V7）：记忆表上限 256 → 2048，只淘汰无活跃连接、已上报且最久未变的键；每个键带 incarnation，宿主按代差分，旧代样本忽略，低于水位的新见键只记基线。ART1–3 仍可解码，旧系统扩展不受影响；Flow ABI 导出计数门禁 25 → 26。
- **Liquid Glass**：卡片与设置分组改用系统填充 `AetherVisual.cardFill`，页面与表单按钮改用系统 bordered 样式；侧边栏、菜单栏面板、命令面板保留玻璃；搜索框改为胶囊形。`Docs/Design.md` 同步。
- **门禁与守卫**：新增 `scripts/test_ui_performance_gate.sh` 并写入 AGENTS.md 发布 SOP；`UIResponsivenessProbe` 改为计到主线程完成布局与提交；设计令牌守卫新增字面量本地化键与直接 `.numericText` 两条规则。
- **官网 Appcast**（aethernative-site 分支 `bcblr/sparkle-notes-native-style`，随本次发布合并）：更新说明改为导语 + 按类别着色的渐变图标块，去掉框中框，所有 App 共用。

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh`（含新增守卫与流量统计单元测试）在合并后的代码上全部通过，无编译警告。
2. **12 协议真实互通**：核心 `183c120` 上五组全部 PASS（48 个用例、26 次证书拒绝），日志在 `outputs/interop-20261010T142038Z/`；`verify_protocol_matrix.sh` 通过。
3. **Tart VM 六维矩阵（macos27）**：QA 自动化候选 2026101004 第二轮全量通过，tun / transparent × rule / global / direct 全部 PASS（大请求上传 3.4–7.5 秒、空闲复用、透明代理 SNI 恢复均通过）。报告在 `outputs/vm-acceptance-1.5.1-2026101004-r2/`。
4. **Mac mini 远程门禁**：`test_remote_arm64.sh fast` 通过，证据在 `outputs/test-evidence/remote-arm64-20261010T150140Z-fast/`。
5. **Mac mini 真机（公证正式候选 2026101003）**：透明代理与 TUN 各一轮，空闲 50 秒复用与 2 MiB 上传（6.3 秒 / 4.3 秒）全部通过；实际占用 68 MB / 73 MB。完成后恢复透明代理模式与连接意图。
6. **UI 测试（VM macos27）**：48 项通过、0 项失败，3 项需显式开启的用例按设计跳过，与 1.5.0 持平。证据在 `outputs/ui-vm-1.5.1-2026101003/`。
7. **UI 性能与内存门禁**（Mac mini，Release，实时遥测，两档各 5 分钟）：切页 p95 153 ms、最慢 201 ms；内存中位数 69–70 MB、峰值 74–75 MB、增长 +2 MB，全部在预算内（p95 ≤ 180 ms、最慢 ≤ 300 ms、中位数 ≤ 90 MB、峰值 ≤ 110 MB、增长 ≤ 8 MB）。同条件下 1.5.0 为 p95 226–414 ms、最慢 805 ms、5 分钟内由 75 MB 涨到 212 MB。证据在 `outputs/perf-gate-1.5.1-2026101003/`。
8. **公证**：App 与 DMG 均 Accepted（提交 `72893d3d-f6a8-4e41-ae58-7683189dfa23`、`97a12236-46db-45d0-96bf-37dad69e7cf1`），发布通道 `stable`。

## 例外说明

1. **VM 磁盘**：首轮矩阵因 VM 只剩约 1.5 GB（需 2.2 GB）未能安装。将 Tart 磁盘由 50 GB 扩到 70 GB，删除位于数据容器之后、阻挡扩容的 Recovery 容器，再扩展 APFS 容器，可用空间升至约 6.4 GB。该 VM 此后没有恢复分区，仅影响测试 VM 本身。
2. **QA 构建号**：VM 矩阵需要带 QA 自动化夹具的候选包。首个 QA 包（2026101003）不带夹具且已在 VM 激活同号系统扩展，同号重建不会替换，故 QA 自动化包使用 2026101004；源码与正式构建 2026101003 一致，仅 QA 夹具、诊断版核心与许可证 JSON 不同。正式包、公证与发布均为 2026101003。
3. **矩阵大请求上传**：第一轮矩阵中 tun/direct、transparent/global、transparent/direct 三项大请求上传判为"中断"：服务器已完整收到 2,097,152 字节并返回 HTTP 200，但 httpbin 回传约 2.8 MB 回显时超过 120 秒。同一时段 rule 组合 4–7 秒完成；随后本机直连 httpbin 实测 3.5–4.1 秒；第二轮矩阵六项全部 3.4–7.5 秒通过。判定为外部网络波动，非回归（1.5.0 矩阵也出现过 63 秒的慢样本）。第一轮报告保留在 `outputs/vm-acceptance-1.5.1-2026101004/`。
4. **性能门禁取代 XCUITest 响应性测试**：`testBilingualNavigationResponsiveness` 的测试运行器沙盒在物理机上无法写入证据目录，且其夹具数字静止、探针在首次渲染即停表，从未发现过真实卡顿。由新门禁取代，原测试仍按需开启。
5. **跳过的 UI 用例**：`testSignedNetworkExtensionConnectDisconnectLifecycle`、`testBilingualNavigationResponsiveness`、`testCaptureUIReviewMatrix` 需要显式环境变量才会运行，与历次发布一致。
