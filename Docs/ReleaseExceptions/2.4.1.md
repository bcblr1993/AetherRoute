# 2.4.1 验收与边界

发布构建：`2026110703`。Rust 核心提交 `cbd6a7edef12ccc3a044e12ea1940db68a153872`（`cbd6a7e`），重点交付对标 Surge 5 / Clash Verge Rev (Mihomo) / Stash 的 **5 层本地回环（Loopback `127.0.0.0/8`、`::1`）与 RFC 6761 `localhost` / `*.localhost` 绝对直连防线**，彻底消除全局代理（`Global`）模式、关闭国内直连加速、应用级分流规则或 `*.localhost` 子域名场景下本地流量误走远端代理节点的隐患。

## 核心修复与改进

1. **Layer 1：Rust 核心引擎全模式回环短路（`Core/Engine/clash-lib/src/app/dispatcher/dispatcher_impl.rs`）**
   - 新增 `loopback_destination_must_stay_direct` 与 `select_route_for_session`，在 TCP（`dispatch_stream`）与 UDP（`dispatch_datagram`）分流热路径同时生效：全局代理（`RunMode::Global`）模式下，凡目标地址属于 `127.0.0.0/8`、`::1`、`0.0.0.0`、`::` 或 `localhost` / `*.localhost`，一律短路直走 `DIRECT`，并跳过回环 IP 的 HTTPS SNI 嗅探（`ip_https_destination_needs_sni`）；规则（`RunMode::Rule`）模式下对 `localhost` / `*.localhost` 域名提供底层兜底直连保障。

2. **Layer 2：Rust DNS 与 Fake-IP 零劫持（`Core/Engine/clash-lib/src/app/dns/`）**
   - 在 `dns/mod.rs` 新增 `is_loopback_or_unspecified_ip` 与 `is_rfc6761_localhost`。
   - `FakeDns::should_skip`（`dns/fakeip/mod.rs`）对 `localhost` 与 `*.localhost` 始终返回 `true`（永不分配 `198.18.0.0/15` / `fc00::/18` Fake-IP），即便用户自定义配置覆盖了 `fake-ip-filter` 也不受影响。
   - `Config::parse_hosts`（`dns/config.rs`）默认注入 `"localhost"` 与 `"+.localhost"` -> `127.0.0.1` 映射，`SystemResolver`（`dns/resolver/system.rs`）对 `localhost` / `*.localhost` 直接返回 `127.0.0.1` / `::1`，零上游 DNS 泄漏。

3. **Layer 3：最高优先级回环保护规则与全开关覆盖（`Sources/AetherRouteKit/DomesticRoutingOptimizer.swift`）**
   - 拆分 `loopbackProtectionRules`（`DOMAIN,localhost,DIRECT`、`DOMAIN-SUFFIX,localhost,DIRECT`、`IP-CIDR,127.0.0.0/8,DIRECT,no-resolve`、`IP-CIDR6,::1/128,DIRECT,no-resolve`），在 `rules:` 最顶端（第 1 优先级，位于 `AETHER-APP` 应用分流规则、用户自定义规则与远程规则集之前）注入，确保即使将 `curl`、浏览器或 IDE 设为进程走代理，访问本地回环服务依然 100% 直连。
   - 新增 `enableDomesticDirect: Bool = true` 参数，并更新 `TunnelManager.swift`、`TunnelManager+Profiles.swift` 与 `TransparentProxyProvider.swift`，即使关闭「国内流量直连加速」仍强制注入 `loopbackProtectionRules` 与 `fake-ip-filter`（含 `+.localhost`、`+.local`、`+.lan`、`+.localdomain`）。

4. **Layer 4 & 5：系统扩展级豁免与 UI 路由测试器 / 6 步分流决策路径对齐**
   - `TransparentProxyProvider.makeNetworkSettings` 默认排除 `"localhost"` 与 `"local"` 主机后缀，系统内核直接放行本地流量。
   - `RouteMatchEngine`（`Sources/AetherRouteKit/ProfileConfigurationSummary.swift`）与 `ConnectionRouteDecisionTrace`（`Sources/AetherRouteKit/ConnectionAndDNSInspector.swift`）新增内建回环直连评估（`BUILT-IN (127.0.0.0/8, ::1, localhost -> DIRECT)`），在规则页路由测试器与连接详情 6 步分流决策卡片中无论处于规则或全局模式均准确显示 `DIRECT`。
