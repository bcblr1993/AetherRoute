# v1.1.6 发布验收说明

2026-10-04，功能版本：规则资源（Country.mmdb、GeoSite.dat）改为连接期间每周自动检查更新，先比对上游 SHA-256，未变化不重复下载；“下载并校验”在连接中可用，新数据下次连接生效。路由、网络引擎与两个系统扩展的行为与 1.1.5 相同。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全部通过，零编译警告；新增 6 个单元测试（`RoutingResourceRefreshTests`）。
2. **Tart 虚拟机矩阵（`macos27`，构建 2026100402）**：6 个组合一次全部通过，无单组合复跑；空闲 Keep-Alive 复用 6/6、2 MiB 上传 6/6、透明代理 SNI 恢复 3/3。
3. **物理真机（Apple Silicon Mac mini）**：远程回归门禁 `test_remote_arm64.sh fast` 通过（证据见 `outputs/test-evidence/remote-arm64-20261004T051725Z-fast`）；公证正式候选包在 TUN 与透明代理两种模式下的空闲复用、大请求上传均通过，透明代理 SNI 恢复通过。
4. **功能实测**：Mac mini 连接后自动将 29 天前的内置 GeoSite.dat 与 11 天前的 Country.mmdb 更新为上游最新版本，SHA-256 与上游发布的校验值一致。

- 无。虚拟机本次可直接访问外网，未使用宿主机出口固件。

4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），发布打包脚本核查仅含 `AetherRoute.app` 与 `Applications`，卷标为 `AetherRoute 1.1.6`。
