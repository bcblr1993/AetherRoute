# v1.0.8 发布验收说明

2026-09-16，维护者明确要求：

> 1. 连接过程中不能对配置重命名或者移除，当前配置不能修改，但是其他配置可以改，放到下个版本；
> 2. 同样的节点在 Verge 里测试延迟非常低，现在软件测试特别慢；全部测试单独测速在 x2cloud 订阅下崩溃退出；
> 3. 1s 刷新曲线各种不连续且很跳动，改为 3s 刷新让波形平滑连续。

### 核心功能演进与缺陷修复：

1. **连接中配置管理放宽**：
   - **活跃配置受保护**：当前正在连接中使用的配置（Active Profile），依然禁止重命名或移除，避免破坏运行中的网络隧道与状态镜像；
   - **非活跃配置放宽**：处于非活跃状态的配置（Inactive Profiles），在连接状态下允许重命名（`Rename…`）、移除（`Remove Profile`）以及原生节点编辑（`Edit Nodes…`）；
   - **数据一致性安全保障**：移除非活跃配置仅修改 `profiles.v2.json`，不影响 `active-profile.v2.json`，不会向正在运行的 Network Extension 触发不必要的重载，保证网络持续稳定。

2. **代理测速崩溃修复与性能提升**：
   - **消除 Swift 6 Actor Isolation 运行时断言崩溃**：将 `probeTCPLatency` 和 `probeDirectMemberLatency` 标记为 `nonisolated`，消除主线程断言失败导致的 `SIGTRAP` 闪退退出；
   - **引入滑动窗口并发池（maxConcurrent = 16）**：避免大型订阅（如 x2cloud 上百节点）测速时并发打满系统 socket 与定时器资源；
   - **测速端点与延迟优化**：统一切换为免 TLS 1.3 握手的轻量 HTTP 204 端点（`http://cp.cloudflare.com/generate_204`），测速延迟降至 50ms 水平（与 Verge 对齐），DIRECT 直连节点 20ms 秒测通过不再超时；
   - **单节点测速与独立状态保留**：支持单节点独立测试，同组其他节点保持显示已有延迟数值与颜色；完善 Testing / Responded / TimedOut / Untested 四态标签。

3. **网络波形图平滑重构与 3 秒刷新**：
   - **轮询周期调整**：高频遥测轮询周期调整为 3 秒（`activeTelemetryPollingIntervalSeconds = 3`），时间轴刷新频率同步设为 3 秒，消除每秒空跳顿挫；
   - **单调三次样条（Monotone Cubic Spline）**：重构贝塞尔曲线绘制，控制点水平严格单调递增，彻底根除内卷打结回路（Looping Bug），极值切线自动置平杜绝过冲；
   - **平滑贴底延展**：数据不足 30 秒时，在左侧补充零基准线点并向右边缘对齐，消除悬空断层。

在 Tart 虚拟机（`aether-diag-1434`）中完成实机测试与验证，经维护者授权跳过常规 24 小时长时间稳定性浸泡测试，直接执行正式生产构建与发布。
