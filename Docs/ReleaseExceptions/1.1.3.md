# v1.1.3 发布验收说明

2026-10-03，维护版本：修复 macOS 27 上网络引擎从零编译失败，两个网络扩展的兜底分支不再可能崩溃，并为纯 HTTP 代理节点补充自动化回归测试。网络引擎源码（`d9f3952`）与数据路径与 1.1.2 相同。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh`（含新增的 `test_http_node_dial.sh`）全部通过；新测试在节点拒绝凭据时按预期失败。
2. **HTTP 节点**：QA 构建 2026100204 在 `macos27` 虚拟机中以宿主机上的 HTTP 节点为唯一出口，TUN 与透明代理两种模式下连接检查、google.com、github.com、wikipedia.org 均经该节点转发。9 月在 1.0.4/1.0.5 上记录的"HTTP 节点从不拨号"已不再出现。
3. **引擎从零编译**：清空 `.build/core` 后两份静态库均可构建，目标文件的部署版本分布与 1.1.2 完全一致（macOS 14：415 个；Rust 自带 compiler-builtins 的 11.0：375 个）。
4. **物理真机（Apple Silicon Mac mini）**：公证候选包、两个系统扩展均已升级为 2026100301——TUN 模式 2 MiB 上传 3.8 秒，空闲 Keep-Alive 复用通过；透明代理模式 2 MiB 3.8 秒，空闲 Keep-Alive 复用与 SNI 恢复通过；连接状态下退出正常；远程回归门禁 `test_remote_arm64.sh fast` 通过。
5. **Tart 虚拟机矩阵（`macos27`，构建 2026100301）**：6 个组合全部通过（`tun/global` 经单组合复跑）；空闲 Keep-Alive 复用 6/6、2 MiB 上传 6/6、透明代理 SNI 恢复 3/3。

### 例外说明

- **矩阵出口改用宿主机 VMess 固件**：为复现 HTTP 节点问题，虚拟机中 App 的当前配置被替换，原先的真实节点配置为加密存储、无法不经界面切回。矩阵改用仓库自带的 `Tests/VMProtocolIntegration/explicit-automatic-failover.yaml`（两个 VMess 固件，自动选择），服务端为宿主机 Clash Verge 自带的 mihomo，监听 192.168.64.1:59103/59104。
- **第一轮矩阵 13 项失败，均与本版本无关**：
  - 6 项"崩溃报告"：虚拟机中仅有一份 1.1.2 build 2026100203（另一会话的 App Store 构建）因 `Code Signature Invalid` 被系统终止的报告，时间早于本次验证；已备份后移除。
  - 7 项 IPv6 相关（仅 TUN）：上述固件配置开启了 `ipv6: true`，TUN 按配置接管 IPv6 属预期。第二轮改用同一配置的仅 IPv4 版本。
- **第二轮 `tun/global`"主端口兼容 SOCKS"一次返回 000**：同轮 `:7890` HTTP 与 `:7891` SOCKS 均通过，该项在其余 5 个组合及第一轮全部 6 个组合中通过；单组合复跑全部通过。判断为宿主机出口的瞬时超时。
- **第二轮 `direct` 路由上传耗时偏长**（TUN 13.6 秒、透明代理 69.0 秒）：`direct` 路由的上传走宿主机自身出口而非代理；同一构建第一轮分别为 3.6 秒与 3.5 秒，当晚宿主机还出现过 DNS 解析失败、Apple 时间戳服务超时与新增 utun 接口。真机两种模式均为 3.8 秒。
- **真机门禁前两次报"本地源码在门禁期间变化"**：发布工作区（git worktree）中的 `Core/Engine` 起初也是 git worktree，门禁暂存副本复制了其 `.git` 指针文件、与本地共用同一份索引，导致结束时本地清单不一致。改为同一提交的独立克隆后，清单哈希不变（`5d6ce358…`），第三次门禁通过。
- **未采集内存指标**：本版本未改动网络引擎与扩展的数据路径，仅以上传耗时与 1.1.2 对比。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记，发布通道为 `stable`；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），发布打包脚本核查仅含 `AetherRoute.app` 与 `Applications`，卷标为 `AetherRoute 1.1.3`。
