# v1.0.18 发布验收说明

2026-09-18，维护者提出透明无感、国内极速分流与 Apple 服务加速的核心产品要求：

> 要求用户透明无感 国内丝滑 国外走代理

### 核心功能演进与缺陷修复：

1. **零配置透明国内与 Apple 服务加速引擎（`DomesticRoutingOptimizer`）**：
   - 实现无损内存配置优化层（Lossless In-Memory Profile Optimization），在不改写用户磁盘配置的前提下，运行时自动注入国内高优先级直连规则与分流策略；
   - 规则层预置 Apple 专属服务域名列表（`swcdn.apple.com`、`updates.cdn-apple.com`、`appldnld.apple.com` 等）、国内主流应用及 CDN 域名直连规则；
   - 注入高优先级 `GEOIP,CN,DIRECT` 规则，并确保 `MATCH` 或终态规则仍指向用户代理策略；
   - DNS 路由优化：自动将 Apple 及国内域名映射至快速国内上游 DNS（`223.5.5.5`），剥离非兼容前缀；
   - 智能 fake-ip-filter：将 Apple 关键下载服务域名注入 fake-ip 过滤列表，确保其解析为国内真实 CDN Anycast IP，彻底避免 Fake-IP (`198.18.x.x`) 导致直连请求失败或绕道海外，实现线速饱和满速下载；
   - 健壮解析与归一化：支持非缩进列表项（`- name: ...`）、容错处理 `rules` / `rule` / `proxy-groups` 大小写与复数形式。

2. **网络重置与 Wi-Fi 切换自愈防振荡（`TunnelManager`）**：
   - 修复应用层在接收系统网络变化事件时重复调用 `resetNetwork()` 触发 `reasserting` 导致的无限自激振荡死锁；
   - 保留物理网络扩展底层的 `NWPathMonitor` 和 `SCDynamicStore` 路径签名检测机制，实现网络切换秒级无感自愈与稳定收敛。
