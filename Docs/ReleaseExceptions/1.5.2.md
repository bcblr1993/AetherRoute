# v1.5.2 发布验收说明

2026-10-11，界面与性能修复版本，正式构建 2026101101。各页面的操作按钮改为与大标题同行并分组；窗口加入 Liquid Glass 侧边栏按钮；重做添加规则弹窗；切换页面时淡入；切页更快，内存更低。引擎未改动（核心 `183c120`）。

## 变更内容

- **页头**：`AetherPageHeader` 改为自定义 `AetherPageHeaderLayout`：标题与操作放得下时同在一行，放不下时操作换到标题下方。操作由 `AetherFlowLayout` 流式排列，大标题最多两行。两个布局都对零宽度探测返回单行尺寸，否则会按零宽度逐字折行，页面撑得比窗口还高。
- **窗口工具栏**：主窗口改为 `.unifiedCompact(showsTitle: false)` 并隐藏背景，工具栏只放系统侧边栏按钮；侧边栏可隐藏，宽度可在 180–260 pt 之间调整。`WindowChromeSynchronizer` 新增 `usesNativeToolbar`。
- **连接页**：七个散落的按钮收为三组：显示（按应用分组、排序）、暂停（只显示图标，暂停时橙色）、更多（全部关闭、断开）。搜索框移到过滤条右侧，过滤条使用新的 `AetherFilterBarLayout`：先给搜索框分配 140–220 pt，剩余宽度一次性交给过滤器。连接详情弹窗改为限高（240/420/520）可滚动，"拷贝"和"完成"固定在底部。
- **添加/编辑规则弹窗**：模式切换改为紧凑分段控件；字段放进同一张分组卡片，名称在左、控件在右；输入后才显示一行校验结果；底栏左侧"验证"，右侧"取消"和"保存"。
- **动效**：切页时淡入（`AetherVisual.pageFade`，只改透明度，160 ms），开启"减弱动态效果"时不播放。
- **测试**：新增 `testConnectionsMenusOpen`；无障碍审计白名单加入两个原生菜单；`TrafficStatisticsTests` 的密文检查改用较长的明文标记。

## 例外说明

1. **性能门禁首轮未通过**：搜索框移入过滤条后，带弹性宽度的 `HStack` 会反复测量过滤器的 `ViewThatFits`（含原生分段控件），连接页切页 p50 由 126 ms 升到 197 ms，门禁 p95 211 ms 超出预算。改用 `AetherFilterBarLayout` 后，连接页 p50 128 ms，门禁通过（见上）。预算未放宽。首轮日志已被通过的一轮覆盖，未通过时的数值即上述数值（两档 p95 211 / 206 ms，内存在预算内）。
2. **VM 矩阵的源码版本**：矩阵使用的 QA 包构建于过滤条布局修复与单元测试修复之前。这两项改动只涉及连接页布局与测试代码，不触及网络栈与扩展，因此未重建 QA 包重跑矩阵。最终代码由远程门禁、真机安装测试、VM UI 测试与性能门禁覆盖。
3. **远程门禁重跑**：
   - 1.5.2 首轮的全部测试都已通过，但结束时 Mac mini 的网卡列表多出 en6、anri0、en7（设备自身的临时接口），触发"网络状态改变"检查。重跑通过。
   - 另一轮中 `testStoreSealsTheLedgerAndOpensItOnlyWithItsKey` 偶发失败：随机密文恰好包含两字节 "HK"。该测试已修复，连续 20 轮通过，最终提交上的远程门禁通过。
4. **UI 测试的宿主网络快照**：最终一轮 UI 测试脚本以 1 退出。49 项测试全部通过，宿主隧道进程未变（PID 8418），但运行期间（55 分钟）本机 DNS / 网卡快照发生变化。判定为宿主环境波动，测试没有触碰宿主网络。
5. **跳过的 UI 用例**：`testSignedNetworkExtensionConnectDisconnectLifecycle`、`testBilingualNavigationResponsiveness`、`testCaptureUIReviewMatrix` 需要显式环境变量才会运行，与历次发布一致。
