# 2.9.1 验收与边界

发布构建：`2026111002`。Rust 核心提交 `df30585e7265e5dea2149e29fbc94e1fa5888f57`（`df30585`），重点修复应用内卸载（「设置 > 关于 > 卸载 AetherRoute...」）在完成界面点击「完成」后卡死、无法退出及沙盒环境下应用包清理受阻的问题。

## 核心修复与优化

1. **彻底消除卸载完成弹窗 `.terminateLater` 模态死锁与退出取消（`TunnelManager.swift`、`AppUninstallPerformer.swift`、`AppUninstaller.swift`）**
   - **根因**：卸载第一步调用 `await tunnel.setEnabled(false)` 时，`recordFinalTrafficSample()` 将 `hasUnsavedTrafficSamples` 置为 `true` 并将状态置为 `.disconnecting` 后立即返回；紧接着第二步移除系统网络扩展配置（`removeFromPreferences`）时，由于 `isTransitioning == true`，`canReloadAfterConfigurationChange` 返回 `false`，导致缓存的 `tunnel.manager` 未被失效清理，其 `connection.status` 停留在 `.disconnecting`（`managerConnectionIsActive == true`）。当用户点击「完成」触发 `AppTermination.request()`（`NSApplication.terminate(_:)`）时，`AppDelegate.applicationShouldTerminate(_:)` 因 `requiresDisconnectBeforeApplicationTermination == true` 返回 `.terminateLater`，AppKit 进入模态冻结循环并轮询已删除的僵尸 `NEVPNConnection` 达 30 秒，超时返回 `false` 后执行 `reply(toApplicationShouldTerminate: false)` 直接取消退出，导致窗口卡死在「完成」界面。
   - **TDD 修复**：新增 `TunnelManager.tearDownForUninstall()`，在卸载断开阶段移除 `configurationObserver` 与 `statusObserver`，取消所有重连任务、健康看门狗、实时遥测与局域网共享代理，停止活跃隧道并等待最多 3 秒后立即调用 `invalidateCachedManager()`，重置 `hasUnsavedTrafficSamples = false` 与 `state = .disconnected`；同时在 `AppUninstaller.finalizeUninstall(...)` 与 `AppUninstallPerformer.removeAppAndTerminate()` 中使用直接进程终止（`Darwin.exit(EXIT_SUCCESS)`）替代 `AppTermination.request()`。

2. **App Sandbox 下应用包直接移除回退与脱离父进程的后台兜底清理（`AppUninstaller.swift`、`AppUninstallPerformer.swift`）**
   - **根因**：Developer ID 沙盒签名配置（`Config/AetherRoute.DeveloperID.entitlements`）授予了 `/Applications/` 的读写临时例外（`com.apple.security.temporary-exception.files.absolute-path.read-write`），但未授予 `~/.Trash/` 权限，导致沙盒内调用 `FileManager.default.trashItem` 跨目录移入废纸篓失败；此外，在渲染「完成」弹窗前提前删除当前容器偏好设置 `com.aetherroute.desktop.plist` 会触发 `CFPREFERENCES_IS_WAITING_FOR_USER_CFPREFSD` 同步阻塞主线程。
   - **TDD 修复**：在 `AppUninstaller.finalizeUninstall(...)` 中优先尝试 `trashItem`，失败时自动回退为使用 `/Applications/` 权限直接执行 `FileManager.default.removeItem(at: appURL)` 删除应用包，并配合脱离父进程的 `/bin/sh` 后台清理脚本兜底；将当前进程自身的容器偏好清理（`cleanHostResiduals()`）与应用包移除推迟到 `removeAppAndTerminate()` 隐藏窗口（`window.orderOut(nil)`）后执行。

3. **系统扩展卸载授权焦点恢复与卸载完成自动收尾退出（`AppUninstallPerformer.swift`、`AppUninstallView.swift`）**
   - 修复 `SystemExtensionDeactivator` 的生命周期强引用集合（`activeDeactivators`），防止 `OSSystemExtensionRequest` 在回调前被释放。
   - 在系统扩展卸载授权弹窗（`SecurityAgent`）结束后调用 `NSApplication.shared.activate(ignoringOtherApps: true)` 恢复应用窗口焦点，并在卸载全部成功（`!result.networkRemovalFailed`）后于 0.8 秒自动触发 `AppUninstallPerformer.removeAppAndTerminate()`（点击「完成」按钮也会立即触发，具备防重入保护）。
