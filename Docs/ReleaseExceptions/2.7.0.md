# 2.7.0 验收与边界

发布构建：`2026110803`。Rust 核心提交 `df30585e7265e5dea2149e29fbc94e1fa5888f57`（`df30585`），重点交付对标 Surge 5（`Diagnostics`）与 Clash Verge Rev（`NetCheck` 网络体检）的 **一键式全链路网络诊断医生（`NetworkDiagnosticDoctor`）与脱敏诊断报告导出**。

## 核心特性与优化

1. **6 维全链路网络诊断模型与纯函数评估引擎（`Sources/AetherRouteKit/NetworkDiagnosticDoctor.swift`）**
   - 新增 `DiagnosticCheckKind`（`.localProxyListener` 本地代理端口监听、`.loopbackDirectBypass` 5 层本地回环与 `localhost` 直连防线、`.dnsResolutionHealth` DNS 解析与 Fake-IP 状态、`.domesticDirectConnectivity` 国内直连连通性、`.proxyOutboundConnectivity` 代理出站连通性、`.subscriptionAndRuleProviderHealth` 活跃订阅与规则集状态）、`DiagnosticCheckStatus`（`.passed`、`.warning`、`.failed`、`.skipped`）、`DiagnosticCheckResult`、`NetworkDiagnosticInputSnapshot` 与 `NetworkDiagnosticReport`。
   - 提供非阻塞 POSIX 回环端口探测 `NetworkDiagnosticDoctor.probeLoopbackTCPPort(_:timeoutMilliseconds:)` 与纯函数评估器 `NetworkDiagnosticDoctor.evaluate(snapshot:generatedAtUnixSeconds:)`。
   - `NetworkDiagnosticReport.formattedMarkdownReport()` 生成零敏感信息（不含任何节点服务器地址、密钥或订阅 URL）的结构化 Markdown 诊断报告，便于一键复制反馈排查。

2. **DNS 页「网络诊断检查」可视化面板（`Sources/AetherRouteApp/DNSPageView.swift`）**
   - 在 DNS 页面新增「网络诊断检查」卡片，支持一键触发 6 项全链路自检、展示每项检查的状态图标/延迟毫秒数/总体状态徽章，并提供「复制诊断报告」按钮，严格遵循 `AetherVisualTokens` 设计规范与中英双语本地化。
