### 核心功能演进与缺陷修复：

1. **TUN 与透明代理底层平滑热切与 UI 连贯无感切换（`TunnelManager`）**：
   - 彻底重构代理引擎切换流，引入底层平滑交接（`performSeamlessNetworkEngineHandover`）；
   - 在新旧引擎交替期间，先激活目标引擎、完成配置加载与会话就绪校验，再优雅停止原引擎，保护活跃网络会话；
   - 在引擎切换全过程中拦截瞬态断开通知，UI 主开关与状态栏始终保持“已连接”（`connected`）状态，连通计时器与状态指示灯连贯不重置；
   - 新增切换防重入锁定（`isSwitchingEngine`）与异常降级回滚保障机制（`attemptRollbackToEngine`）。

2. **长时间休眠与唤醒底层核心连接重置与网络自愈（`TunnelManager` & Core）**：
   - 深入排查并修复系统休眠长达 10+ 小时后恢复时，外部网络通畅但网页打开极慢、在线更新假死的故障；
   - 在 macOS 唤醒自愈链路中，主动调度底层网络核心连接状态重置与套接字池刷新，消除静默半开连接与陈旧路由缓存。

3. **规则管理系统视觉重构与路由模拟测试器（`RulesSettingsView`）**：
   - 全面升级规则页面为现代卡片流与层级视觉体系，呈现直观的类型胶囊标签、目标匹配值与出站策略动作；
   - 新增交互式“路由模拟测试器”（Route Simulation Tester），输入目标域名或 IP 地址即可实时推演命中规则详情与最终出站节点；
   - 引入快捷多维筛选器（全部 / Proxy / Direct / Reject）与关键词实时过滤，并补全 Reject 动作规范本地化。

4. **概览页面连接转场动效重构与微交互优化（`OverviewView` & `ContentView`）**：
   - 消除连接/断开状态切换时的页面高度瞬态抖动与布局跳跃；
   - 重构连接指示灯为优雅的流光渐变呼吸动效（Beacon），强化当前活跃网络引擎类型标识（TUN / Transparent Proxy）；
   - 诊断卡片支持平滑渐进式展开收起，带来沉浸、专业的桌面交互体验。

5. **菜单栏节点稳定原始排序与两级菜单联动（`MenuProxyNodeOrder` & Menu Bar）**：
   - 固化菜单栏节点呈现顺序，严格按照配置文件原始声明排列，不再随鼠标点击选中或测速延迟刷新发生无序跳动；
   - 优化一级菜单与二级子菜单的联动状态呈现，确保层级选择逻辑严谨一致。

6. **终端代理快捷复制命令语义消歧**：
   - 消除菜单栏终端代理快捷复制按钮歧义，明确划分为“复制代理命令”（配置当前实际端口与防 DNS 泄露环境变量）与“复制清除命令”（清理环境变量）。
