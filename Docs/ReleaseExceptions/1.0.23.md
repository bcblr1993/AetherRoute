# v1.0.23 发布验收说明

2026-09-22，完成物理网络通知防抖与会话复用优化、底层核心内存映射与线程收敛、Apple Silicon 物理真机验证与 Tart 虚拟机全量 6 维网络矩阵回归测试：

### 核心优化与演进落地：

1. **物理网络接口通知防抖与动态存储会话复用（`PacketTunnelProvider.swift` & `TransparentProxyProvider.swift`）**：
   - 引入 150ms `DispatchWorkItem` 防抖机制，彻底消除了网络扩展启动 (`installNetworkSettings`) 及物理网卡切换时引发的内核通知风暴（>220 次/秒）；
   - 复用 `SCDynamicStore` 会话实例，杜绝高频调用 `SCDynamicStoreCreate` 引发的系统 CoreFoundation 节流警告与无谓 IPC 开销。

2. **核心内存映射与运行时线程预算收敛（`Core/Engine`）**：
   - 引入 `memmap2` 对 MaxMind MMDB 数据库文件实施只读只取内存映射，消除数十兆完整堆载入物理常驻，完美适配 iOS 15MB 严格 Jetsam 上限并大幅减轻 macOS Network Extension 常驻驻留；
   - 约束 Tokio 异步运行时工作线程池大小，进一步避免进程内线程激增与上下文切换开销。

3. **标准发布流水线 SOP 制度化（`AGENTS.md`）**：
   - 将本地构建回归、Tart VM 6 维网络矩阵验证及清理、`chenxu@100.64.0.3` 物理真机门禁、CHANGELOG 维护、公证发布与官网同步标准化为强制性 SOP。
