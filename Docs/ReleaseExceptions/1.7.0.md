# v1.7.0 发布验收说明

2026-10-12，功能版本，正式构建 2026101103。新增配置覆写（自定义分组、按地区生成分组、隐藏节点）。订阅更新后保留节点选择等设置。TUN 与 Tailscale MagicDNS 共存。引擎更新到核心 `d2cd0b4`。实施计划见 `Docs/Plan-1.7.0.zh-CN.md`。

## 变更内容

- **订阅更新保留设置**
  - `ProfileSettingsMigration` 在新配置安装前，把选中的节点、选择方式（含 1.6.0 旧开关键）、首选节点、DNS 覆盖从旧内容摘要迁到新摘要。
  - 只迁移新配置（应用覆写后）中仍然存在的分组与节点，不覆盖新摘要已有的设置。
  - 扩展读取的文件格式与键规则不变。
- **配置覆写**
  - 模型与存储：`ProfileOverride` / `CustomProxyGroup`，结构化、无脚本、有上限。作为 `ActiveProfile.overrides` 保存在加密配置目录，随导出与 iCloud 同步。`ProfileCatalogStore.replace` 统一保留覆写，只有 `setOverrides` 能修改或清除。旧版本读取时忽略该字段。
  - 编译：`ProfileOverrideCompiler` 把自定义分组以单行写法插在 `proxy-groups` 开头。需要改动的分组改写为保留全部字段的单行映射，其余行逐字节不变。读不准的分组原样保留并提示。结果重新解析，失败则回退原配置。支持 JSON 配置。
  - 运行：运行配置为原文加覆写（`runtimeYAML`），扩展的兜底路径同样应用覆写。连接中保存覆写走热重载，不清空运行状态。
  - 界面：代理页"新建分组"、"更多 › 按地区生成分组… / 隐藏节点…"，表单实时预览，自定义分组带标签、可编辑删除。
- **Tailscale 共存**
  - 核心 `d2cd0b4`：TUN 下发往真实 IP 的 HTTPS 连接按 TLS SNI 恢复域名（复用透明代理已有逻辑）。
  - 透明代理排除 `100.64.0.0/10`。
  - DNS 页检测到 Tailscale 时给出说明，出口节点接管默认路由时提示冲突。
- **测试**
  - 单元测试：覆写编译、迁移、存储、地区识别、Tailscale 网段。
  - 引擎加载门禁：`test_profile_override_cores.sh`，已并入 `test.sh`。
  - UI 测试：3 项。
  - 端到端：`test_profile_override_e2e.sh`。
  - QA 钩子：`AETHERROUTE_QA_OVERRIDES_PATH`、`AETHERROUTE_QA_REPLACE_PROFILE_PATH`，仅编入 QA 构建。
  - `test_ui_in_vm.sh` 支持逗号分隔多个用例。

## 例外说明

1. **矩阵直连组合的大请求上传**：
   - tun/direct 用时 113 秒（门限内通过）；transparent/direct 两次都在送达全部 2,097,152 字节、收到 HTTP 200 后，于 120 秒时被截断。
   - 直连模式不经过任何节点。在 VM 中完全退出 AetherRoute 后直接上传到同一站点，两次也都在 120 秒被截断。判定为当日直连网络路径偏慢，与本版本无关。
   - 所有经代理的组合均为 3.9–6.5 秒。
   - 单独复跑 transparent/direct 时，退出核验报"tunnel has no current stop evidence"：只跑子集时，准备阶段启动的 TUN 扩展没有对应的停止记录。完整矩阵中六项退出核验全部通过。
2. **故障转移 TUN 首轮 43 秒**：切换耗时由巡检间隔（10 秒）、复测（1 秒）、候选探测与测试脚本自身的探测间隔叠加而成，首轮恰好落在最坏位置。两次复测为 22、24 秒，与 1.6.0 的 22 秒一致，预算未放宽。
3. **UI 测试首轮中断**：首轮在会话结束时被中断，中断前 34 项通过、`testPrivacyPageKeepsConsentInReachAcrossLanguagesAndAppearances` 一项因"等待 UI 查询超时"失败。该页面本版本未改动，完整重跑 53 项全部通过（见验证结论 9）。
4. **真机 MagicDNS 测试**：需要临时开启 Mac mini 的"使用 Tailscale DNS"，经用户同意后执行。测试脚本退出时自动恢复为关闭，并恢复透明代理模式。
5. **跳过的 UI 用例**：`testSignedNetworkExtensionConnectDisconnectLifecycle`、`testBilingualNavigationResponsiveness`、`testCaptureUIReviewMatrix` 需要显式环境变量，与历次发布一致。
