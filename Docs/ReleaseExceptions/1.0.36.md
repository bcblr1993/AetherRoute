# v1.0.36 发布验收说明

2026-09-30，界面全面重做。网络引擎、协议实现与两个网络扩展的代码与 1.0.35 相同，本版只改动 App 界面层。

### 新增

1. **菜单栏版本与更新提示**：底部显示当前版本；Sparkle 发现新版本后变为"新版本 x.y.z"标签，点击打开更新窗口，"以后提醒"不会清除，跳过或开始安装后清除；有新版本时菜单栏图标右上角显示蓝点；"···"菜单顶部显示版本并提供"检查更新"。
2. **命令面板（⇧⌘P）**：键盘完成连接/断开、重新连接、切换路由模式与网络引擎、测速、切换节点、跳转页面与设置。
3. **自动组显示实际节点**：url-test / fallback 等自动策略组根据实时连接的出口链路显示正在使用的节点（如"Singapore Edge · Auto"），没有流量时显示组名。

### 改进

1. **菜单栏面板**按控制中心样式重做：顶部状态环与大开关，中部出口节点与测速，下方路由模式与网络引擎；节点列表改为扁平行，8 个以内隐藏搜索。
2. **设置由 9 个分页合并为 4 个**：通用、网络（含绕过规则）、隐私与诊断、关于（含软件更新与开源许可）；旧分页名跳转仍然有效。
3. **概览页**：连接状态、出口与线路质量合为一张卡片；已连接时显示连接时长；分段控件选中段改为强调色，深色模式下清晰可辨。
4. **8 个弹窗统一**头部、宽度与按钮布局；自定义规则弹窗不再溢出；连接详情分为"路由 / 流量"两组；命中规则统一按 `DOMAIN-SUFFIX` 等配置写法显示。
5. **动效**：切换页面只淡入新页面，不再整窗形变；"连接中"改为旋转圆弧；流量波形平滑滚动；延迟数值滚动过渡；全程遵循"减弱动态效果"。
6. **流量刷新**：前台可见每 3 秒、可见但不在前台每 10 秒、不可见时暂停；线路健康检查恒为 15 秒。

### 修复

1. 窄窗口（780×560，英文）下连接页被页标题顶出窗口。
2. 字面量标题的按钮（保存、下载并保存、下载并校验、检查更新）及多处弹窗文案在中文界面显示英文。
3. 最小窗口下代理页节点列表只显示一行半。
4. 出口为嵌套策略组时误显示为节点并带占位协议"PROXY"。
5. 窗口可见但不在前台时流量数字停止刷新；连接页单独停留时不刷新。
6. DNS 运行时覆盖行说明被挤成窄列，且说明字重高于标题。
7. 自动检查更新关闭时仍显示"已启用自动检查"。
8. `scripts/test.sh` 中虚拟机预热测试以 `sudo killall` 真实结束本机正在运行的隧道扩展（测试替身缺少 `sudo`）。

### 清理

删除经 Periphery 分析并逐项核对的无用 Swift 代码与 148 条无用本地化文案、60 个无引用脚本、3 个孤立探针程序。

### 验证结论

1. **本地回归**：`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全部通过；单元测试 466 个全部通过。
2. **Tart 虚拟机矩阵（`macos27`，构建 2026093003）**：6 个组合首轮全部通过，含大请求上传、空闲 Keep-Alive 复用与透明代理 SNI 恢复检查；测试后虚拟机无遗留临时文件。
3. **物理真机（Apple Silicon Mac mini）**：使用公证候选包实测——TUN 模式 2 MiB 上传 3.5 秒、6 MiB 5.6 秒、空闲 Keep-Alive 复用通过；透明代理模式 2 MiB 3.4 秒、6 MiB 7.2 秒、空闲 Keep-Alive 复用与 SNI 恢复通过；远程回归门禁 `test_remote_arm64.sh fast` 通过，门禁前后系统代理、DNS、默认路由与网卡状态一致。
4. **界面**：中英文、浅色/深色、780×560 至 1100×720 窗口的隔离预览截图逐页核对；设计令牌、本地化与遥测订阅范围守卫通过。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. Sparkle 更新清单使用 Ed25519 密钥签名并通过验签；
5. 磁盘镜像不含测试说明文件，卷标为 `AetherRoute 1.0.36`。
