# v1.0.31 发布验收说明

2026-09-27，完成本机 6 小时连续运行指标与系统日志深度监控（720 周期无侵入采样）、SwiftUI 运行时更新 Fault 消除、Combine 状态同步解耦、Menu Bar Quit 退出 XPC 0x7d 断言修复与优雅清理、网络扩展意外中断恢复感知（.recovering）、活动路由探测超时高灵敏度优化（3.5s Failover）、Tart 虚拟机与物理真机全矩阵回归验证：

### 核心优化与演进落地：

1. **SwiftUI 运行时 Fault 消除（`ContentView.swift`）**：
   - 修复在视图更新周期内调用 `setRealtimeTelemetryPreferred` 引发的 `Publishing changes from within view updates is not allowed` 告警；
   - 将 `updateOverviewTelemetryState()` 中的属性同步改由 `DispatchQueue.main.async` 派发，彻底消除运行时状态更新竞争。

2. **Combine 状态同步初始化解耦（`AppAutomationController.swift`）**：
   - 为 `licenseAccessObservation` 和 `privacyObservation` 订阅管道追加 `.receive(on: DispatchQueue.main)` 调度；
   - 规避在控制器与主视图装载生命周期中因同步修改属性引发的重入警告。

3. **MenuBarExtra Quit 退出时 XPC 0x7d 断言修复与安全退场（`AetherRouteApp.swift`）**：
   - 菜单栏弹窗中的 Quit 按钮通过 `DispatchQueue.main.async { NSApplication.shared.terminate(nil) }` 异步解耦，杜绝在 AppKit 菜单事件跟踪循环内强杀引发的 `0x7d` XPC 退出断言；
   - 在 `AppDelegate` 中实现 `applicationWillTerminate(_:)` 生命周期回调，有序释放 DispatchSource 信号源并主动清理网络扩展 Tunnel 资源，实现进程优雅安全退出。

4. **网络扩展中断恢复感知（`TunnelManager+ConnectionLifecycle.swift`）**：
   - 针对多网络工具并存场景下底层系统扩展触发 NEVPNConnectionErrorDomain Code 12 意外终止，当即将触发自动重连时将连接状态置为 `.recovering`（恢复中），防止界面误报不可用错误红框，并在重连成功后平滑恢复至 `.connected`。

5. **活动路由探测超时高灵敏度优化（`TunnelStartupTimingPolicy.swift`、`TunnelManager+Telemetry.swift`）**：
   - 新增 `activeRouteProbeTimeoutMilliseconds = 3_500` 策略；
   - 将活动节点探测超时由 10s 缩短至 3.5s，极大提升节点网络闪断感应速度与节点切换（Failover）敏捷度。

6. **版本号推进与项目规范对齐（`project.yml`、`CHANGELOG.md`）**：
   - 版本号推进至 `MARKETING_VERSION: "1.0.31"`, `CURRENT_PROJECT_VERSION: "2026092702"`。
