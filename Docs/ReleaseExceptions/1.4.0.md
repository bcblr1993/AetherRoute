# v1.4.0 发布验收说明

2026-10-08，功能与架构重大升级版本：支持连接无损断开（单连接/应用批量/全部断开）、节点切换自动断开旧连接；集成应用与网络扩展的端到端日志查看器与实时日志级别下发；新增节点分享链接与多源二维码解析（图片文件拖拽、剪贴板截图、ScreenCaptureKit 屏幕扫码）；引入基于内核 ART3 遥测的精确本地流量统计与 AES-256-GCM 加密存储；支持进入代理页自动测速；内核 Flow ABI 升级至 v6（25 个独立导出符号）。

### 验证结论

1. **本地回归**：12 种协议真实互通门禁（sing-box 24 用例、VLESS REALITY、WireGuard、ShadowQUIC、OpenSSH）、`test_network_switch_gate.py`、`Tests/EngineReconnect/run.sh`、`Tests/RuntimeEnvironment/run.sh`、`./scripts/test.sh` 全量通过；单元测试套件全部通过，零编译警告；App 完整构建通过。
2. **物理真机门禁与运行时验证（Mac mini，局域网 100.64.0.3，代替虚拟机）**：公证正式候选包 2026100803 执行 TUN 与透明代理全量测试，空闲复用（6/6）与 2 MiB 上传（6/6）全部通过。
3. **远程门禁**：`test_remote_arm64.sh fast` 在 `100.64.0.3` 上执行通过。

### 例外说明

1. **虚拟机矩阵改在物理真机执行**：因本地 Tart VM 环境不可用，按照发布策略，全量测试矩阵与门禁改在局域网物理设备 Apple Silicon Mac mini (`chenxu@100.64.0.3`) 上执行。

### 正式发布规范执行核验

1. 采用标准生产核心（Normal Core Variant），不含 QA 自动化标记，发布通道为 `stable`；
2. 主程序与两个网络扩展均为 Developer ID 签名与 Hardened Runtime；
3. 经 Apple 公证并完成票据装订（App + DMG）；
4. 安装包不含任何配置归档、测试服务器、私有凭据或订阅地址（`*.aetherroute`、`*.yaml`、`*.conf`），发布打包脚本核查仅含 `AetherRoute.app` 与 `Applications`，卷标为 `AetherRoute 1.4.0`。
