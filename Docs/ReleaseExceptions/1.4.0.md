# v1.4.0 发布验收说明

2026-10-09，功能版本：连接无损断开（单连接 / 按应用 / 全部）、切换节点自动关闭旧连接；应用与网络扩展的日志查看器及实时日志级别；节点分享链接与二维码导入（图片、剪贴板截图、屏幕扫码）；基于内核 ART3 遥测的本地流量统计（AES-256-GCM 加密存储）；进入代理页自动测速；内核 Flow ABI v6（25 个导出符号）。正式构建 2026100901。

## Review 修正

- 重启、关机或注销后恢复自动连接：1.3 在系统的多次退出回调中反复改写连接意图，最后一次回调时扩展已停止，记录成"未连接"。现仅在第一次退出回调保存，并保留用户已保存的意图，主动断开不会被撤销。本机重启日志 `stage=startup autoReconnect skipped reason=wasNotConnectedBeforeTermination` 证实了 1.3.3 的这一行为。
- 流量统计保存与清空串行执行；关闭统计或退出前写入待保存数据；按 VPN 会话开始时间识别新会话。
- 多行日志作为完整记录按时间排序；日志尾部读取只读取所需字节。
- 图片二维码解码与链接解析移到后台；导入期间不能再次开始导入；剪贴板图片读取保留 PDF/HEIC 等格式的兜底。

## 例外说明

1. **UI 测试环境性失败**：22 项在 v1.3.3 与 1.4.0 上同样失败，原因在 VM 环境：`Cmd+,` 打不开设置窗口（13 项设置类用例）、macOS 27 新增的无障碍审计规则（对比度、可点击 action）以及列表行数与搜索过滤的时序问题。新增的日志查看器用例同样卡在打开设置窗口这一步，未能在 VM 中执行。此前的 VM 运行还受另一个项目的 QA 应用抢焦点、VM 自动锁屏与拼音输入法影响，已分别排除后重跑。
2. **候选包之后的测试改动**：公证候选包构建后修改了 `Tests/AetherRouteUITests/AetherRouteUITests.swift`（统计窗口按钮按标题定位；导入用例改用剪贴板输入、文字断言同时匹配 value），以及本说明与 CHANGELOG。产品二进制未改变。
3. **统计窗口的容器标识符**：`traffic-statistics` 标识符会传播并覆盖子元素的标识符，只影响 UI 自动化定位，对用户与 VoiceOver 无影响；1.4.1 改为 `.accessibilityElement(children: .contain)`。
4. **Mac mini 门禁网络**：第一次经 Tailscale（100.64.0.3）运行时网络中断，改经局域网 192.168.50.226 重跑通过。
