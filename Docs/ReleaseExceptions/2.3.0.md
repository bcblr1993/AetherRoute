# 2.3.0 验收与边界

发布构建：`2026110602`。Rust 核心提交 `bdb88eb081eb8594351438d1f78a40f84dc858ab`（`bdb88eb`），重点交付对标 Surge 5 的三大核心特性：**网络环境自动化（按网关 / 有线以太网 / Wi-Fi 自动切分流模式或启停连接）**、**单连接阶段握手耗时拆解（`ART5` 与 `ConnectionTimingBreakdown`）** 以及 **DNS 自定义本地 Hosts 映射（`CustomHostMapping`）**。

## 核心新特性

1. **网络环境自动化（`NetworkAutomationPreferences`）**
   - **零权限物理网络环境感知**：在 `Sources/AetherRouteKit/PhysicalUplinkDetector.swift` 新增 `NetworkEnvironmentSnapshot` 与 `PhysicalUplinkDetector.currentNetworkEnvironment(store:wifiSSIDProvider:)`，基于 `SCDynamicStore` 实时读取主物理上行网卡、IEEE 802.11 / 有线以太网接口类型以及 IPv4 路由器网关地址（`Router`），无需申请 macOS 定位权限即可区分家庭、办公室路由器与有线网络环境。
   - **规则优先级匹配与动作执行**：在 `Sources/AetherRouteKit/AppAutomationPreferences.swift` 新增 `NetworkTriggerKind`（`.gatewayAddress`、`.ethernet`、`.wifiSSID`）、`NetworkAutomationAction`（`.setRoutingMode(RoutingMode)`、`.connect`、`.disconnect`）、`NetworkAutomationRule` 与 `NetworkAutomationPreferenceStore`；在 `AppAutomationController.swift` 与 `AetherRouteApp.swift`（设置 → 通用 → 自动化）提供规则管理界面与自动切换闭环。

2. **单连接阶段握手耗时拆解（`ART5` & `ConnectionTimingBreakdown`）**
   - 在 `Sources/AetherRouteKit/NetworkTelemetry.swift` 扩展 `ConnectionTelemetry` 与二进制编解码器 `NetworkTelemetryCodec`（新增 `ART5` 协议头，100% 向下兼容 `ART1`–`ART4`），承载单条连接的 `dnsDurationMilliseconds` 与 `connectDurationMilliseconds`，并提供 `ConnectionTimingBreakdown` 计算 DNS 解析、出站节点握手与建连总耗时及占比。
   - 在 `Sources/AetherRouteApp/ConnectionsPageView.swift` 的连接详情面板（`ConnectionInspector`）新增「建连耗时（`Timing`）」分组，清晰展示 `DNS 解析`、`节点握手` 与 `建连总耗时`。

3. **DNS 自定义本地 Hosts 映射（`CustomHostMapping` in `ProfileOverride`）**
   - 在 `Sources/AetherRouteKit/ProfileOverride.swift` 新增 `CustomHostMapping`（支持精确域名 `nas.home.lan`、单级通配 `*.dev.internal`、后缀通配 `+.corp.example` 以及基于 `inet_pton` 的 IPv4/IPv6 字面量严格校验），随配置加密存储与 iCloud 同步，订阅更新绝不覆盖。
   - 在 `Sources/AetherRouteKit/ProfileOverrideCompiler.swift` 支持将已启用的 `customHosts` 无损合并编译至 YAML 与 JSON 配置的顶层 `hosts:` 映射中；在 `ProfileHostsInspector.resolveAlias`（`Sources/AetherRouteKit/ProfileConfigurationSummary.swift`）新增 `+.` 后缀通配解析并接入「规则」页路由测试器（`RulesPageView.swift`），同时在「DNS」页（`DNSPageView.swift`）提供可视化自定义 Hosts 管理卡片。
