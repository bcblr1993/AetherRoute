### 核心功能演进与缺陷修复：

1. **开机自启动管理（\`AppStartupController\`）**：
   - 基于 macOS 原生推荐的 \`ServiceManagement.SMAppService.mainApp\` 接入系统级开机自启动；
   - 动态监听与维护注册状态（\`enabled\` / \`notRegistered\` / \`requiresApproval\`），支持用户一键开启或关闭；
   - 在「设置 -> 通用」中新增「开机自启动」专属控制卡片，附带系统权限引导与未批准状态告警。

2. **连接意图持久化（\`ConnectionIntentStore\`）**：
   - 在 \`AetherRouteKit\` 中实现轻量且线程安全的连接意向持久化存储；
   - 严密隔离常规运行模式与 UI Review / QA 模式，确保用户意图真实有效保存。

3. **退出网络保护与启动智能重连恢复（\`TunnelManager\`）**：
   - **退出/关机安全切断**：在应用退出与关机流程（\`disconnectForApplicationTermination()\`）中，标记 \`isApplicationTerminating\` 隔离标志，在切断 Network Extension 保护系统网络不瘫痪的同时，完整保留用户的预期连接意图，防止退出清理逻辑误将意图覆写为断开；
   - **启动智能恢复重连**：应用启动 \`prepare()\` 流程收尾时，读取上次连接意图；若此前处于连接状态且满足网络接入条件，自动安全恢复连接；若此前为断开状态，则保持未连接。

4. **国际化与多语言完备支持（\`Localizable.xcstrings\`）**：
   - 补充完善中英文全部新特性与状态提示文案。
