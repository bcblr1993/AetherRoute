# v1.0.21 发布验收说明

2026-09-20，完成 10 小时长周期监控优化、Apple Silicon 物理真机验证与 Tart 虚拟机全量矩阵回归测试：

### 核心优化与演进落地：

1. **常驻后台内存主动释放机制（`AppWindowManager.swift`）**：
   - 引入 Darwin `malloc_zone_pressure_relief`，在窗口关闭（`windowShouldClose`）以及最小化（`windowDidMiniaturize`）时，主动通知系统回收空闲堆内存分页；
   - 显著缩减菜单栏后台常驻物理内存占用，自 ~123MB 回收至 60–90MB。

2. **数据包处理缓冲容量预分配（`CoreBridge.swift`）**：
   - 在 `writePacket` 中预先预留容量（`reserveCapacity(64)`），防止网络突发流量下的数组频繁扩容与内存抖动；
   - 优化批量刷盘逻辑，确保网络包转发具备更低延迟与更高吞吐表现。
