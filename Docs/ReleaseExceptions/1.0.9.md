# v1.0.9 发布验收说明

2026-09-16，维护者明确要求：

> 修复锁屏再解锁时软件自动断开并重连一次的问题，实现锁屏和解锁期间一直保持连接，不触发重新连接，避免锁定屏幕时网络断开。
> 完成全部测试，所有功能重新测试一遍，编写 CHANGELOG，构建正式版本发布 v1.0.9。

### 核心功能演进与缺陷修复：

1. **锁屏与显示器休眠期间保持持续连接**：
   - **解除屏幕锁屏/解锁与系统休眠的过度绑定**：此前在 `AppRuntimeEnvironmentController` 中将 `com.apple.screenIsLocked`/`screenIsUnlocked` 以及显示器熄屏/亮屏（`screensDidSleepNotification`/`screensDidWakeNotification`）错误映射为 `.systemWillSleep` 和 `.systemDidWake`，导致用户每次锁屏解锁时都触发 IPC 调用 `client.resetNetwork()` 并引起扩展核心重置和隧道断开重连；
   - **保持网络流与长连接持续存活**：macOS 锁屏与熄屏期间，系统硬件与网络协议栈处于完全正常运行状态。现仅保留真实的系统物理睡眠与唤醒通知（`NSWorkspace.willSleepNotification` 与 `NSWorkspace.didWakeNotification`），锁屏和熄屏时绝不断开网络，保障下载、SSH 会话与实时代理的稳定持续；
   - **完善回归测试套件**：新增 `Tests/RuntimeEnvironment/` 自动化测试套件，在隔离通知中心下全面覆盖显示器休眠连续性、锁屏不重置、以及真实整机休眠/唤醒恢复链路。

在 Tart 虚拟机（`aether-diag-1434`）中完成实机测试与验证，经维护者授权跳过常规 24 小时长时间稳定性浸泡测试，直接执行正式生产构建与发布。
