   - 每个组合写入引擎、路由模式与本地代理设置后重新连接，再运行与虚拟机矩阵相同的 `test_runtime_acceptance.sh`；
   - 与虚拟机相比缺少"每轮干净环境"的隔离；Mac mini 无免密 sudo，验收以非特权模式运行（本地代理端口归属仍按候选进程 PID 校验通过）；

2. **TUN 本地代理提示的界面截图**：新增的说明文字位于设置页底部，本机隔离预览无法自动滚动到该处截图；文案经编译、本地化校验覆盖，未做截图验收。
