# v1.0.14 发布验收说明

2026-09-17，维护者明确要求：

> /goal 在进行完整包构建 然后 在 vm 完成完成全部场景以及功能的回归验证和测试 测试通过后 根据上一个版本的 到当前的改动编写 changelog 然后发布最新的 v1.0.14 版本

### 核心功能演进与缺陷修复：

1. **Sparkle 软件更新弹窗重构（Apple HIG 规范）**：
   - 采用精致 macOS 原生卡片容器与双层视觉架构（`AppUpdateWindow`）；
   - 支持全动态深色/浅色自适应外观、动态平滑过渡；
   - 更新内容结构化分类呈现（新增功能、视觉与体验优化、问题修复），并在顶部直观展示版本号与构建编号药丸标签；
   - 优化 `generate_sparkle_appcast.sh`，构建时自动为更新说明套用原生样式模板并注入 Appcast 描述。

2. **代理页面（ProxiesPageView）原生交互与视觉全面升级**：
   - **策略组切换体验重构**：将顶部平铺按钮改造为 macOS 原生 Segmented 胶囊切换栏，配合弹簧动画与平滑交互，彻底解决多策略组切换不够直观的问题；
   - **强化当前策略组身份呈现**：在节点列表顶部新增专属信息卡片，清晰呈现当前选中的策略组名称、语义图标、调度策略标签（如 Select / URL-Test / Fallback）及手动切换状态；
   - **明晰测速控制层级**：消除“全部测速”与“测试延迟”混淆，顶层保留全局全组测速操作并配文案说明，策略组内部卡片提供单组专属“测速本组”动作；
   - **底库节点与诊断专区语义化**：将“底库节点清单与 Providers”明确重命名为“节点解析与协议诊断（底库清单）”，并在展开区补充诊断说明，帮助排查节点解析状态与协议参数；
   - 完整补齐多语言国际化词条（`Localizable.xcstrings`）。

### 正式发布规范执行核验：

1. 采用标准生产核心（Normal Core Variant），剥离 QA 自动化测试标记；
2. 主程序（`com.aetherroute.desktop`）及网络扩展（`com.aetherroute.desktop.tunnel`、`com.aetherroute.desktop.transparent-proxy`）均采用 Developer ID 签名与 Hardened Runtime；
3. 通过 Apple Notarization 官方公证（Accepted）并完成票据装订（Stapled）；
4. Sparkle 自动更新清单采用官方专用 Ed25519 密钥签名并经反向验签断言通过；
5. 生成完整 SHA256SUMS 校验清单并发布官网与 GitHub。
